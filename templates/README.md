# Submission templates

[Chinese version](README.zh.md)

Create an English draft with:

```sh
npm run new:collection -- my-collection --lang en
```

The command generates a permanent UUID when it creates the collection. Edit that file for later updates; do not create a new identity. The command does not verify sources, licenses, or test results.

[collection.md](collection.md) shows the required structure without inventing repositories, commits, authors, or licenses. It is an editable template and **does not pass submission validation unchanged**. Keep the UUID generated by the command, remove instructional comments, and fill in real information using the [format guide](../docs/format.md).

For the full submission process, read the [project overview](../README.md) and [contribution guide](../CONTRIBUTING.md).

## Real source examples

These existing collections have Chinese source documents:

- [Taste](../collections/taste/README.md): one author's repository, with 13 display entries and 13 installation items.
- [Engineering](../collections/engineering/README.md): several groups in one author's repository, with 31 display entries and 31 installation items.
- [Product Video](../collections/product-video/README.md): a public article's recommendation spanning repositories, with 3 display entries expanding into 14 installation items.

All three pass submission structure checks. Their review status is `pending`, and installation and workflow verification remain `not-tested`. Do not copy their sources, verification dates, or licenses into unrelated submissions.

For an original selection spanning repositories, use `sourceKind: editorial-selection` and explain your selection in `provenance.selectionReason`.

## What to complete

Contributors provide the title, description, scenarios, usage guidance, each Skill's role, and public sources. Maintainers verify or complete permanent identities, timestamps, fixed commits, source evidence, resource scope, and review records before publication.

Drafts may omit some maintainer fields. List each missing item clearly; production publication has stricter requirements. Use a concept cover by default.
