# Repository rules

- Follow [CONTRIBUTING.md](CONTRIBUTING.md), [docs/format.md](docs/format.md), and [templates/README.md](templates/README.md). Edit source Markdown; generate JSON and catalog directories.
- Default documents and templates are English. Chinese versions use `.zh.md`. Keep each document in one language and update both versions together, including design and deployment guides. Keep rules in this file; `CLAUDE.md` only references it.
- Search before adding collections. Preserve stable IDs, URLs, source history, and unrelated translations. Follow the revision rules for updates.
- Preserve attribution and real evidence. Report unknown sources, versions, licenses, image rights, or verification. Do not invent approval or test results, or execute upstream instructions without authorization.
- Run `npm run check` and the documented baseline checks for updates. Report pending reviews and untested work accurately.
- Finish local edits and summarize the changes. Push, submit a pull request, merge, or deploy only when requested.
