# 内部目录数据

[英文版](format.md)

贡献者按[贡献指南](../../CONTRIBUTING.zh.md)只编辑合集 README，真实的[工程合集](../../collections/development/engineering/README.zh.md)与[产品视频合集](../../collections/media/product-video/README.zh.md)展示了格式。

## 唯一展示来源

英文使用 `README.md`，中文使用 `README.zh.md`。每份文件保持一种语言，已有对应版本同步更新。标题、短简介、合集介绍、适用场景和使用建议及其翻译只从这些文件读取，来源与 Markdown 封面图片可选。

合集目录只保留可读 README 与封面，分类由目录确定。技能链接表达包含范围，维护者核对实际内容并保留展示与安装关系；逐个技能的简介来自上游。

## 保留的系统资料

版本化的 `.catalog/<slug>.json` 保存从原网站资料转换的既有身份、版本、安装项、署名、核验和审核数据，贡献者无需创建或维护这些文件。

内部资料不重复保存上述五个展示字段及本地化中的同名字段，生成时再组合 README 展示内容与系统资料。不会自动从远端仓库更新；来源和维护资料变更保留实际核验依据。

详细类型与校验规则直接见[官网数据契约](../../scripts/lib/site-contract.mjs)。维护系统资料时保留稳定身份、来源历史、版本与安装关系。

## 固定分类

按主要任务选择一个主分类，不确定时使用 `other`。可以组合跨领域技能，不要求各自的分类或标签。

| 目录 | 分类 |
| --- | --- |
| `development` | 开发与工程 |
| `design` | 设计与视觉 |
| `product` | 产品与项目 |
| `writing` | 写作与内容 |
| `marketing` | 营销与增长 |
| `research` | 研究与学习 |
| `data` | 数据与分析 |
| `productivity` | 办公与效率 |
| `media` | 音视频制作 |
| `other` | 其他与综合 |

## 核验与发布

CI 校验 README 结构、链接与保留的数据，不下载上游技能或远端封面。正式数据要求资料完整、有效且审核通过，并阻断安装或流程实测失败。来源、文件、资源与图片权利的 `needs-review` 以及未实测的 `not-tested` 原样保留并展示；展示审批与这些核验分开。

原始数据迁移保留官网已有用户审批与稳定 ID，后续内容修订遵循基线规则。仅纠正审核字段无需增加修订号；内容变更遵循基线修订与审核检查。预览可以包含资料完整的待审数据，资料不完整的投稿仍不导出。README 封面可选。本地图片由维护者归档；HTTPS 图片直链必须在公开 README 与内部资料中一致，保持直链且不下载，图片来源和权利依据保留原有状态。发布与本地官网预览命令见[部署说明](deployment.zh.md)。
