# 仓库规则（中文阅读版）

正式规则见 [AGENTS.md](../AGENTS.md)。本页同步提供中文说明，`CLAUDE.md` 引用正式规则。

- 按[贡献指南](../CONTRIBUTING.zh.md)投稿。新增前先查重，贡献者编辑可读的合集 README。根 README 直接链接贡献指南与维护文档。
- 默认英文，中文文件加 `.zh.md`。每份文件保持一种语言，已有中英文版本同步更新，规则文件也一样。
- 贡献者提交 README 和可选封面，不新增 `.catalog` JSON。CI 读取链接指向的上游技能，将官网数据生成到 `dist/`。身份、版本和安装关系遵守[维护规则](maintainers/format.zh.md)，保留三份迁移记录的兼容性。
- 合集展示内容来自 README，技能简介原样采用上游内容。格式检查离线运行；生成预览需要联网读取上游数据。
- 保留真实署名与核验状态，不编造许可、批准或测试结果。正式审批来自真实审核后合并到 `main` 的 PR，由可信发布 CI 核对。检查通过本身不代表审核通过。
- 修改后运行 `npm run check`，如实报告结果。
- 只有用户要求时，才执行上游技能指令、推送、提交拉取请求、合并或部署。
