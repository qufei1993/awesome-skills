# 仓库规则（中文阅读版）

正式规则见 [AGENTS.md](../AGENTS.md)。本页同步提供中文说明，`CLAUDE.md` 引用正式规则。

- 按[贡献指南](../CONTRIBUTING.zh.md)投稿。新增前先查重，贡献者编辑可读的合集 README。根 README 直接链接贡献指南与维护文档。
- 默认英文，中文文件加 `.zh.md`。每份文件保持一种语言，已有中英文版本同步更新，规则文件也一样。
- 合集展示内容来自 README，技能简介来自上游。修改内部数据或发布时遵守[维护规则](maintainers/format.zh.md)。保留身份、版本和安装关系，用工具生成网站数据。
- 保留真实署名与核验状态，不编造来源、许可、批准或测试结果。允许展示不代表核验完成，检查通过不代表可以发布。
- 修改后运行 `npm run check`，如实报告结果。
- 只有用户要求时，才执行上游技能指令、推送、提交拉取请求、合并或部署。
