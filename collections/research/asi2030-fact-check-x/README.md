# Fact-Check-X Module Suite

Capture answers, compare claims, verify evidence, and coordinate fact checks.

## Overview

Follows the author’s released four-module suite; the one-entry complete distribution is a separate product variant.

## Scenarios

- Compare AI answers
- Trace claims to evidence

## Usage

Keep all four modules and their bundled scripts and references. Use the documented collection and comparison tools to preserve original answers and evidence trails.
