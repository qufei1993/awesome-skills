# Firecrawl 技能目录

使用 Firecrawl 正式网络基础操作及研究、提取流程。

## 合集介绍

分发目录结合由作者 CI 同步的基础与工作流系列，本仓库是完整目录的官方安装来源。

## 适用场景

- 收集并提取网站数据
- 运行结构化研究流程

## 使用建议

安装目录或选择具名技能，再配置 Firecrawl 访问；CLI 接入安装基础技能，工作流依赖随具体流程而定。
