# Firecrawl Skills Catalog

Use Firecrawl’s published web primitives and research or extraction workflows.

## Overview

The distribution catalog combines core and workflow families synchronized by the author’s CI. This repository is an official installation source for the complete catalog.

## Scenarios

- Collect and extract website data
- Run a structured research workflow

## Usage

Install the catalog or select a named Skill, then configure Firecrawl access. CLI onboarding installs core Skills; workflow requirements depend on the recipe.
