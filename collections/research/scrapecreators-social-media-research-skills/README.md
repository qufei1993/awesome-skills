# ScrapeCreators Social Research Skills

Turn public social data into competitor, audience, and content research.

## Overview

ScrapeCreators’s workflows cover outlier posts, comments, transcripts, ad libraries, creators, influencer prospects, trends, demand, and social listening.

## Scenarios

- Find successful posts and audience themes
- Analyze competitors, creators, or ad libraries

## Usage

Configure the ScrapeCreators API key and provide the platforms and research question. Use the API foundation Skill with the research workflow and retain source evidence.
