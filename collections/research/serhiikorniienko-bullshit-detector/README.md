# Bullshit Detector Skills

Extract claims, check their evidence, and publish a sourced assessment.

## Overview

The pack separates ingestion from analysis and publishing for videos, articles, posts, and PDFs, with explicit verdicts and source-backed reports.

## Scenarios

- Fact-check a video or article
- Check a draft before publication

## Usage

Install the bundle and provide the source URL or draft. Configure the ingestion dependencies for that medium, then inspect claim evidence before publishing a report.
