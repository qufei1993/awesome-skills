# AlterLab 学术技能

开展研究、验证引用、分析科学数据并准备学术成果。

## 合集介绍

作者学术包涵盖科学领域、学术数据库、写作、可视化、文档工具、教师工作、方法论与流程编排。

## 适用场景

- 审阅文献并验证引用
- 分析数据并准备论文

## 使用建议

用 alterlab-skill-finder 选择入口，分阶段目标可用 alterflow；配置所选数据库与科学工具，领域上传包和核心 MCP 集成有不同配置方式。
