# AlterLab Academic Skills

Research, verify citations, analyze scientific data, and prepare academic outputs.

## Overview

The author’s academic pack spans scientific domains, scholarly databases, writing, visualization, document tools, faculty work, methodology, and workflow orchestration.

## Scenarios

- Review literature and verify references
- Analyze data and prepare a paper

## Usage

Use alterlab-skill-finder to choose an entry or alterflow for a staged goal. Configure the chosen databases and scientific tools; domain uploads and core MCP integrations have separate setup paths.
