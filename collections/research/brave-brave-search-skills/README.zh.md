# Brave Search API 技能

用 Brave 网络、媒体、新闻与本地搜索数据支撑 Agent 回答。

## 合集介绍

官方包覆盖搜索接口、LLM 上下文、带来源回答、查询清理与 bx CLI，并通过 Goggles 自定义排序。

## 适用场景

- 为有依据回答收集来源内容
- 搜索新闻、媒体与本地地点

## 使用建议

配置 Brave Search API 密钥，为 Agent 安装技能，再选择 bx 或接口专用流程；有来源研究可使用 LLM Context。
