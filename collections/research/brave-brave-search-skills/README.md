# Brave Search API Skills

Ground agent answers with Brave web, media, news, and local-search data.

## Overview

The official pack covers search endpoints, LLM context, cited answers, query cleanup, and the bx CLI, with custom ranking through Goggles.

## Scenarios

- Collect source content for grounded answers
- Search news, media, and local places

## Usage

Configure a Brave Search API key, install the Skills for your agent, and choose bx or an endpoint-specific workflow. Use LLM Context for source-grounded research.
