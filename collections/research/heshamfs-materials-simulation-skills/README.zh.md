# 材料模拟技能

用稳定性检查、收敛研究和可复现流程辅助数值模拟。

## 合集介绍

这套计算材料科学技能覆盖数值方法、模拟编排、HPC 部署、验证、FAIR 数据、故障诊断和本体管理。完整目录同时包含辅助脚本与评估案例。

## 适用场景

- 检查时间步长、网格与求解器收敛
- 准备 SLURM 作业并诊断运行故障
- 整理模拟结果与验证证据

## 使用建议

说明模拟方法、输入以及待诊断或验证的问题。按上游要求准备 Python 环境，再选择 Agent 安装工具或配套 mss CLI。
