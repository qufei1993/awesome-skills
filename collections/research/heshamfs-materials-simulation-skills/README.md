# Materials Simulation Skills

Support numerical simulation with stability checks, convergence studies, and reproducible workflows.

## Overview

This materials-science package spans numerical methods, simulation orchestration, HPC deployment, verification, FAIR data, failure diagnosis, and ontologies. Its complete catalog includes scripts and evaluation cases.

## Scenarios

- Check time steps, meshes, and solver convergence
- Prepare SLURM jobs and diagnose runtime failures
- Package simulation results and verification evidence

## Usage

Describe the simulation, inputs, and failure or validation question. Follow the upstream Python setup and choose an agent installer or the bundled mss CLI.
