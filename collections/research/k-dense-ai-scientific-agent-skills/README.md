# Scientific Agent Skills

Support scientific literature, data analysis, modeling, and research communication.

## Overview

K-Dense’s scientific library spans biology, chemistry, medicine, materials, astronomy, and computational research, with database access and package-specific workflows.

## Scenarios

- Find literature and retrieve scientific database records
- Analyze sequencing, imaging, or experimental data
- Model scientific systems and prepare research outputs

## Usage

Choose the workflow for your scientific question and provide its data. Install the required scientific packages and configure any database credentials listed in the upstream Skill.
