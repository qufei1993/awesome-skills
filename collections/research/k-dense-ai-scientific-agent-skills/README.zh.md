# 科学研究技能合集

协助文献检索、科学数据分析、建模和研究成果表达。

## 合集介绍

K-Dense 的技能库覆盖生物、化学、医学、材料、天文和计算研究，提供数据库访问及针对科学软件包的流程。

## 适用场景

- 查找文献并获取科学数据库记录
- 分析测序、成像或实验数据
- 建立科学模型并整理研究成果

## 使用建议

按科学问题选择流程并提供数据，根据上游技能要求准备科学软件包与数据库访问凭据。
