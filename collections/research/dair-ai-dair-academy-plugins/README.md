# DAIR Academy Plugins

Build learning artifacts, research wikis, and AI study workflows with DAIR Academy’s plugins.

## Overview

The marketplace includes tutoring, courses, survey papers, YouTube notes, research wikis, images, model councils, and X intelligence feeds. Its plugins connect standalone learning artifacts with specialist model and source services.

## Scenarios

- Turn a talk into study notes
- Build a course or research survey
- Maintain a reusable research wiki

## Usage

Add the DAIR Academy marketplace and install the relevant plugin. Follow its service setup: image work uses Gemini, model councils and surveys use Fireworks AI, and X feeds use the official X MCP server.
