# CrossFrame Skill Suite

面向中文结构诊断、公共议题、组织和历史材料开展分析。

![CrossFrame Skill Suite 官方项目封面](<https://raw.githubusercontent.com/xi-kari/crossframe-skill/7c8990f9abd8be35b0f2907c49ef689e42cdd31d/site/assets/readme-hero.svg>)

## 合集介绍

CrossFrame 完整十六技能家族覆盖诊断、追问、对话、辩论、成文、评审、教学、组织、历史，以及独立的 Max 与 ProMax 推演模式。

## 适用场景

- 分析公共或组织问题
- 形成论证和历史文章
- 评审结构推演与证据

## 使用建议

从 crossframe-suite 或明确点名的专项技能开始。ProMax 需要精确点名及 Python 运行依赖，并应保留附带源材料快照和产出记录。
