# CrossFrame Skill Suite

Analyze structures, public questions, organizations, and historical material in Chinese.

![CrossFrame Skill Suite — original project cover](<https://raw.githubusercontent.com/xi-kari/crossframe-skill/7c8990f9abd8be35b0f2907c49ef689e42cdd31d/site/assets/readme-hero.svg>)

## Overview

CrossFrame’s complete sixteen-Skill family spans diagnosis, inquiry, dialogue, debate, essays, reviews, teaching, organizations, history, and independent Max and ProMax reasoning modes.

## Scenarios

- Analyze public or organizational questions
- Develop arguments and historical essays
- Review structural reasoning and evidence

## Usage

Start with crossframe-suite or explicitly name a specialist. ProMax requires exact invocation and its Python runtime dependencies; preserve the supplied source snapshots and artifacts.
