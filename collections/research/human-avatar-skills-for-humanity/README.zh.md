# Skills for Humanity

用结构化推理方法分析决策、激励、系统与复杂问题。

## 合集介绍

s4h 方法层把推理传统转成各公开集群与领域的可检查步骤，可串联决策、事前验尸与激励分析。

## 适用场景

- 分析决策及其失败方式
- 梳理复杂系统中的激励

## 使用建议

通过作者 s4h 包安装并用 /s4h 提出问题，补充事实与约束，让所选方法有具体证据可用。
