# Skills for Humanity

Apply structured reasoning methods to decisions, incentives, systems, and difficult questions.

## Overview

The s4h methods layer turns reasoning traditions into inspectable procedures across its published clusters and domains. Methods can be chained for decisions, premortems, and incentive analysis.

## Scenarios

- Analyze a decision and its failure modes
- Map incentives in a complex system

## Usage

Install with the author’s s4h package and invoke /s4h with the problem. Supply the facts and constraints so the selected methods have concrete evidence to work with.
