# SandBase 技能

研究并交叉核对证据，再应用于营销工作流。

## 合集介绍

SandBase 以 research 与 marketing 作为规范技能组，目录索引定义安装路径，可移植插件镜像主要入口 multi-source-search。

## 适用场景

- 通过独立来源核查主张
- 制作有证据支撑的营销材料

## 使用建议

选择目录条目并使用宿主网络工具；宿主已有搜索时 multi-source-search 无需 SandBase 账号，可选 SandBase MCP 提供模型与 API 工具。
