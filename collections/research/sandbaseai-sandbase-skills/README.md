# SandBase Skills

Research and cross-check evidence, then apply it to marketing workflows.

## Overview

SandBase publishes research and marketing as its canonical Skill groups. The catalog defines installation paths, while the portable plugin mirrors the flagship multi-source-search entry.

## Scenarios

- Fact-check a claim against independent sources
- Develop evidence-based marketing material

## Usage

Choose a catalog entry and use the host’s web tools. Multi-source-search needs no SandBase account when search is available; optional SandBase MCP adds model and API tools.
