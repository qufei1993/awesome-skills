# QuestionPunk Research Skills

Design, check and analyze surveys and research interviews, with tested scripts for the calculations.

## Overview

These 22 skills cover questionnaire design, interview guides and survey analysis. They work on your own files. Skills that perform calculations include standard-library Python scripts and tests. The collection uses the [MIT license](https://github.com/questionpunk/research-skills/blob/668a5d0755adac02ef01c31d306c47b6d3d08f8f/LICENSE).

## Scenarios

- Check a draft questionnaire for leading, loaded and double-barreled questions
- Work out how many responses a survey needs
- Run a Van Westendorp or MaxDiff analysis on exported responses
- Code open-ended answers into themes
- Turn a discussion guide into an AI-moderated interview

## Usage

Install every skill with `npx skills add questionpunk/research-skills`, or one with `--skill <name>`. Skills with a script need Python 3.9 or later. Where a study needs fielding, an optional last step shows how to run it with QuestionPunk's MCP server, and the agent asks before creating or publishing anything.
