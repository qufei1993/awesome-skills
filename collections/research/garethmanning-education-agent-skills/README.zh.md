# 教育 Agent 技能库

用基于教育研究的技能规划教学与学习者互动。

## 合集介绍

Gareth Manning 的技能库覆盖二十个领域，包括课程、评价、记忆、包容性设计、提问、身心状态，以及面向学生的 AI 学习互动，适用于教育者与学习系统开发者。

## 适用场景

- 设计多周教学单元
- 为学习者调整课程与评价
- 引导 AI 辅助学习

## 使用建议

可本地安装或复制 skills 中所需目录，无需构建技能库。作者建议 Hermes 用户先安装适用的小范围技能；托管 MCP 访问需要令牌。
