# Education Agent Skills Library

Plan teaching and learner interactions with evidence-based pedagogical Skills.

## Overview

Gareth Manning’s library covers twenty domains, including curriculum, assessment, memory, inclusive design, questioning, wellbeing, and student-facing AI study interactions. It supports both educators and learning-system builders.

## Scenarios

- Design a multi-week teaching unit
- Adapt lessons and assessments for learners
- Guide AI-assisted study sessions

## Usage

Install locally or copy the needed folders from skills; no build is required for the library. The author recommends a small relevant starter set for Hermes, while hosted MCP access requires a token.
