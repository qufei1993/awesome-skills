# Firecrawl CLI Skills

Search, scrape, crawl, and inspect web and research sources through the Firecrawl CLI.

## Overview

The CLI’s native Skills cover web primitives and source indexes for papers, developer material, and government documents. They use Firecrawl commands to turn selected sources into local text and structured outputs.

## Scenarios

- Collect pages for a research task
- Explore a website before crawling
- Find and inspect papers or developer sources

## Usage

Install and authenticate the Firecrawl CLI, then install its core or index Skills. Build integration and workflow families are maintained in separate author repositories and have their own setup paths.
