# Firecrawl CLI 技能

通过 Firecrawl CLI 搜索、抓取、爬取并检查网络与研究资料。

## 合集介绍

CLI 的原生技能覆盖网络基础操作以及论文、开发资料和政府文件索引，利用 Firecrawl 命令把所选资料转换成本地文本与结构化输出。

## 适用场景

- 为研究任务收集网页
- 爬取前探索网站
- 查找并检查论文或开发资料

## 使用建议

先安装并认证 Firecrawl CLI，再安装基础或索引技能；集成开发与工作流系列由作者的其他仓库维护，并有各自配置方式。
