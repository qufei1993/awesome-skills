# Stipple Agent 技能

核验文档和引用、提取证据并筛查公开信息。

## 合集介绍

Stipple 完整目录通过 API 提供文档检查、引用核验、数据提取、身份材料、招标、负面报道和文本来源评估。

## 适用场景

- 检查报告引用与文档证据
- 提取结构化文档数据
- 研究招标或负面报道

## 使用建议

提供文档、主张或检索背景，并遵循所选 Stipple 端点的输入要求；可选 API 密钥用于账户用量管理。
