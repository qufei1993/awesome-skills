# Stipple Agent Skills

Verify documents and citations, extract evidence, and screen public information.

## Overview

Stipple’s complete catalog covers document checks, citation verification, data extraction, identity packs, tenders, adverse media, and text-origin assessment through its API.

## Scenarios

- Check a report’s citations and document evidence
- Extract structured document data
- Research tenders or adverse media

## Usage

Provide the document, claims, or search context. Follow the selected Stipple endpoint’s input requirements; an optional API key provides account-level metering.
