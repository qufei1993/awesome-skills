# MFS Context Skills

Ingest and retrieve relevant context from code, files, knowledge, and connected sources.

## Overview

MFS’s two official Skills guide context ingestion and discovery through a unified workspace. Research and tag examples are separate demonstrations.

## Scenarios

- Ingest documents and repositories into context
- Find evidence relevant to an agent task

## Usage

Start the MFS server, install mfs-cli, configure server access, and add the Skills. Ingest sources before asking the agent to find context.
