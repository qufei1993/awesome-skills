# MFS 上下文技能

从代码、文件、知识与已连接来源摄取并检索相关上下文。

## 合集介绍

MFS 两个官方技能通过统一工作区引导上下文摄取与发现，研究和标签示例是独立演示。

## 适用场景

- 把文档与仓库摄取为上下文
- 查找 Agent 任务相关证据

## 使用建议

启动 MFS 服务，安装 mfs-cli、配置服务访问并加入技能，先摄取来源，再让 Agent 查找上下文。
