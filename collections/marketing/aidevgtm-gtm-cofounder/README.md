# The GTM Co-Founder

Build a go-to-market plan for a technical product with limited commercial support.

## Overview

The pack takes founders and first GTM hires from an initial brief and roadmap through audience selection, positioning, first users, and ongoing commercial work.

## Scenarios

- Diagnose a developer tool’s GTM gaps
- Plan positioning and first-user acquisition

## Usage

Start with 00-start-here, then 01-strategy-and-roadmap before later Skills. Provide a one-line product brief; each Skill is self-contained without additional dependencies.
