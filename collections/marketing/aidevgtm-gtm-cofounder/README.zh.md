# GTM 商业合伙人技能

为商业支持有限的技术产品建立上市推广计划。

## 合集介绍

技能包引导创始人与首位 GTM 员工，从初始简报和路线图推进到受众选择、定位、首批用户与持续商业工作。

## 适用场景

- 诊断开发工具的 GTM 缺口
- 规划定位与首批用户获取

先使用 00-start-here，再使用 01-strategy-and-roadmap，然后进入后续技能；提供一句产品简报，各技能独立且无额外依赖。
