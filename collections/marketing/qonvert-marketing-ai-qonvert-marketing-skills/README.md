# Qonvert Marketing Skills

Review existing paid search campaigns and prepare one evidence-backed change for approval.

## Overview

Qonvert Marketing AI maintains six open Agent Skills for campaign review, conversion tracking, acquisition, SEO, and connecting marketing sources. The paid search workflow uses spend, recorded conversions, and search terms to prepare a specific recommendation for human review.

## Scenarios

- Review an existing Google Ads or Yandex Direct campaign from a supplied report
- Check a campaign link for missing tracking parameters
- Prioritize an SEO opportunity from a search report
- Connect authorized project sources through Qonvert Connect

## Usage

Load Review existing ad performance in a compatible assistant. Provide a sanitized report with one campaign, one conversion goal, and a complete date range. For a synthetic first run, use a search term that spent $84 over 30 days with zero recorded bookings, then ask for one proposed exclusion and its review criteria. For live data, follow Connect Qonvert, sign in with OAuth, and grant access to the relevant source.
