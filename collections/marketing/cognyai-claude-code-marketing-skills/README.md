# Cogny Marketing Skills

Audit SEO and ads, research competitors, and qualify leads with optional connected data.

## Overview

Cogny’s public pack combines account-free workflows with premium Skills that use managed MCP services for real marketing data.

## Scenarios

- Audit search visibility and advertising
- Research competitors and lead quality

## Usage

Copy the published skills folders or use the installer. Free workflows need no account; premium workflows require a Cogny subscription and their managed MCP setup.
