# Cogny 营销技能

审查 SEO 与广告、研究竞品并筛选潜在客户，可选连接业务数据。

## 合集介绍

Cogny 公开包结合无需账号的流程与使用托管 MCP 服务获取真实营销数据的付费技能。

## 适用场景

- 审查搜索可见性与广告
- 研究竞品与客户质量

## 使用建议

复制正式技能文件夹或使用安装器；免费流程无需账号，付费流程需要 Cogny 订阅及对应托管 MCP 配置。
