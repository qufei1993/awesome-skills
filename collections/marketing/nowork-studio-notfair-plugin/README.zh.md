# NotFair 营销技能合集

审查搜索可见性、调查广告支出并改进连接式营销工作。

## 合集介绍

NotFair 的共享技能入口覆盖 SEO、GEO、分析、付费媒体、内容、WordPress 和 GoHighLevel，可供多种助手使用。

## 适用场景

- 诊断流量下降与搜索问题
- 审查广告活动和无效支出
- 整理内容或连接站点的改进

## 使用建议

安装插件并配置 NotFair MCP 连接。各入口加载对应类别流程，需要保留流程文件与服务访问权限。
