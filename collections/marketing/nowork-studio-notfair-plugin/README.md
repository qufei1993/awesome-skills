# NotFair Marketing Skills

Audit search visibility, investigate ad spend, and improve connected marketing work.

## Overview

NotFair’s shared Skill entry points cover SEO, GEO, analytics, paid media, content, WordPress, and GoHighLevel workflows across supported agent hosts.

## Scenarios

- Diagnose traffic drops and search issues
- Audit campaigns and wasted advertising spend
- Prepare content or connected site improvements

## Usage

Install the plugin and configure the NotFair MCP connection. Each entry point loads its category workflow; keep those workflow files and service access available.
