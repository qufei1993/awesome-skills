# UnifAPI 营销 Agent

通过 UnifAPI 实时公开数据研究营销决策。

## 合集介绍

作者的角色、行业与平台 Agent 覆盖 SEO、AI 可见性、竞争对手、达人、本地业务与社交倾听；工作流用于研究和估算。

## 适用场景

- 审查搜索与 AI 可见性
- 研究竞品与达人报价

## 使用建议

连接 UnifAPI MCP 服务并完成 OAuth，再安装营销技能；按业务问题选择角色或行业 Agent。
