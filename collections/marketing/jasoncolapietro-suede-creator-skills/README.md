# Suede Creator Skills

Coordinate SEO, conversion, business operations, creative work, and software delivery.

![Suede Creator Skills — original project cover](<https://raw.githubusercontent.com/jasoncolapietro/suede-creator-skills/a9bf55ec00fdb9577767db04dc4c9e26bbdc7a61/docs/assets/readme/hero.svg>)

## Overview

Suede’s pack spans business growth and creator work with outcome orchestration, adversarial review, code shipping, design, mobile factories, recovery, and release rights.

## Scenarios

- Audit search visibility and conversion
- Take a creative or software task through review

## Usage

Install the Suede pack and state the business outcome. The author’s installer also supplies fixed orchestration agents; follow its setup for end-to-end workflows.
