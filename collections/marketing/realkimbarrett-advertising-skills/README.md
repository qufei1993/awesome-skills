# Advertising Skills for AI Agents

Structure direct-response advertising, paid media, and conversion copy.

## Overview

Kim Barrett’s system combines advertising foundations, a Copy Chief perspective, an Operator OS, quality checks, and orchestration. It moves from positioning and messaging to campaign execution and feedback.

## Scenarios

- Develop a direct-response advertising angle
- Align funnel copy with positioning
- Review campaign quality before scaling

## Usage

Provide the business, audience, offer, and campaign context, then move through foundations, copy, operations, and QA. The author uses the standard Agent Skills directory layout.
