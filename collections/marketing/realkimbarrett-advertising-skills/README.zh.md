# AI Agent 广告技能库

组织直接响应广告、付费媒体与转化文案。

## 合集介绍

Kim Barrett 的体系整合广告基础、Copy Chief 文案视角、Operator OS、质量检查与流程编排，从定位和信息表达推进到活动执行与反馈。

## 适用场景

- 设计直接响应广告角度
- 让漏斗文案与定位一致
- 扩大投放前检查活动质量

## 使用建议

提供业务、受众、产品方案与活动背景，再依次使用基础、文案、运营和质量检查能力。作者采用标准 Agent Skills 目录布局。
