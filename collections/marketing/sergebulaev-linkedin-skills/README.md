# LinkedIn Marketing Skills

Plan, draft, and review LinkedIn content in a consistent personal voice.

## Overview

Serge Bulaev’s library covers posts, comments, replies, hooks, humanizing, profiles, content planning, repurposing, advocacy, thread monitoring, and engagement analytics.

## Scenarios

- Write and review posts, comments, or replies
- Plan content and analyze audience engagement

## Usage

Install the canonical Skill group and provide your notes and voice context. Publishing uses Publora; configure its connection and approve the draft before publishing.
