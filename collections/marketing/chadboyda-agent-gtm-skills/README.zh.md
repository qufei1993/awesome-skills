# GTM 技能栈

规划定位、定价、外联、获客、留存与收入运营。

## 合集介绍

十八技能包将策略、主动外联、自然获客、付费渠道、增长与运营组织成可复用 GTM 手册。

## 适用场景

- 定义理想客户与外联序列
- 规划发布与留存项目

## 使用建议

安装技能包并提供产品与市场背景，在执行渠道工作前先明确基础定位和定价选择。
