# The GTM Stack

Plan positioning, pricing, outreach, acquisition, retention, and revenue operations.

## Overview

The eighteen-Skill pack organizes strategy, outbound, inbound, paid channels, growth, and operations as reusable go-to-market playbooks.

## Scenarios

- Define an ICP and outreach sequence
- Plan a launch and retention program

## Usage

Install the pack and supply product and market context. Start with the foundational positioning and pricing choices before channel execution.
