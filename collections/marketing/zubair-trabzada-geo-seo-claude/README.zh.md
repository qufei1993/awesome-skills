# GEO SEO Claude 技能合集

审查网站在 AI 搜索中的可见性与准备情况。

## 合集介绍

作者的 GEO 包将主路由与引用价值、爬虫、品牌提及、内容、结构化数据、技术信号和报告审查结合。

## 适用场景

- 审查 AI 搜索可见性与爬虫访问
- 整理优化计划和客户报告

## 使用建议

按上游安装器准备独立 Python 环境与浏览器工具，提供网站地址后使用路由选择审查流程。
