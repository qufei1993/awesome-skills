# GEO SEO Claude Skills

Audit a website’s visibility and readiness for AI search.

## Overview

The author’s GEO package joins a primary router with specialized audits for citability, crawlers, mentions, content, schema, technical signals, and reporting.

## Scenarios

- Audit AI-search visibility and crawler access
- Prepare an optimization plan and client report

## Usage

Run the upstream installer to prepare the isolated Python environment and browser tools. Provide the website URL and use the router for the relevant audit.
