# Linked API LinkedIn 技能

用 Linked API 工具操作 LinkedIn 工作流与增长例行任务。

## 合集介绍

作者将 linkedin 与 linkedin-growth 打包，结合 CLI 账号工作与额外增长运行环境，支持交互和自动化配置。

## 适用场景

- 研究并管理 LinkedIn 工作流
- 运行可重复的增长任务

## 使用建议

用 @linkedapi/skills 安装并检查就绪状态，配置 LinkedIn CLI 与 Linked API；linkedin-growth 还需要包依赖和 doctor 检查。
