# Linked API LinkedIn Skills

Operate LinkedIn workflows and growth routines with Linked API tooling.

## Overview

The author packages linkedin and linkedin-growth with CLI-backed account work and an additional growth runtime, supporting interactive and automated setup.

## Scenarios

- Research and manage a LinkedIn workflow
- Run a repeatable growth routine

## Usage

Use @linkedapi/skills to install and check readiness. Configure LinkedIn CLI and Linked API; linkedin-growth additionally needs its package dependencies and doctor check.
