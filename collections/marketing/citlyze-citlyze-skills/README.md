# Citlyze Agent Skills

Audit pages and analyze brand visibility in AI search.

## Overview

Citlyze’s complete five-Skill package covers page readiness, visibility reports, citation gaps, tracked prompts, and action plans across supported AI search engines.

## Scenarios

- Audit a page for answer extraction
- Compare brand visibility over time
- Identify citation gaps and improvement tasks

## Usage

Use aeo-page-audit for a standalone page review. Reporting and account analysis require the Citlyze MCP connection and the relevant tracked brand or prompt data.
