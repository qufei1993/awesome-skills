# Citlyze Agent 技能

审查网页并分析品牌在 AI 搜索中的可见性。

## 合集介绍

Citlyze 完整五技能包覆盖页面准备度、可见性报告、引用缺口、跟踪提示和行动计划，面向其支持的 AI 搜索引擎。

## 适用场景

- 审查页面是否便于答案提取
- 比较品牌可见性变化
- 识别引用缺口与改进任务

## 使用建议

独立页面评审使用 aeo-page-audit；报告和账户分析需要连接 Citlyze MCP，并提供跟踪品牌或提示数据。
