# Corey Haines Marketing Skills

Run marketing strategy, copy, conversion, and growth workflows with an AI agent.

## Overview

Corey Haines’s marketing library covers acquisition, SEO, campaign creative, conversion, retention, pricing, and revenue operations for software products.

## Scenarios

- Improve landing pages and signup conversion
- Write campaigns and lifecycle email sequences
- Plan launches, SEO, and growth experiments

## Usage

Start with product-marketing context, then ask for the marketing task. Follow the upstream installation guide; local tools, MCP services, and credentials require their own setup.
