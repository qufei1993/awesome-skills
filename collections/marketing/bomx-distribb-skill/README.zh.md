# Distribb SEO 技能

开展 SEO、发布、社交再利用与分阶段九十天增长冲刺。

## 合集介绍

Distribb 技能串联关键词研究、站点审查、主题集群、外链、搜索优化和发布。内部的九十天搜索优化流程按阶段组织这些任务。

## 适用场景

- 审查网站并建立 SEO 路线图
- 运行九十天内容与影响力冲刺

## 使用建议

配置 DISTRIBB_API_KEY，并连接网站与 Search Console；基础技能使用 curl 与 jq，较长项目可按冲刺阶段推进。
