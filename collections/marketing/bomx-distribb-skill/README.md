# Distribb SEO Skills

Run SEO, publishing, social repurposing, and a phased ninety-day growth sprint.

## Overview

The Distribb Skill connects keyword research, audits, topic clusters, backlinks, optimization, and publishing. Its internal 90-day SEO sprint organizes those tasks into stages.

## Scenarios

- Audit a site and build an SEO roadmap
- Run a ninety-day content and authority sprint

## Usage

Configure DISTRIBB_API_KEY and connect the website and Search Console. The basic Skill uses curl and jq; follow the sprint’s phases for a longer program.
