# Ad Video Skills

Produce advertising variants, launch films, and testimonial videos.

![Ad Video Skills — original project cover](<https://raw.githubusercontent.com/iart-ai/ad-video-skills/0de0f2a1c1f42a98103fc0ec436509276428372c/showcase.gif>)

## Overview

This three-Skill iart.ai package turns reusable motion templates and brand assets into advertising creative, product-launch videos, and customer-testimonial clips.

## Scenarios

- Create advertisement variants
- Build a product-launch film
- Turn testimonials into branded clips

## Usage

Provide the brand assets, message, footage, and output placements. Establish a reusable composition, then vary hooks or calls to action and check each exported format.
