# SuperSEO Skills

Research and produce SEO audits, content briefs, articles, and link-building plans.

## Overview

InhouseSEO’s pack starts from one input and researches the needed evidence, covering page quality, keywords, topic clusters, semantic gaps, E-E-A-T, snippets, and expert interviews.

## Scenarios

- Audit a page against competing results
- Prepare and improve an SEO article

## Usage

Install the superseo plugin and provide the page, topic, or target keyword. The author’s workflows fetch research rather than requiring exported datasets or API keys.
