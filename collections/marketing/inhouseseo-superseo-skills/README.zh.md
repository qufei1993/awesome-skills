# SuperSEO 技能

研究并制作 SEO 审查、内容简报、文章与外链计划。

## 合集介绍

InhouseSEO 技能包从一个输入出发研究所需证据，覆盖页面质量、关键词、主题集群、语义缺口、E-E-A-T、摘要与专家访谈。

## 适用场景

- 对照竞争搜索结果审查页面
- 准备并改善 SEO 文章

## 使用建议

安装 superseo 插件并提供页面、主题或目标关键词；作者流程主动获取研究资料，无需先提供导出数据或 API 密钥。
