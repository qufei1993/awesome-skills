# Digital Marketing Pro

Plan and operate multi-brand marketing engagements with shared strategy documents.

## Overview

Indranil Banerjee’s plugin connects brand onboarding, strategy, content, campaigns, measurement, automation, and publication checks. Its engagement flow keeps work tied to four core documents across agency and in-house portfolios.

## Scenarios

- Onboard a new marketing client
- Run SEO and campaign sprints
- Prepare quarterly performance reviews

## Usage

Set up the brand first, then run engagement or select a specific workflow. Use doctor before connector-backed automation and configure the relevant service accounts for API actions.
