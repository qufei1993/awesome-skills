# Digital Marketing Pro

以共享策略文档规划并执行多品牌营销项目。

## 合集介绍

Indranil Banerjee 的插件把品牌接入、策略、内容、活动、衡量、自动化与发布检查串起来；engagement 流程让代理商和企业内部的工作围绕四份核心文档展开。

## 适用场景

- 接入新的营销客户
- 推进 SEO 与营销活动
- 准备季度成效回顾

## 使用建议

先配置品牌，再运行 engagement 或选择具体流程。使用连接器自动化前先运行 doctor，并为 API 操作配置对应服务账号。
