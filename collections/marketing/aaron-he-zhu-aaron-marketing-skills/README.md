# Aaron Marketing Skills

Run coordinated marketing work across narrative, channels, launch, and audit gates.

## Overview

Aaron’s complete library covers brand narrative, SEO/GEO, social, email, paid media, influencers, launches, and a shared protocol with auditor checkpoints.

## Scenarios

- Build a narrative and channel strategy
- Produce and evaluate campaigns
- Coordinate launches and marketing quality reviews

## Usage

Start with the business data and the relevant discipline. Tier 1 works with supplied data; connected tiers, hooks, and bot deployments need the upstream runtime and service setup.
