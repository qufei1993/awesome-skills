# Appeeky App Store Optimization Skills

Research and improve app-store acquisition, conversion, and growth.

## Overview

Appeeky’s library joins keyword and competitor research with metadata, screenshots, icons, localization, reviews, experiments, attribution, and paid acquisition.

## Scenarios

- Improve app listings and discoverability
- Plan store experiments and acquisition campaigns

## Usage

Start with app-marketing-context or aso-router and provide the app’s listing and goals. Configure Appeeky API access for workflows that retrieve store and competitor data.
