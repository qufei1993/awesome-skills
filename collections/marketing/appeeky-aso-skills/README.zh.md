# Appeeky 应用商店优化技能

研究并改善应用商店获客、转化和增长。

## 合集介绍

Appeeky 技能库结合关键词与竞品研究，以及元数据、截图、图标、本地化、评价、实验、归因和付费获客。

## 适用场景

- 改善应用展示与搜索可见性
- 规划商店实验和获客活动

## 使用建议

从 app-marketing-context 或 aso-router 开始，提供应用展示页与目标。需要商店或竞品数据的流程先配置 Appeeky 接口访问。
