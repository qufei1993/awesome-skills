# Developer Marketing Skills

Market technical products through documentation, community, discovery, and developer experience.

## Overview

The author’s library covers foundations, content, community, distribution, growth, competitors, conversion, activation, and retention for developer audiences.

## Scenarios

- Prepare a technical launch and Show HN post
- Improve developer onboarding and activation

## Usage

Install the pack and provide the technical product, audience, and channel context. Use the developer-listening and strategy workflows before choosing outreach or content tactics.
