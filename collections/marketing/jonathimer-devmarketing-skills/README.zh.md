# 开发者营销技能

通过文档、社区、发现渠道与开发者体验推广技术产品。

## 合集介绍

作者库面向开发者受众，涵盖基础、内容、社区、分发、增长、竞品、转化、激活与留存。

## 适用场景

- 准备技术发布与 Show HN 帖子
- 改善开发者接入与激活

## 使用建议

安装技能包并提供技术产品、受众与渠道背景，在选择外联或内容方法前使用开发者倾听与策略流程。
