# Claude SEO Skills

Audit technical SEO, content, structured data, and AI-search readiness.

## Overview

Claude SEO combines its core audit Skills with the author’s optional live-data extensions for SEO services, analytics, crawling, and image generation.

## Scenarios

- Audit a site and prioritize SEO repairs
- Review schema, content quality, and search visibility
- Enrich audits with search and analytics data

## Usage

Install the plugin and run its setup for Python and Chromium. The core works independently; enable an extension only after configuring its required service account and MCP server.
