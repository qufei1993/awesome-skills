# 一人公司技能合集

研究市场并制作小型业务发布所需素材。

## 合集介绍

ReScienceLab 套件为独立创业者提供社交与产品研究、域名选择、品牌图像、发布准备以及 SEO 和 GEO 流程。

## 适用场景

- 研究用户、竞品和产品社区
- 制作品牌素材并准备发布

## 使用建议

安装完整公开 skills 目录并提供产品背景，图像流程依赖 nanobanana 与对应服务设置，研究流程需要文档指定的服务访问。
