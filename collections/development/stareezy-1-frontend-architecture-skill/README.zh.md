# 前端架构技能

结合契约、变更、SEO 与可观测性组织 React 和 React Native 前端。

## 合集介绍

作者的六技能包覆盖功能模块架构、数据契约、乐观变更、SEO、Lighthouse 关卡和前端可观测性，适用于不同框架。

## 适用场景

- 组织前端功能模块
- 设计类型化数据与变更行为
- 检查性能、SEO 和可观测性

## 使用建议

提供应用结构和相关前端流程，结合架构与数据或质量专项指导，需要时准备 Lighthouse 或可观测性工具。
