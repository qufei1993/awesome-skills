# Frontend Architecture Skills

Structure React and React Native frontends with contracts, mutations, SEO, and observability.

## Overview

The author’s six-Skill package covers feature-oriented architecture, data contracts, optimistic mutations, SEO, Lighthouse gates, and frontend observability across frameworks.

## Scenarios

- Organize frontend feature modules
- Design typed data and mutation behavior
- Check performance, SEO, and observability

## Usage

Provide the app structure and relevant frontend workflow. Use the architecture Skill with specialized data or quality guidance and prepare Lighthouse or observability tools when needed.
