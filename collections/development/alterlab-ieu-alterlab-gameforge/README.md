# AlterLab GameForge

Run an indie game project with studio roles, production workflows, and engine specialists.

## Overview

GameForge’s complete package combines eleven studio roles, twenty workflows, and three specialists for Unity, Unreal, and Godot. It supports design, prototyping, playtesting, localization, production planning, and launch.

## Scenarios

- Develop game concepts and design documents
- Prototype and playtest a game
- Plan production, localization, and launch

## Usage

Begin with game-start and a project brief, then follow the workflow for the current phase. Use the engine specialist and upstream project configuration for the chosen engine.
