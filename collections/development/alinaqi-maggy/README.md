# Claude Bootstrap & Maggy Skills

Add test-enforced engineering, persistent context, and model-routing workflows to Claude Code.

## Overview

Claude Bootstrap supplies engineering Skills, hooks, rules, and templates. Maggy adds an optional local harness with a dashboard, protocols, and multi-model orchestration for individual engineers and teams.

## Scenarios

- Enforce testing during feature work
- Preserve context between coding sessions
- Route parallel work across models

## Usage

Start with the author’s Bootstrap installation and add the Maggy server when routing or dashboard features are needed. Configure model connections before using the optional harness.
