# Claude Bootstrap 与 Maggy 技能

为 Claude Code 加入测试约束工程、持久上下文与模型路由工作流。

## 合集介绍

Claude Bootstrap 提供工程技能、Hook、规则与模板；Maggy 是可选本地宿主，加入仪表板、协议和多模型编排，支持个人开发者与团队。

## 适用场景

- 在功能开发中落实测试
- 在编程会话间保留上下文
- 在模型之间分配并行工作

## 使用建议

先按作者方式安装 Bootstrap，需要路由或仪表板时再加入 Maggy 服务；使用可选宿主前配置模型连接。
