# Gemini API 技能合集

开发 Gemini 应用、实时交互和视频流程。

## 合集介绍

Google Gemini 的技能库提供通用生成、实时音视频会话与 Omni Flash 视频任务的接口和 SDK 指导。

## 适用场景

- 接入 Gemini 生成与工具调用
- 开发实时多模态会话
- 通过接口生成或编辑视频

## 使用建议

安装上游插件或技能目录并准备 Gemini 接口访问，说明 SDK 语言、交互模式与媒体输入。
