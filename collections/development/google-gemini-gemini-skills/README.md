# Gemini API Skills

Build Gemini-powered applications, live interactions, and video workflows.

## Overview

Google Gemini’s library provides API and SDK guidance for general generation, real-time audio and video sessions, and Omni Flash video tasks.

## Scenarios

- Integrate Gemini generation and tool calls
- Build a live multimodal session
- Generate or edit video through the API

## Usage

Install the upstream plugin or Skill folders and prepare Gemini API access. Specify the SDK language, interaction mode, and media inputs for the task.
