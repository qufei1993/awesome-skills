# ax Agent 经验技能

通过本地经验图检查会话证据并改进 Agent 工作流。

## 合集介绍

ax 公开技能支持配置、复盘、调优、上下文复用、成本分析与模型分配，把已审阅会话模式转成项目指引。

## 适用场景

- 检查会话中反复出现的错误
- 调整 Agent 指引与模型路由

## 使用建议

配置本地 ax 图并明确请求复盘，应用前审阅建议；发布或分享是独立主动操作。
