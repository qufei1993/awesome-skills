# squirrelscan Audit Skills

Crawl websites and turn SEO, performance, security, and accessibility findings into fixes.

## Overview

The official pack contains squirrelscan and audit-website, combining the audit tool’s rules, health scores, and regression reports with agent workflows.

## Scenarios

- Audit a website before release
- Compare results after a site change

## Usage

Install both Skills or the plugin, then configure the CLI or hosted MCP route. Provide the site URL and inspect the concrete issue report before making changes.
