# squirrelscan 审查技能

爬取网站，把 SEO、性能、安全与无障碍发现转为修复任务。

## 合集介绍

官方包包含 squirrelscan 与 audit-website，把审查工具的规则、健康分数和回归报告与 Agent 工作流结合。

## 适用场景

- 发布前审查网站
- 网站改动后比较结果

## 使用建议

安装两项技能或插件，再配置 CLI 或托管 MCP 方式，提供网站链接并在改动前检查具体问题报告。
