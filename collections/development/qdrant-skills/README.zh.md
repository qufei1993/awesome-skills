# Qdrant 向量搜索技能

为 Qdrant 向量搜索制定架构与性能决策。

## 合集介绍

分层手册涵盖量化、分片、隔离、混合搜索、迁移、扩展、监控与搜索质量，并提供 Qdrant Advisor 发现入口。

## 适用场景

- 诊断缓慢的向量搜索
- 设计扩展与混合搜索

## 使用建议

通过 Advisor 获取 skills.qdrant.tech 在线指引，或安装完整集供离线使用；提供负载规模、症状与部署背景。
