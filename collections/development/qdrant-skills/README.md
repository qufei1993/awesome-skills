# Qdrant Vector Search Skills

Make architecture and performance decisions for Qdrant vector search.

## Overview

The hierarchical handbook covers quantization, sharding, isolation, hybrid search, migrations, scaling, monitoring, and search quality, with a Qdrant Advisor discovery entry.

## Scenarios

- Diagnose slow vector search
- Design scaling and hybrid search

## Usage

Use the Advisor for live guidance from skills.qdrant.tech or install the complete set for offline use. Supply workload size, symptoms, and deployment context.
