# Subagent CLI Skills

Delegate work between coding agents through their headless command-line interfaces.

## Overview

The author’s twenty-four-Skill package teaches a main agent to invoke another vendor’s CLI as a subagent. Each workflow includes delegation and execution guidance for its specific tool.

## Scenarios

- Ask another coding agent for a review
- Delegate a bounded implementation task
- Coordinate agents from different vendors

## Usage

Install and authenticate the target agent CLI before delegation. Give the subagent a bounded task and use the upstream execution rules to inspect its result.
