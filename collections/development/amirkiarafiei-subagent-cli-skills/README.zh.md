# Subagent CLI 技能

通过无界面的命令行模式在编程 Agent 之间委派任务。

## 合集介绍

作者的二十四技能包教主 Agent 调用其他厂商 CLI 作为子 Agent，每个流程提供相应工具的委派与执行指导。

## 适用场景

- 请求另一编程 Agent 评审
- 委派范围明确的实现任务
- 协调不同厂商的 Agent

## 使用建议

委派前安装并认证目标 Agent CLI，提供范围明确的任务，并按上游执行规则检查结果。
