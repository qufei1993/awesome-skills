# Plannotator Review Skills

Review plans, documents, code changes, and visual artifacts with browser annotations.

![Plannotator Review Skills — original project cover](<https://raw.githubusercontent.com/backnotprop/plannotator/545c7afc38bd173abb80070fe5ca5bb65b22c35d/.github/assets/banner.webp>)

## Overview

Plannotator’s canonical core and optional extra Skills cover review, annotation, recent sessions, goal setup, compound planning, and visual explanations.

## Scenarios

- Annotate an agent’s plan or document
- Review code changes and explain implementation plans

## Usage

Install the Plannotator binary and agent integration. Use the matching review or annotation Skill, then send the collected feedback back to the agent.
