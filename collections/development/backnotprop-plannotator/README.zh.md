# Plannotator 审阅技能合集

通过浏览器批注审阅计划、文档、代码变更和视觉产物。

## 合集介绍

Plannotator 的正式核心与可选扩展技能覆盖审查、批注、近期会话、目标设置、组合规划和视觉解释。

## 适用场景

- 批注助手计划或文档
- 审查代码变更并解释实现计划

## 使用建议

安装 Plannotator 程序与助手集成，选择审查或批注技能，再将收集的反馈传回助手。
