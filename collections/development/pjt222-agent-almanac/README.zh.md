# Agent Almanac 登记技能包

整理可执行的开发、研究、数据、运维与专业工作流。

## 合集介绍

按作者 registry 的完整 373 个路径整理，模板及语言、风格镜像保持独立。

## 适用场景

- 选择技术工作流
- 使用专业步骤

## 使用建议

按 registry 选择入口并准备其语言、数据或系统工具，保留引用资料与脚本；registry 不含作者模板。
