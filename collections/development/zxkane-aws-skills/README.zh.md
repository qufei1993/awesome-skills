# Claude Code AWS 技能

设计 AWS 基础设施、运营、无服务器系统与 AI Agent 部署。

## 合集介绍

作者插件覆盖 CDK、SST、成本运营、事件驱动架构与 Bedrock AgentCore，共享 AWS 文档 MCP 配置。

## 适用场景

- 开发 CDK 或 SST 基础设施
- 优化成本并部署 Agent 工作负载

## 使用建议

先安装 aws-common，再安装所需插件；配置 AWS 访问及所选流程要求的 MCP 集成。
