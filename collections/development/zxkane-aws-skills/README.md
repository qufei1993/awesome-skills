# AWS Skills for Claude Code

Design AWS infrastructure, operations, serverless systems, and AI-agent deployments.

## Overview

The author’s plugins cover CDK, SST, cost operations, event-driven architecture, and Bedrock AgentCore, with a shared AWS documentation MCP setup.

## Scenarios

- Build CDK or SST infrastructure
- Optimize costs and deploy agent workloads

## Usage

Install aws-common first, then the relevant plugin. Configure AWS access and the MCP integrations required by the selected workflow.
