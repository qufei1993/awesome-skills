# WGM 与配套技能

将粗略需求转成可用软件，并帮助使用者理解产出。

## 合集介绍

作者完整包包含 wgm 和 teach-me、quiz-me、rugged 三个配套技能，连接需求澄清、规划、实现循环、依据代码的讲解、知识检查与压力检验。

## 适用场景

- 根据粗略需求开发软件
- 学习代码库并检验理解
- 对交付结果做压力检验

## 使用建议

按上游安装方式保留主技能与所有配套技能，提供目标和验收条件，再对产出仓库使用学习或 rugged 流程。
