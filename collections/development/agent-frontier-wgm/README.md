# WGM and Companion Skills

Turn a rough request into working software and help its operator understand the result.

## Overview

The complete author package contains wgm plus teach-me, quiz-me, and rugged companions. It joins request clarification, planning, implementation loops, code-backed teaching, knowledge checks, and stress testing.

## Scenarios

- Develop software from a rough request
- Learn and quiz yourself on a repository
- Stress-test the delivered result

## Usage

Use the upstream installer to retain the main Skill and all companions. Supply the goal and acceptance conditions, then use the learning or rugged workflows against the resulting repository.
