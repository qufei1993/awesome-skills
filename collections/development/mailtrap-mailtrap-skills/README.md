# Mailtrap Skills

Configure, send, test, and manage email through Mailtrap workflows.

## Overview

Mailtrap’s complete seven-Skill package covers API authorization, sending domains, messages, sandbox testing, contacts, and template use or conversion.

## Scenarios

- Set up a sending domain and API access
- Test messages in the Mailtrap sandbox
- Manage templates and contacts

## Usage

Provide the integration environment and email task. Follow the selected Skill’s current Mailtrap documentation and configure the account credentials required for its API.
