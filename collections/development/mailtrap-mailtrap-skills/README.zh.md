# Mailtrap 邮件技能

通过 Mailtrap 流程配置、发送、测试与管理邮件。

## 合集介绍

Mailtrap 完整七技能包覆盖 API 授权、发信域名、邮件、沙箱测试、联系人及模板使用和转换。

## 适用场景

- 配置发信域名与 API 访问
- 在 Mailtrap 沙箱测试邮件
- 管理模板和联系人

## 使用建议

提供集成环境与邮件任务，查阅所选技能关联的当前 Mailtrap 文档，并配置对应 API 凭据。
