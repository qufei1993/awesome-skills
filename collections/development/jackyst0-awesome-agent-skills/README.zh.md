# Awesome Agent Skills 示例包

用作者可安装的示例开展审查、调试、文档、测试与提交工作。

## 合集介绍

本合集保留 JackyST0 的五个本地示例技能作为一个包；仓库还维护外部资源目录，其安装器与手动复制方式分发这些具体示例。

## 适用场景

- 审查并调试改动
- 生成 API 文档与单元测试
- 准备清晰的 Git 提交

## 使用建议

使用作者的已审阅版本安装器，或把示例文件夹复制到 Agent 技能目录；按任务选择示例并提供相关代码或差异。
