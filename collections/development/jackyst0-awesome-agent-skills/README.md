# Awesome Agent Skills Example Pack

Use the author’s installable examples for review, debugging, documentation, tests, and commits.

## Overview

This collection preserves JackyST0’s five local example Skills as one package. The repository also maintains an external directory, while its installer and manual-copy path distribute these concrete examples.

## Scenarios

- Review and debug a change
- Generate API documentation and unit tests
- Prepare a meaningful Git commit

## Usage

Use the author’s reviewed-release installer or copy the example folders to your agent’s Skills directory. Choose the example for the task and supply the relevant code or diff.
