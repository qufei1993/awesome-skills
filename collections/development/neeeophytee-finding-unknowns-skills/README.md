# Finding-Unknowns Skills

Expose blind spots, context gaps, and missing evidence before implementing a change.

![Finding-Unknowns Skills — original project cover](<https://raw.githubusercontent.com/neeeophytee/finding-unknowns-skills/ca5696a0f08d2de6b2997fff1d6cc05c3ed587cc/assets/social-preview.png>)

## Overview

The pack turns task clarification and context-engineering methods into fourteen agent Skills, including evidence extensions and a workflow for proving a bug fix.

## Scenarios

- Find assumptions before planning a feature
- Audit context and prove a bug fix

## Usage

Install the pack, describe the task and available evidence, then choose the relevant unknowns or context pass. The author documents explicit invocation for each supported agent.
