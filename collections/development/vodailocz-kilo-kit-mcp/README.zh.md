# Kilo-Kit 技能 registry

## 合集介绍

保留完整 180 项源 registry，身份依据作者相对路径而非唯一展示名称。

## 适用场景

- 规划实现
- 验证代理任务

## 使用建议

使用 registry 路由时配置作者 Node.js MCP runtime 与记忆服务，保留路径身份及跨目录依赖；尚未验证运行。
