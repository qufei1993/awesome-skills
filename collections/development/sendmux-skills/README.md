# Sendmux Skills

Connect agent email workflows to Sendmux mailboxes, attachments, CLI, and MCP.

## Overview

Sendmux’s complete canonical pack covers onboarding, sending, mailbox agents, attachments, management, MCP setup, and efficient tool use. Separate plugin bundles distribute the same Skills to supported hosts.

## Scenarios

- Set up agent inbox and sending workflows
- Manage messages and attachments
- Connect Sendmux CLI or MCP

## Usage

Follow Sendmux account and tool setup before using a mailbox. Provide the intended email operation and choose CLI or MCP according to the upstream workflow.
