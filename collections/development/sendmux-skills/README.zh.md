# Sendmux 邮件技能

将 Agent 邮件流程连接到 Sendmux 邮箱、附件、CLI 和 MCP。

## 合集介绍

Sendmux 的完整原生包覆盖接入、发送、邮箱 Agent、附件、管理、MCP 配置和高效工具使用；独立插件包向不同宿主分发同一组技能。

## 适用场景

- 配置 Agent 收件与发信流程
- 管理邮件和附件
- 接入 Sendmux CLI 或 MCP

## 使用建议

先按上游方式配置 Sendmux 账号和工具，再说明需要的邮件操作，并按流程选用 CLI 或 MCP。
