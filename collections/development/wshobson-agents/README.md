# Wshobson Agent Workflow Skills

Apply specialized engineering workflows from a multi-agent plugin marketplace.

## Overview

The marketplace groups Skills into native plugins for backend and frontend development, languages, testing, security, infrastructure, and delivery.

## Scenarios

- Implement APIs and language-specific features
- Build testing and review workflows
- Operate infrastructure and delivery pipelines

## Usage

Choose the native plugin for your task and follow its agent’s installation route. Skills-only installs omit the plugin’s agents, commands, hooks, and MCP configuration.
