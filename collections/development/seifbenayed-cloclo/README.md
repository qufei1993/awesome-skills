# Cloclo Project Skill Snapshot

Development, document, and browser workflows from Cloclo’s tracked project skills.

## Overview

Includes all 15 project skills under .claude/skills at the fixed commit; these files are not bundled as the npm runtime’s skill catalog.

## Scenarios

- Review repository changes
- Use browser and document workflows

## Usage

Use these project workflows with the browser, document, and repository tools they declare. This snapshot does not claim to be the npm runtime’s independently shipped skill package.
