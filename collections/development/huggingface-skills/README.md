# Hugging Face Skills

Create datasets, train models, evaluate results, and work with the Hugging Face Hub.

## Overview

Hugging Face’s workflow library covers Hub operations, datasets, training, evaluation, Spaces, local models, papers, and cloud deployment planning.

## Scenarios

- Prepare datasets and fine-tune models
- Evaluate or deploy models and publish research

## Usage

Start with hf-cli and install workflow Skills on demand. Prepare the hf CLI, Hub authentication, and the compute or cloud permissions required by the task.
