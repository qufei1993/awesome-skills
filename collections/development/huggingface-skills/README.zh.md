# Hugging Face 技能合集

制作数据集、训练和评估模型并操作 Hugging Face Hub。

## 合集介绍

Hugging Face 流程库涵盖 Hub、数据集、训练、评估、Spaces、本地模型、论文和云部署规划。

## 适用场景

- 准备数据集并微调模型
- 评估或部署模型并发布研究

## 使用建议

先配置 hf-cli，再按需安装流程技能。准备 hf 命令行工具、Hub 授权以及任务所需计算资源或云权限。
