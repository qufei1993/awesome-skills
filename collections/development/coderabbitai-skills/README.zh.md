# CodeRabbit 技能

通过 CodeRabbit Agent 集成审查代码并应用修复。

## 合集介绍

官方包包含 code-review 与 autofix，通过插件提供给受支持编程 Agent，并以 CodeRabbit CLI 作为执行层。

## 适用场景

- 合并前审查改动
- 应用并验证建议修复

## 使用建议

先安装 CodeRabbit CLI，再加入 Agent 集成；提出审查请求并按提示完成认证，然后使用 autofix。
