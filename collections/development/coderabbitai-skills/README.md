# CodeRabbit Skills

Review code and apply fixes through CodeRabbit’s agent integration.

## Overview

The official pack contains code-review and autofix, with plugin packaging for supported coding agents and the CodeRabbit CLI as the execution layer.

## Scenarios

- Review a change before merging
- Apply and verify suggested fixes

## Usage

Install the CodeRabbit CLI, then add the agent integration. Ask for a review and complete authentication when prompted before using autofix.
