# Reverse Skill Router Pack

Route authorized security research and CTF tasks to specialized analysis workflows.

## Overview

The author’s router combines reverse engineering, penetration testing, case evidence, and a CTF orchestration pack, with tool discovery and repeatable analysis paths.

## Scenarios

- Analyze Android, binaries, or JavaScript behavior
- Investigate authorized penetration-test findings
- Organize CTF work and evidence handoff

## Usage

Follow upstream setup to prepare the router, tool index, and required analysis tools. Define the authorized scope before choosing a scenario and retain its evidence trail.
