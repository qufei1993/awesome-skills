# Reverse Skill 安全路由合集

将授权安全研究和 CTF 任务路由至专项分析流程。

## 合集介绍

作者的路由包整合逆向分析、渗透测试、案件证据和 CTF 编排技能，配套工具发现与可复用分析路径。

## 适用场景

- 分析 Android、二进制或 JavaScript 行为
- 调查授权测试中的安全发现
- 组织 CTF 工作与证据交接

## 使用建议

按上游说明准备路由器、工具索引和分析工具。先明确授权范围，再选择场景并保留证据记录。
