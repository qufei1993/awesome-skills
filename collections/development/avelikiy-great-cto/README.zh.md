# Great CTO 技能

让产品简报通过架构、实现、审查与安全门槛。

## 合集介绍

作者交付体系分配细分 Agent 角色，用另一模型系列检查实现，并记录用户对产品、设计与部署的决定。

## 适用场景

- 从简报开发产品
- 独立验证并审查功能

## 使用建议

为 Claude Code 或 Codex 初始化 Great CTO，配置模型访问并选择门槛等级，提供允许项目路径并审阅必要决策。
