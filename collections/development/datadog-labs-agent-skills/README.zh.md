# Datadog 代理技能源包

整理 Datadog 接入、监控、调查与代理可观测性工作流。

## 合集介绍

保留作者完整技能源文件，以及 README 引用的 Linux、Kubernetes 和产品工作流层次。

## 适用场景

- 调查日志与链路
- 配置可观测性

## 使用建议

按工作流配置 Pup、Datadog 授权及所需 MCP toolsets，保留父技能引用的 Linux 和 Kubernetes 子目录。
