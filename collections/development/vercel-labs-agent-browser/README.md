# Agent Browser Workflow Skills

Automate browser tasks with the workflows bundled in agent-browser.

## Overview

The CLI’s public skill library covers browser control, exploratory testing, Electron, Slack, protected Vercel deployments, sandboxes, and WebMCP workflows.

## Scenarios

- Inspect and operate web applications
- Test an app and capture reproducible browser evidence
- Work with protected deployments or browser sandboxes

## Usage

Install agent-browser and its browser dependencies. Load the matching workflow with skills get; the upstream discovery stub delegates to this versioned CLI content.
