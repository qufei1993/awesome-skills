# Agent Browser 浏览器流程技能

使用 agent-browser 内置流程执行浏览器任务。

## 合集介绍

命令行工具公开的技能库涵盖浏览器控制、探索测试、Electron、Slack、受保护的 Vercel 部署、沙箱和 WebMCP。

## 适用场景

- 检查并操作网页应用
- 测试应用并记录可复现的浏览器证据
- 使用受保护部署或浏览器沙箱

## 使用建议

先安装 agent-browser 和浏览器依赖，再通过 skills get 加载对应流程。上游发现入口会转交给命令行工具所带的版本化内容。
