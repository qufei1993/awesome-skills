# App Store Connect CLI Skills

Ship and manage Apple-platform apps using the asc command-line workflows.

## Overview

Rork’s community package covers builds, TestFlight, metadata, localization, screenshots, signing, submissions, analytics, subscriptions, pricing, and Apple Ads.

## Scenarios

- Prepare signing, builds, and TestFlight distribution
- Localize store metadata and submit a release
- Inspect app analytics and submission health

## Usage

Install asc and the upstream Skill package, then configure App Store Connect access. Use the resolver and CLI guidance to confirm IDs, commands, and release prerequisites before the delivery workflow.
