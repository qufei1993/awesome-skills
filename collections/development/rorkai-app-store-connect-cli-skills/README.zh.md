# App Store Connect 命令行技能

通过 asc 命令行流程发布和管理 Apple 平台应用。

## 合集介绍

Rork 社区包涵盖构建、TestFlight、元数据、本地化、截图、签名、提交、分析、订阅、定价和 Apple Ads。

## 适用场景

- 准备签名、构建和 TestFlight 分发
- 本地化商店信息并提交版本
- 检查应用分析与提交状态

## 使用建议

安装 asc 与上游技能包并配置 App Store Connect 访问，使用标识解析与命令行指导确认标识、命令和版本前提，再开展交付流程。
