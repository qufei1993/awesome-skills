# WordPress 技能合集

依据 WordPress 团队指导开发、审查和管理项目。

## 合集介绍

官方库覆盖项目识别、插件、区块、主题、模式、REST 与 Abilities 接口、Interactivity 接口、性能、测试及运维。

## 适用场景

- 开发 WordPress 插件、区块或主题
- 审查接口集成与站点性能
- 测试和管理 WordPress 项目

## 使用建议

提供 WordPress 项目并由 wordpress-router 选择流程，根据任务准备 PHP 与 Node 工具链、WP-CLI 或 wp-env。
