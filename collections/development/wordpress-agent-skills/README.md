# WordPress Agent Skills

Build, review, and operate WordPress projects with the WordPress team’s guidance.

## Overview

The official library covers project triage, plugins, blocks, themes, patterns, REST and Abilities APIs, the Interactivity API, performance, testing, and operations.

## Scenarios

- Develop WordPress plugins, blocks, or themes
- Review API integration and site performance
- Test and operate a WordPress project

## Usage

Provide the WordPress project and let wordpress-router select the workflow. Prepare the project’s PHP and Node toolchain, WP-CLI, or wp-env as required.
