# Replicate Skills

Find, compare, run, build, and publish models for Replicate-powered applications.

## Overview

The official seven-Skill pack spans model discovery and execution, Cog packaging, releases, and image or video prompting.

## Scenarios

- Choose and integrate an AI model
- Package and publish a custom Cog model

## Usage

Install the pack, configure Replicate access, and choose the model lifecycle stage. Custom model work follows Cog’s configuration and local serving workflow.
