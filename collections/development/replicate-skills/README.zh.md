# Replicate 技能

为 Replicate 应用查找、比较、运行、开发与发布模型。

## 合集介绍

官方七技能包覆盖模型发现与执行、Cog 打包、发布，以及图片或视频提示。

## 适用场景

- 选择并集成 AI 模型
- 打包并发布自定义 Cog 模型

## 使用建议

安装技能包、配置 Replicate 访问，并选择模型生命周期阶段；自定义模型按 Cog 配置与本地服务流程开发。
