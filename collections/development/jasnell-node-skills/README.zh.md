# Node.js 技能合集

使用新版 Node.js 的内置 API，并确认项目运行时支持哪些功能。

## 合集介绍

James M. Snell 的技能合集覆盖 Node.js 的模块加载、内置测试运行器、诊断、SQLite、流、网络及不同版本新增的 API。迁移技能整理了废弃和移除的接口，以及默认行为的变化。

## 适用场景

- 检查已安装的 Node.js 版本是否支持新 API 或实验性 API。
- 迁移使用废弃接口或依赖旧默认行为的代码。
- 使用 `node:test` 编写测试并排查失败原因。
- 评估是否在应用中使用内置工具、SQLite 或流。

## 使用建议

告诉 Agent 项目使用的 Node.js 版本，再按任务选择技能。采用新 API 或实验性 API 前，可以用 `node-experimental-check` 核实目标版本是否支持。
