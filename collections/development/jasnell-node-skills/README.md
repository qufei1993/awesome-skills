# Node.js Skills

Use modern Node.js built-in APIs and check which features your project’s runtime supports.

## Overview

James M. Snell’s collection covers module loading, the built-in test runner, diagnostics, SQLite, streams, networking, and newer APIs across Node.js releases. The migration Skill covers deprecations, removals, and changes to defaults.

## Scenarios

- Check whether a new or experimental API is available in the installed Node.js version.
- Migrate code that uses deprecated APIs or depends on older defaults.
- Write and troubleshoot tests with `node:test`.
- Evaluate built-in utilities, SQLite, or streams for an application.

## Usage

Give the agent your project’s Node.js version and select the Skill for the task. Use `node-experimental-check` before relying on a new or experimental API, and confirm that the target version supports it.
