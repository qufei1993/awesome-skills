# AuraKit Skills

Coordinate coding workflows with Aura modes, compact context, and guard checks.

## Overview

AuraKit’s public Skill package contains aura, aura-compact, and aura-guard. It combines project inspection, planning, implementation, validation, memory, and security checks with a separate installer and hooks.

## Scenarios

- Build or repair a full-stack feature
- Review code and project security
- Manage context and resume project work

## Usage

Use the upstream AuraKit installer to configure its tools and hooks before invoking /aura. The complete workflow uses Node.js, Python, git, and jq.
