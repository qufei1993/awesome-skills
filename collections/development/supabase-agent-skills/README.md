# Supabase Agent Skills

Build Supabase applications and improve PostgreSQL design and performance.

## Overview

Supabase’s official library combines platform workflow guidance with database best practices for queries, schemas, connections, indexes, and security.

## Scenarios

- Develop an application using Supabase
- Review database queries and performance

## Usage

Install both Skills or the corresponding native plugins. Provide the Supabase project context and database evidence, and configure platform access when needed.
