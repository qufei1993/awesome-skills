# Kapso Agent 技能

用 Kapso 开发与运行 WhatsApp 集成和自动化。

## 合集介绍

Alpha 技能包通过 Kapso CLI 与 API 支持 WhatsApp 集成、工作流、可观测性与任务执行。

## 适用场景

- 开发 WhatsApp 工作流
- 诊断集成或执行问题

## 使用建议

优先使用已认证 Kapso CLI；也可配置 KAPSO_API_BASE_URL 与 KAPSO_API_KEY，再按技能使用 API 备用方式。
