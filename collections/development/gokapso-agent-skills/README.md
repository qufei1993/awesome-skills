# Kapso Agent Skills

Build and operate WhatsApp integrations and automations with Kapso.

## Overview

The alpha pack supports WhatsApp integration, workflows, observability, and task execution through Kapso’s CLI and API.

## Scenarios

- Build a WhatsApp workflow
- Diagnose an integration or execution

## Usage

Prefer the authenticated Kapso CLI. Otherwise configure KAPSO_API_BASE_URL and KAPSO_API_KEY, then follow the Skill’s API fallback.
