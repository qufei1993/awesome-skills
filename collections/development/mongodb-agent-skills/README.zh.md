# MongoDB Agent 技能

设计表结构、编写查询并使用 MongoDB 搜索与向量能力。

## 合集介绍

官方规范技能支持 Atlas 与自托管 MongoDB 工作流，产品插件打包副本并配置相应托管或本地 MCP 连接。

## 适用场景

- 检查表结构与查询性能
- 开发 Atlas Search 或 Vector Search

## 使用建议

安装直接技能，或选择使用托管 OAuth 的 mongodb-atlas、使用本地 MCP 的 mongodb，并配置对应部署访问。
