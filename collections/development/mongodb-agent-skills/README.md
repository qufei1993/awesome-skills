# MongoDB Agent Skills

Design schemas, write queries, and use MongoDB search and vector features.

## Overview

The official canonical Skills support Atlas and self-managed MongoDB workflows. Product plugins bundle copies and configure their respective hosted or local MCP connections.

## Scenarios

- Review schema and query performance
- Build Atlas Search or Vector Search

## Usage

Install the direct Skills or choose mongodb-atlas for hosted OAuth and mongodb for a local MCP connection. Configure the appropriate deployment access.
