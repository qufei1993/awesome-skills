# KyberSwap Skills

Query, build, simulate, and manage KyberSwap DeFi operations across EVM chains.

## Overview

The complete sixteen-Skill package covers quotes, tokens, pools, approval, swap construction and execution, simulation, status, limit orders, positions, zaps, and error handling.

## Scenarios

- Inspect swap quotes and token data
- Build and simulate transactions
- Manage limit orders and liquidity positions

## Usage

Specify the chain, tokens, amounts, and wallet context. Use quote and simulation workflows before execution, and follow the upstream wallet and tool setup.
