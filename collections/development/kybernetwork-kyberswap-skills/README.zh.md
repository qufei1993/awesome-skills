# KyberSwap 技能

跨 EVM 链查询、构建、模拟和管理 KyberSwap DeFi 操作。

## 合集介绍

完整十六技能包覆盖报价、代币、池、授权、交换构建与执行、模拟、状态、限价单、头寸、Zap 和错误处理。

## 适用场景

- 查询交换报价与代币数据
- 构建并模拟交易
- 管理限价单和流动性头寸

## 使用建议

明确链、代币、数量和钱包背景，执行前使用报价及模拟流程，并按上游方式配置钱包与工具。
