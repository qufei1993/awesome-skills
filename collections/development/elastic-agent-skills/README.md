# Elastic Agent Skills

Work with Elasticsearch, Kibana, Observability, Security, and Elastic Cloud.

## Overview

Elastic’s official library covers platform administration, search, analytics, monitoring, and security investigations. Product plugins mirror the same canonical Skills.

## Scenarios

- Build Elasticsearch queries and indexes
- Investigate observability and security data

## Usage

Install the cloud and Elasticsearch authentication Skills first, then add those needed for the task. Configure access to your Elastic deployment.
