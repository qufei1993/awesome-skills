# Elastic Agent 技能

操作 Elasticsearch、Kibana、Observability、Security 与 Elastic Cloud。

## 合集介绍

Elastic 官方库涵盖平台管理、搜索、分析、监控和安全调查；产品插件镜像同一规范技能库。

## 适用场景

- 构建 Elasticsearch 查询与索引
- 调查可观测性与安全数据

## 使用建议

先安装 Cloud 与 Elasticsearch 认证技能，再添加任务所需能力，并配置 Elastic 部署访问。
