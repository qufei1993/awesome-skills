# Claude-Mem Plugin Skills

Recall past work and organize coding workflows around persistent agent memory.

## Overview

Claude-Mem’s Claude Code plugin pairs memory search with planning, handoffs, codebase exploration, reporting, and other memory-aware workflows.

## Scenarios

- Recover decisions from earlier coding sessions
- Plan work and hand it to another session
- Explore a codebase and prepare activity reports

## Usage

Install the complete Claude-Mem plugin and worker using the upstream setup. Skill files alone do not register capture hooks or provide the memory service.
