# fp-ts 技能

结合专题指南和快速参考应用实用的函数式 TypeScript 模式。

## 合集介绍

完整 fp-ts 包覆盖组合、代数类型、Option、Either、异步效果、验证、转换、不可变数据、React、后端和重构。

## 适用场景

- 表示可空值和类型化错误
- 组合异步与验证管道
- 重构 React 或后端 TypeScript

## 使用建议

提供现有代码和目标行为。简单问题用快速参考，设计或重构用完整指南，并匹配项目的 fp-ts 版本。
