# fp-ts Skills

Apply practical functional TypeScript patterns with focused guides and quick references.

## Overview

The complete fp-ts package covers composition, algebraic types, Option and Either, asynchronous effects, validation, transformations, immutable data, React, backend work, and refactoring.

## Scenarios

- Model nullable values and typed errors
- Compose asynchronous and validation pipelines
- Refactor React or backend TypeScript

## Usage

Provide the existing code and desired behavior. Use a quick reference for a narrow question or a full pattern guide for design and refactoring; match the project’s fp-ts version.
