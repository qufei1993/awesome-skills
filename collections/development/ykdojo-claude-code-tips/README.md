# YK’s DX Skills

Improve daily coding-agent work with focused development and research helpers.

## Overview

The dx plugin includes GitHub Actions investigation, repository search and partial cloning, handoffs, instruction review, version checks, and web-community summaries.

## Scenarios

- Investigate a failing GitHub Actions run
- Hand off work or find code across repositories
- Fetch and summarize developer discussions

## Usage

Install the upstream dx plugin, then invoke the helper for the current task. Some workflows require GitHub access, Gemini CLI, or local repository mirrors.
