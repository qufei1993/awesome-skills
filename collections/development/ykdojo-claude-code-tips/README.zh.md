# YK 开发体验技能合集

通过开发与研究辅助技能改善助手日常工作。

## 合集介绍

dx 插件提供 GitHub Actions 调查、仓库搜索和部分克隆、任务交接、指令审查、版本检查和开发社区摘要。

## 适用场景

- 调查失败的 GitHub Actions 运行
- 交接任务或跨仓库查找代码
- 提取并总结开发讨论

## 使用建议

安装上游 dx 插件后按任务调用辅助技能。部分流程需要 GitHub 权限、Gemini CLI 或本地仓库镜像。
