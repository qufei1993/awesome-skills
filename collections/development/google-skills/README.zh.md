# Google 产品技能合集

使用 Google 公开技能开发和管理产品与云服务。

## 合集介绍

Google 技能库覆盖云架构、AI 助手、GKE、数据系统、可观测性、安全、广告、分析和开发知识。

## 适用场景

- 设计并部署 Google Cloud 方案
- 排查基础设施、数据和安全问题
- 接入 Google Ads 与 Analytics 接口

## 使用建议

安装公开技能目录后选择对应产品，按流程准备命令行授权、项目权限和必要服务。
