# Google Product Skills

Build and operate applications with Google’s public product and cloud Skills.

## Overview

Google’s library spans Cloud architecture, AI agents, GKE, data systems, observability, security, advertising, analytics, and developer knowledge.

## Scenarios

- Design and deploy Google Cloud solutions
- Diagnose infrastructure, data, and security issues
- Integrate Google Ads and Analytics APIs

## Usage

Install the public Skill directory, then choose the relevant Google product. Prepare CLI authentication, project access, and the services required by its workflow.
