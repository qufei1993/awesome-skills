# ECC 技能合集

让编程助手协同完成规划、测试、审查、记忆管理和领域任务。

## 合集介绍

ECC 将工程流程与语言实践、研究、安全、内容和运营知识放在同一工具库中，本合集保留作者正式的 skills 技能目录。

## 适用场景

- 规划并验证功能实现
- 审查安全问题并排查构建故障
- 复用研究与持久记忆流程

## 使用建议

按上游 ECC 安装流程配置所用助手。钩子、规则、MCP 连接和 Memory Vault 运行时需要分别配置。
