# ECC Skills

Coordinate planning, testing, review, memory, and domain workflows for coding agents.

## Overview

ECC combines reusable engineering workflows with language patterns, research, security, content, and operations knowledge. This collection follows its canonical public skills directory.

## Scenarios

- Plan and verify feature implementation
- Review security and diagnose build failures
- Reuse research and persistent memory workflows

## Usage

Follow the upstream ECC installer for your agent. Hooks, rules, MCP connections, and the Memory Vault runtime have separate setup requirements.
