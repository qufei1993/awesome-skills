# AgentFlow 技能

利用看板、工作 Agent 和质量关卡协调开发。

## 合集介绍

AgentFlow 完整插件包覆盖规格转看板、编排、工作 Agent、健康检查、停止和演示，通过项目管理状态协调工程阶段。

## 适用场景

- 将规格转成看板任务
- 执行并监测开发流水线
- 检查健康状态或停止编排

## 使用建议

准备 Claude Code、受支持的项目管理 MCP 集成和 Git 项目。使用上游完整插件保留提示、约定、工作钩子与质量关卡。
