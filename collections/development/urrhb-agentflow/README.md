# AgentFlow Skills

Coordinate development through a Kanban board with workers and quality gates.

## Overview

AgentFlow’s complete plugin package covers specification-to-board conversion, orchestration, workers, health, stopping, and a demo. It uses project-management state to coordinate engineering stages.

## Scenarios

- Turn a specification into board tasks
- Run and monitor a development pipeline
- Inspect health or stop orchestration

## Usage

Prepare Claude Code, the supported project-management MCP integration, and a Git project. Use the full upstream plugin to retain prompts, conventions, worker hooks, and quality gates.
