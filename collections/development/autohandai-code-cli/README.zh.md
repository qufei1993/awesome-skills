# Autohand 内置技能

用 Autohand 随附 Agent 工作流处理工程、研究与电脑任务。

## 合集介绍

内置包包含架构、头脑风暴、审查、调试、性能、研究、数据科学、扩展开发、目标与工作流发现。

## 适用场景

- 诊断并审查代码改动
- 拆解架构与研究工作

## 使用建议

安装 Autohand 并查看 /skills 目录，按任务选择随附技能；扩展示例与另行生成的项目技能有各自范围。
