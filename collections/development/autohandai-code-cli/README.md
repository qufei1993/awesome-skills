# Autohand Built-in Skills

Use Autohand’s shipped agent workflows for engineering, research, and computer tasks.

## Overview

The built-in pack includes architecture, brainstorming, review, debugging, performance, research, data science, extension building, goals, and workflow discovery.

## Scenarios

- Diagnose and review a code change
- Break down architecture and research work

## Usage

Install Autohand and inspect the /skills catalog. Select a shipped Skill for the task; extension examples and separately generated project Skills have their own scope.
