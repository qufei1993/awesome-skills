# Birdview 架构技能

在修改代码库前检查架构、项目约束与技能兼容性。

## 合集介绍

Birdview 生成独立 HTML，呈现架构与改动范围；专用审查和兼容性入口与主技能配套，以源文件证据说明改动建议及 Agent 指令重叠。

## 适用场景

- 绘制项目架构与约束
- 实现前审查模块边界
- 检查已安装技能的兼容性

## 使用建议

针对项目明确调用 Birdview。birdview-review 依赖主包的引用资料与渲染器，需要配套安装；授权改动前先审阅建议。
