# Birdview Architecture Skills

Inspect architecture, project constraints, and Skill compatibility before changing a codebase.

## Overview

Birdview produces standalone HTML views of architecture and change scope. Its dedicated review and compatibility entries accompany the main Skill, using source evidence to explain proposed changes and overlapping agent instructions.

## Scenarios

- Draw a project’s architecture and constraints
- Review module boundaries before implementation
- Audit installed Skill compatibility

## Usage

Invoke Birdview explicitly for a project. Install birdview-review alongside the complete main bundle because it depends on its references and renderer; review proposals before authorizing changes.
