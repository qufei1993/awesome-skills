# Cavekit Specification Skills Archive

Carry a software change through a durable specification, research, implementation, and checks.

## Overview

Cavekit’s frozen suite keeps work in SPEC.md, with workflows for clarifying ideas, researching facts, reviewing specifications, building, detecting drift, and feeding failures back into the specification.

## Scenarios

- Clarify an uncertain change and write its specification
- Implement the specification and check for drift

## Usage

Install the upstream frozen package and keep SPEC.md and FORMAT.md with the project. Use the full loop when the change warrants it; active development has moved to the author’s related Caveman projects.
