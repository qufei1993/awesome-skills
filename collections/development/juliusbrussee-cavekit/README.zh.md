# Cavekit 规格技能存档

通过持久规格推进软件变更的研究、实现与检查。

## 合集介绍

已冻结的 Cavekit 将工作保存在 SPEC.md 中，提供想法澄清、事实研究、规格审查、实现、漂移检测和失败反馈流程。

## 适用场景

- 澄清不确定变更并编写规格
- 实现规格并检查偏移

## 使用建议

安装上游冻结版本，并在项目中保留 SPEC.md 和 FORMAT.md。按变更规模选择流程，后续开发已转移到作者相关 Caveman 项目。
