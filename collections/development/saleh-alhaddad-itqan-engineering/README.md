# Itqan Engineering Skills

Run a resumable engineering lifecycle with staged decisions and completion evidence.

## Overview

The official Itqan plugin contains twelve Skills for discovery, definition, planning, construction, verification, review, release, design, security, assessment, and learning. Artifacts remain in an engineering workspace.

## Scenarios

- Turn an idea into a specification and plan
- Implement and verify a feature
- Review release readiness and security

## Usage

Invoke the suite explicitly with the project goal. Use engineer for the complete lifecycle or a named phase, and retain the workspace artifacts to resume across sessions.
