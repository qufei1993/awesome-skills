# Itqan 工程技能

通过分阶段决策与完成证据执行可续接的工程流程。

## 合集介绍

Itqan 的官方插件包含十二个技能，覆盖调研、定义、规划、实施、验证、评审、发布、设计、安全、评估和学习。过程产物保存在工程工作区。

## 适用场景

- 将想法转成规格与计划
- 实现并验证功能
- 评审发布条件和安全

## 使用建议

明确点名套件并说明项目目标。完整流程使用 engineer，也可调用特定阶段；保留工作区产出以跨会话续接。
