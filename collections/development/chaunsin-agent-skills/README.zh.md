# Chaunsin 的 Agent 技能

处理数据库、Git、需求、发布评审与内容转换任务。

## 合集介绍

作者十技能包覆盖 Drizzle 迁移冲突、PostgreSQL 和 Redis CLI、Git 堆叠开发、需求访谈、PRD、规格、发布前评审、rclone 与 Hugo 导出。

## 适用场景

- 诊断数据库和迁移流程
- 将需求转成规格
- 评审发布或导出内容

## 使用建议

提供项目文件与操作目标，准备相关 CLI；数据库、存储和发布流程应保留版本与环境信息。
