# Chaunsin’s Agent Skills

Handle database, Git, requirements, release review, and content-conversion tasks.

## Overview

The author’s ten-Skill package covers Drizzle migration conflicts, PostgreSQL and Redis CLIs, stacked Git work, requirements interviews, PRDs, specifications, pre-release review, rclone, and Hugo exports.

## Scenarios

- Diagnose database and migration workflows
- Turn requirements into specifications
- Review releases or export content

## Usage

Provide the project files and desired operation. Prepare the relevant CLI and retain version and environment details when using database, storage, or release workflows.
