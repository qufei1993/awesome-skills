# Weights & Biases Skills

Guide coding agents through W&B experiment analysis, training research, and application tracing.

## Overview

Weights & Biases publishes Skills for project operations, evaluation tables, bounded training trials, Weave instrumentation, and AgentLens tracing. The author labels these public bundles experimental.

## Scenarios

- Analyze training runs and evaluation tables
- Instrument Python or TypeScript agent applications
- Compare bounded training experiments

## Usage

Configure a W&B account and API key through the upstream setup. Check each Skill’s SDK requirements; the README specifies Python and package version floors for its helpers.
