# Weights & Biases 技能

辅助编程 Agent 分析 W&B 实验、开展训练研究并接入应用追踪。

## 合集介绍

Weights & Biases 提供项目操作、评估表、受限训练试验、Weave 插桩和 AgentLens 追踪技能。作者将这些公开技能包标记为实验性。

## 适用场景

- 分析训练运行与评估表
- 为 Python 或 TypeScript Agent 应用添加追踪
- 比较有明确边界的训练实验

## 使用建议

按上游说明配置 W&B 账号与 API 密钥，并检查各技能的 SDK 要求。README 为辅助脚本列出了 Python 和依赖包的最低版本。
