# Weaviate Agent Skills

Build and query AI applications backed by Weaviate.

## Overview

The official pack supplies onboarding, search, and agent-development guidance with scripts and resources for Weaviate workflows.

## Scenarios

- Set up a Weaviate-backed application
- Search collections with source context

## Usage

Install the pack, configure the Weaviate endpoint and credentials, and supply required external model-provider keys. Use the quickstart to verify access.
