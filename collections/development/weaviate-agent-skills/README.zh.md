# Weaviate Agent 技能

开发并查询使用 Weaviate 的 AI 应用。

## 合集介绍

官方包提供接入、搜索与 Agent 开发指引，并附带 Weaviate 流程所需脚本和资源。

## 适用场景

- 配置 Weaviate 应用
- 结合来源背景搜索集合

## 使用建议

安装技能包，配置 Weaviate 地址与凭据，并提供所需外部模型服务密钥；通过 quickstart 验证访问。
