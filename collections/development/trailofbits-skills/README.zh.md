# Trail of Bits 安全技能合集

协助安全分析、漏洞研究和严谨的软件测试。

## 合集介绍

Trail of Bits 将公开技能按原生插件组织，涵盖审计上下文、静态分析、合约、模糊测试、审查和安全开发。

## 适用场景

- 审计源码与智能合约
- 调查漏洞并验证修复
- 编写模糊测试和属性测试

## 使用建议

按授权评估任务安装对应插件并准备分析工具，提供相关源码、规格与测试证据。
