# Trail of Bits Security Skills

Support security analysis, vulnerability research, and rigorous software testing.

## Overview

Trail of Bits groups its public Skills into native plugins for audit context, static analysis, contracts, fuzzing, review, and secure development.

## Scenarios

- Audit source code and smart contracts
- Investigate vulnerabilities and validate repairs
- Build fuzzing and property-based tests

## Usage

Install the plugin for the authorized assessment and prepare its analysis tools. Provide source, specifications, and test evidence for the relevant workflow.
