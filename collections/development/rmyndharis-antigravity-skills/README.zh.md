# Antigravity 技能库

在 Google Antigravity 中应用专项开发、运维、安全和商业流程。

## 合集介绍

作者将 Claude Code 生态中的领域知识、专项助手角色和工作程序整理为统一 Antigravity 技能目录。

## 适用场景

- 实现并排查软件系统
- 审查安全与基础设施运维
- 协调专项助手流程

## 使用建议

通过上游命令行安装，或将完整公开 skills 目录放入所需助手范围。按当前任务激活技能并保留配套资源。
