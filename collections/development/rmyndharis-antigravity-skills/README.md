# Antigravity Skill Vault

Apply specialized development, operations, security, and business workflows in Google Antigravity.

## Overview

The author ports domain knowledge, specialist-agent roles, and workflow procedures from the Claude Code ecosystem into a single Antigravity Skill catalog.

## Scenarios

- Implement and troubleshoot software systems
- Review security and infrastructure operations
- Coordinate specialized agent workflows

## Usage

Install through the upstream CLI or copy the complete public skills directory into the desired agent scope. Activate Skills strategically for the current task and keep their resources available.
