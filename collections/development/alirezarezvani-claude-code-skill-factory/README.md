# Claude Code Skills & Agents Factory

Build reusable Claude Skills, agents, prompts, hooks, and coding commands.

## Overview

The factory’s ready-made Skills support interactive package creation, prompt presets, Claude project instructions, and the Codex CLI bridge, alongside AWS, Microsoft 365, and content research workflows.

## Scenarios

- Create and validate a custom Skill
- Generate Claude Code hooks and commands
- Maintain Claude and Codex project instructions

## Usage

Start with the factory-guide or a ready-made Skill in generated-skills, then validate the output before installation. Prompt Factory is the author’s suggested starting point for role-specific prompts.
