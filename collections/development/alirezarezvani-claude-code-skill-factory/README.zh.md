# Claude Code Skills & Agents Factory

制作可复用的 Claude Skills、Agent、提示词、Hook 与编程命令。

## 合集介绍

工厂的现成技能支持交互式包创建、提示词预设、Claude 项目说明与 Codex CLI 桥接，也包含 AWS、Microsoft 365 和内容研究工作流。

## 适用场景

- 创建并验证自定义 Skill
- 生成 Claude Code Hook 与命令
- 维护 Claude 与 Codex 项目说明

## 使用建议

从 factory-guide 或 generated-skills 中的现成技能开始，安装生成内容前先验证输出。作者建议用 Prompt Factory 生成角色提示词。
