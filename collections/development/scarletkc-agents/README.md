# Scarlet’s Agent Skills

Reuse cross-agent standards and task workflows for everyday development.

## Overview

Scarlet’s repository separates project and user collaboration guidance from a shared Skill library, with resources bundled beside each SKILL.md.

## Scenarios

- Apply shared coding and review practices
- Package guidance for another agent host

## Usage

Use the author’s install prompt or skills CLI to choose a Skill and target agent. Supply project-specific context alongside the general shared standards.
