# Scarlet Agent 技能

在日常开发中复用跨 Agent 标准与任务流程。

## 合集介绍

Scarlet 仓库把项目及用户协作指引与共享技能库分开，各 SKILL.md 旁附带所需资源。

## 适用场景

- 应用共享编程与审查实践
- 为其他 Agent 宿主打包指引

## 使用建议

用作者安装提示词或 skills CLI 选择技能与目标 Agent，并在通用共享标准之外补充项目背景。
