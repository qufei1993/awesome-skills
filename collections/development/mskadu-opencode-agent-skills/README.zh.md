# OpenCode Agent 技能

改善 OpenCode 配置、权限、模型同步与 Git 流程。

## 合集介绍

作者完整五技能包覆盖减少迎合、权限管理、重复任务技能建议、Ollama 同步和 Git 自动化。

## 适用场景

- 审查 OpenCode 权限
- 同步本地 Ollama 模型
- 检查重复工作与 Git 修改

## 使用建议

提供相关 OpenCode 配置或任务历史，审阅拟议设置，使用对应流程时准备 Ollama 或 Git 工具。
