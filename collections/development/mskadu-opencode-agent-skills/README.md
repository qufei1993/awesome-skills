# OpenCode Agent Skills

Improve OpenCode configuration, permissions, model synchronization, and Git workflows.

## Overview

The author’s complete five-Skill package covers anti-sycophancy, permission management, recurring-task Skill suggestions, Ollama synchronization, and Git automation.

## Scenarios

- Audit OpenCode permissions
- Synchronize local Ollama models
- Review recurring work and Git changes

## Usage

Provide the relevant OpenCode configuration or task history. Inspect proposed settings and prepare Ollama or Git tooling when using those workflows.
