# Venice API Skills

Integrate Venice text, media, model routing, authentication, and account APIs.

## Overview

The canonical catalog covers chat, responses, embeddings, images, audio, video, decisions, routing, keys, billing, wallet access, and API error handling.

## Scenarios

- Build a multimodal Venice integration
- Select models and handle API authentication

## Usage

Install the selected folders from a pinned release and configure the applicable authentication mode. Check the Skill’s endpoint status and current API schema before integrating.
