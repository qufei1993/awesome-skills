# Venice API 技能

集成 Venice 文本、媒体、模型路由、认证与账号 API。

## 合集介绍

规范目录覆盖对话、Responses、嵌入、图片、音频、视频、决策、路由、密钥、计费、钱包访问与 API 错误处理。

## 适用场景

- 开发多模态 Venice 集成
- 选择模型并处理 API 认证

## 使用建议

从固定版本安装所选文件夹并配置适用认证方式，集成前检查技能的接口状态与当前 API 结构。
