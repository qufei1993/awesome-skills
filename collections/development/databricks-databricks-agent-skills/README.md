# Databricks AI Tools Skills

Build Databricks apps, jobs, pipelines, serving, and deployment bundles.

## Overview

The canonical library includes stable product guidance and the author’s separately marked experimental additions. Generated agent-specific plugin copies are mirrors of the stable source.

## Scenarios

- Build a data pipeline and deploy its bundle
- Configure Lakebase or model serving

## Usage

Use databricks aitools install and configure workspace authentication. Experimental Skills require the explicit experimental flag and have a lower support and review level.
