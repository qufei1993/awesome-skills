# Databricks AI Tools 技能

开发 Databricks 应用、作业、流水线、模型服务与部署包。

## 合集介绍

规范库包含稳定产品指引及作者单独标记的实验性补充；生成的各 Agent 插件副本镜像稳定源目录。

## 适用场景

- 开发数据流水线并部署其包
- 配置 Lakebase 或模型服务

## 使用建议

使用 databricks aitools install 并配置工作区认证；实验技能需要显式 experimental 参数，其支持与审查标准低于稳定技能。
