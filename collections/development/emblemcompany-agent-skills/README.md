# EmblemAI Agent Skills

Build wallet-native applications and crypto workflows with EmblemAI tools.

## Overview

EmblemAI’s complete Skill package covers framework integration, React, agent wallets, prompt examples, market research, portfolio tracking, token swaps, yield, and token discovery.

## Scenarios

- Integrate wallets into an application
- Research markets and track portfolios
- Prepare swaps or DeFi workflows

## Usage

Configure the EmblemAI tools and account access using the upstream guide. State the chain, wallet, and operation clearly before using a transaction workflow.
