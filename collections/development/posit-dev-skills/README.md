# Posit Agent Skills

Develop R packages, data applications, and open-source projects with Posit’s workflows.

## Overview

The library includes general engineering, GitHub collaboration, open-source releases, r-lib, ggsql, Shiny, Quarto, and Connect deployment guidance.

## Scenarios

- Develop and review an R package
- Publish a Shiny or Quarto project

## Usage

Select a category or Skill with the skills CLI. Posit Assistant and other supported coding agents discover the same author library from their configured Skills directories.
