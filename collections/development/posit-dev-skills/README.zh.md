# Posit Agent 技能

用 Posit 工作流开发 R 包、数据应用与开源项目。

## 合集介绍

本库包括通用工程、GitHub 协作、开源发布、r-lib、ggsql、Shiny、Quarto 与 Connect 部署指引。

## 适用场景

- 开发并审查 R 包
- 发布 Shiny 或 Quarto 项目

## 使用建议

通过 skills CLI 选择类别或技能；Posit Assistant 与其他受支持编程 Agent 从各自配置的技能目录发现同一作者库。
