# Repository Engineering Skills

Keep code review and refactoring aligned with a repository’s existing boundaries.

## Overview

The author’s current public package pairs repo-foundation with repo-native-refactor. It establishes project conventions and contracts, then guides scoped changes using repository-native patterns.

## Scenarios

- Establish repository rules for a session
- Review changes against existing contracts
- Refactor a bounded code area

## Usage

Load the foundation before changing the repository and provide the refactoring goal. Keep acceptance evidence and scope visible; archived evaluation copies are not part of the package.
