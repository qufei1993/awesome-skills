# 仓库工程技能

让代码评审和重构遵循仓库已有边界。

## 合集介绍

作者当前公开包包含 repo-foundation 与 repo-native-refactor：先明确项目约定和契约，再依据仓库已有模式指导限定范围的修改。

## 适用场景

- 为会话建立仓库规则
- 依据既有契约评审修改
- 重构范围明确的代码区域

## 使用建议

修改前加载基础规则并说明重构目标，持续保留验收证据和范围；归档评估副本不属于正式包。
