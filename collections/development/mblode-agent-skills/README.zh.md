# Blode Agent 技能

改善架构、界面质量、写作、审查与软件发布。

## 合集介绍

Blode 将按需流程分成架构、设计、写作、质量、交付与创作，把产品品质与工程交付连接起来。

## 适用场景

- 审查界面与排版质量
- 审查并发布软件改动

## 使用建议

为 Codex 或 Claude Code 安装技能包，选择当前阶段，并提供代码、设计、草稿或发布背景。
