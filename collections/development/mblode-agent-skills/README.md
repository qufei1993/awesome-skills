# Agent Skills by Blode

Improve architecture, interface quality, writing, review, and software releases.

## Overview

Blode groups on-demand workflows into architecture, design, writing, quality, shipping, and authoring, linking product craft to engineering delivery.

## Scenarios

- Audit UI and typography quality
- Review and release a software change

## Usage

Install the pack for Codex or Claude Code and choose the current stage. Supply the code, design, draft, or release context rather than a generic brief.
