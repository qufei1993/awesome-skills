# Superpowers Lab

试用用于重复代码分析、MCP、终端与 Windows 虚拟机的实验性编程 Agent 工具。

## 合集介绍

作者实验室发布四个可用的实验技能，以专项分析和交互执行方式扩展 Claude Code Superpowers。

## 适用场景

- 查找语义重复函数
- 操作交互终端或 Windows 虚拟机

## 使用建议

安装实验室插件并按所选技能配置工具；作者将本包标为实验性，技术迭代时工作流可能变化。
