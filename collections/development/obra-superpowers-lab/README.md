# Superpowers Lab

Try experimental coding-agent tools for duplication analysis, MCP, terminals, and Windows VMs.

## Overview

The author’s lab publishes four functional experimental Skills extending Claude Code Superpowers with specialized analysis and interactive execution techniques.

## Scenarios

- Find semantically duplicate functions
- Work with interactive terminals or a Windows VM

## Usage

Install the lab plugin and follow the chosen Skill’s tool requirements. The author marks this package experimental, so workflows can change as the techniques evolve.
