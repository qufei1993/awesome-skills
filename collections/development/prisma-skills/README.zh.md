# Prisma 开发技能

处理 Prisma 数据库配置、客户端查询、迁移、适配器与 Compute 部署。

## 合集介绍

Prisma 团队的完整仓库包包含 ORM 与 Postgres 配置、CLI 和客户端参考、版本迁移、驱动适配器开发及 Compute 操作，同时保留作者发布的兼容入口。

## 适用场景

- 配置 Prisma ORM 与 Prisma Postgres
- 编写查询并管理数据库迁移
- 规划版本升级或 Compute 部署

## 使用建议

根据应用的 Prisma 版本选用技能。新 ORM 项目会转交给依赖包提供的 Prisma 8 技能；已有 Prisma 6、7 项目仅在明确升级时切换版本。
