# Prisma Skills

Handle Prisma database setup, client queries, migrations, adapters, and Compute deployment.

## Overview

The Prisma team’s complete repository package includes ORM and Postgres setup, CLI and client references, version migrations, driver-adapter implementation, and Compute operations. It retains compatibility entry points shipped by the author.

## Scenarios

- Set up Prisma ORM and Prisma Postgres
- Write queries and manage database migrations
- Plan version upgrades or Compute deployment

## Usage

Match the Skill to the application’s Prisma version. New ORM setup delegates to the package-owned Prisma 8 Skill; existing Prisma 6 or 7 projects keep their version unless an upgrade is requested.
