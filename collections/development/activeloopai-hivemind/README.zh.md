# Hivemind 共享记忆技能

检索团队知识，并将助手工作连接到持久目标和知识图谱。

## 合集介绍

Activeloop 的 Hivemind 将 Deeplake 共享记忆与目标跟踪、图谱流程结合，工作服务负责记录轨迹并整理重复模式。

## 适用场景

- 找回先前会话的决策与模式
- 跟踪目标并探索关联团队知识

## 使用建议

按所用助手安装完整 Hivemind 运行时并配置 Deeplake 访问。所选 Claude Code 目录包含完整记忆、目标和图谱组，其他助手目录属于适配版本。
