# Hivemind Shared Memory Skills

Recall team knowledge and connect agent work to persistent goals and a knowledge graph.

## Overview

Activeloop’s Hivemind package combines shared Deeplake memory with goal tracking and graph workflows, while its worker captures traces and codifies recurring patterns.

## Scenarios

- Recover decisions and patterns from earlier sessions
- Track goals and explore connected team knowledge

## Usage

Install the complete upstream Hivemind runtime for the chosen harness and configure Deeplake access. The selected Claude Code directory contains the full memory, goals, and graph group; other harness directories are adaptations.
