# Atlas 目标约束技能

用明确的目标契约和可复用经验约束 Agent 工作。

## 合集介绍

Atlas 将任务契约与跨会话台账组合起来：契约审查目标偏离及未证实结论，台账将经过确认的经验记录为项目条款。

## 适用场景

- 明确任务目标与完成证据
- 检查实现过程中的范围偏离
- 记录已发现偏差的经验

## 使用建议

为较复杂任务使用 atlas-contract 并提供真实目标。发现偏差后，审阅台账拟议条款再加入 Atlas.md。
