# Atlas Skills

Keep agent work tied to an explicit goal contract and reusable lessons.

## Overview

Atlas pairs a task contract with a cross-session ledger. The contract audits goal drift and unproven claims; the ledger records confirmed lessons as project clauses.

## Scenarios

- Define a task’s goal and completion evidence
- Audit scope drift during implementation
- Record lessons from caught deviations

## Usage

Use atlas-contract for substantial tasks and supply the actual goal. After a deviation is caught, review the proposed ledger clause before adding it to Atlas.md.
