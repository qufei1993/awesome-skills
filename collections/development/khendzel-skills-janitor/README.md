# Skills Janitor

Inspect Skill context costs, duplicates, security, and MCP usage.

## Overview

The six-command pack helps Claude Code and Codex users triage installed capabilities, including interactive keep/delete decisions and duplicate detection.

## Scenarios

- Find unused or duplicate installed Skills
- Review Skill and MCP security

## Usage

Install the pack and review findings before removing an entry. The author marks the project in maintenance mode because newer host tools cover part of the workflow.
