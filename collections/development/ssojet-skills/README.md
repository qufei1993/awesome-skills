# SSOJet Agent Skills

Implement SSOJet authentication, team management, and provisioning in applications.

## Overview

The complete SSOJet catalog combines framework-specific authentication workflows with management guidance. It covers hosted login, OIDC, enterprise identity, and team or SCIM operations.

## Scenarios

- Add authentication to an application
- Integrate enterprise SSO flows
- Manage teams and provisioning

## Usage

Provide the framework, deployment environment, and identity requirements. Configure the SSOJet tenant and application values using the selected integration guide.
