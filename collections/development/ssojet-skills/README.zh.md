# SSOJet Agent 技能

在应用中实现 SSOJet 认证、团队管理和用户预配。

## 合集介绍

SSOJet 完整目录组合各框架认证流程与管理指导，覆盖托管登录、OIDC、企业身份和团队或 SCIM 操作。

## 适用场景

- 为应用添加认证
- 接入企业 SSO 流程
- 管理团队和用户预配

## 使用建议

提供框架、部署环境和身份需求，再按选定集成指南配置 SSOJet 租户及应用参数。
