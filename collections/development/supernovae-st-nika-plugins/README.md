# Nika Plugin Skills

Author, check, debug, migrate, and operate repeatable Nika workflows.

## Overview

The complete coding-agent plugin package includes authoring, debugging, migration, and operating Skills. Nika connects workflow files to pre-run checks, execution, and a read-only oracle service.

## Scenarios

- Write a reusable Nika workflow
- Diagnose and migrate workflow files
- Check and run a planned workflow

## Usage

Install the Nika binary and the upstream coding-agent plugin. Keep its commands, hooks, and oracle configuration available; the standalone Hermes delegation Skill is a separate host surface.
