# Nika 插件技能

编写、检查、调试、迁移和运行可重复的 Nika 流程。

## 合集介绍

完整编程 Agent 插件包包含编写、调试、迁移和运行四个技能，将流程文件连接到运行前检查、执行和只读参考服务。

## 适用场景

- 编写可复用 Nika 流程
- 诊断和迁移流程文件
- 检查并执行已规划流程

## 使用建议

安装 Nika 可执行文件及上游编程 Agent 插件，保留命令、钩子和参考服务配置；独立 Hermes 委派技能属于另一宿主入口。
