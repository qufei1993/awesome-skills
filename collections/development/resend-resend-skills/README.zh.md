# Resend 技能

开发邮件投递、Agent 收件箱与 React 邮件模板。

## 合集介绍

Resend 正式包把 API 和安全收件箱流程，与从作者伴随项目同步的 CLI、React Email 和邮件最佳实践结合。

## 适用场景

- 实现事务邮件
- 创建 Agent 收件箱或 React 邮件

## 使用建议

安装技能或插件并选择邮件任务；托管 MCP 使用 OAuth，直接 API 工作流按对应技能配置服务。
