# QA Skills

Run a testing pipeline with a shared knowledge base and test-type decision matrix.

## Overview

The complete QA framework covers requirements, strategy, cases, review, API and end-to-end testing, exploration, regression, bug analysis, reliability, and testing memory. Its core directory is a required shared dependency.

## Scenarios

- Analyze requirements and write executable cases
- Plan API, end-to-end, and regression testing
- Diagnose defects and assess test reliability

## Usage

Install the complete skills directory together with core to preserve relative references. Start with the qa pipeline or a specific testing task and supply requirements, interfaces, and available evidence.
