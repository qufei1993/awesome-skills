# QA Skills 测试工程技能

通过共享知识库与测试类型决策矩阵执行完整测试流程。

## 合集介绍

完整 QA 框架覆盖需求、策略、用例、评审、接口与端到端测试、探索、回归、缺陷分析、可靠性和测试记忆；core 目录是必须一同安装的共享依赖。

## 适用场景

- 分析需求并编写可执行用例
- 规划接口、端到端和回归测试
- 诊断缺陷并评估测试可靠性

## 使用建议

完整安装 skills 目录并保留 core，避免相对引用断裂。可从 qa 流水线或具体测试任务开始，提供需求、接口和已有证据。
