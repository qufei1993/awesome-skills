# Guard Skills

Review AI-generated code, tests, and documentation before delivery.

## Overview

The focused suite supplies second-pass quality gates for general code, tests, documents, WordPress, and WooCommerce, supported by deeper review references.

## Scenarios

- Review a completed implementation diff
- Check tests, documentation, or WordPress changes

## Usage

Install the upstream package and invoke the relevant guard after implementation. Provide the diff and expected behavior, and resolve its findings before presenting or landing the work.
