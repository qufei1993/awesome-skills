# Ontoly Agent Skills

Analyze JavaScript and TypeScript repositories through a shared Software Graph.

## Overview

Ontoly’s fourteen-Skill package covers onboarding, architecture, configuration, dependencies, dead code, documentation, impact, migration, performance, refactoring, tracing, SDKs, and security.

## Scenarios

- Explore architecture and dependencies
- Assess change impact and refactoring
- Review performance or security

## Usage

Install Ontoly and build a graph for the repository before analysis. Check graph trust and diagnostics, then use the corresponding Skill with the upstream MCP or CLI.
