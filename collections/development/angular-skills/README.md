# Angular Skills

Create and maintain Angular applications with the Angular team’s agent guidance.

## Overview

The official pair covers Angular CLI project setup and application development, including signals, routing, forms, dependency injection, SSR, accessibility, and testing.

## Scenarios

- Scaffold a modern Angular application
- Implement components and reactive data flows
- Review application architecture and tests

## Usage

Use angular-new-app when creating a project, then angular-developer for ongoing code and architecture work. Install with the repository’s documented skills CLI command.
