# Angular 技能

用 Angular 团队的 Agent 指引创建与维护 Angular 应用。

## 合集介绍

官方技能组合涵盖 Angular CLI 项目配置与应用开发，包括信号、路由、表单、依赖注入、SSR、无障碍与测试。

## 适用场景

- 创建现代 Angular 应用骨架
- 实现组件与响应式数据流
- 审查应用架构与测试

## 使用建议

创建项目时使用 angular-new-app，后续代码与架构工作使用 angular-developer，并按仓库说明通过 skills CLI 安装。
