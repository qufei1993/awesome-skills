# Dimillian Development Skills

Improve Apple-platform apps and recurring engineering workflows.

## Overview

The public collection covers SwiftUI, concurrency, iOS debugging, macOS packaging, React performance, GitHub work, release notes, refactors, and multi-agent reviews.

## Scenarios

- Debug and optimize SwiftUI or React apps
- Review changes and coordinate a refactor
- Package macOS apps and prepare App Store notes

## Usage

Place the full folders in the Codex Skills directory. Provide the project, diff, or build environment needed by the selected engineering workflow.
