# Context Engineering Skills

Design agent context, memory, tools, operating loops, and evaluation systems.

## Overview

Muratcan Koylan’s library covers context failures and compression alongside multi-agent architectures, memory, harness engineering, and long-running project workflows.

## Scenarios

- Diagnose context degradation and reduce noise
- Design memory and multi-agent coordination
- Evaluate and improve an agent harness

## Usage

Use the canonical plugin Skills for the agent-system problem at hand. Provide the current context flow, tools, failure evidence, and evaluation criteria.
