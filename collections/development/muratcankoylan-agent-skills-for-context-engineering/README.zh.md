# 上下文工程技能合集

设计助手的上下文、记忆、工具、执行循环和评估体系。

## 合集介绍

Muratcan Koylan 的技能库涵盖上下文失效与压缩，以及多助手架构、记忆、运行框架和长期项目流程。

## 适用场景

- 诊断上下文退化并减少噪声
- 设计记忆与多助手协作
- 评估并改进助手运行框架

## 使用建议

按当前助手系统问题使用正式插件技能，并提供上下文流、工具、失败证据和评估标准。
