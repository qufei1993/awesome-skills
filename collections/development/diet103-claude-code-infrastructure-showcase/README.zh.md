# Claude Code 基础设施技能合集

通过自动技能激活应用真实项目中的工程约定。

## 合集介绍

Diet103 的参考库提供后端、前端、错误跟踪和技能开发指导，并配套激活规则与钩子。

## 适用场景

- 应用 TypeScript 前后端约定
- 配置技能发现和错误跟踪

## 使用建议

将参考基础设施适配到项目并准备钩子依赖。.agents 目录是这组正式 Claude 技能的同步宿主镜像。
