# Sanity Agent Toolkit Skills

Build Sanity content systems from Studio and schema through frontend integration.

## Overview

The official toolkit combines content modeling, development practices, SEO/AEO, experimentation, and onboarding guidance with Sanity project tools.

## Scenarios

- Model content and configure Sanity Studio
- Integrate content with a frontend

## Usage

Install the Skills or Sanity plugin. Configure the MCP server for project access, then follow the Studio/schema, content, and frontend stages.
