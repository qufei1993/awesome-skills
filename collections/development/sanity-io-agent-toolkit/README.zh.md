# Sanity Agent Toolkit 技能

从 Studio 与表结构推进到前端集成，开发 Sanity 内容系统。

## 合集介绍

官方工具包把内容建模、开发实践、SEO/AEO、实验与接入指引同 Sanity 项目工具结合。

## 适用场景

- 建模内容并配置 Sanity Studio
- 将内容与前端集成

## 使用建议

安装技能或 Sanity 插件，为项目访问配置 MCP 服务，再按 Studio/表结构、内容、前端阶段推进。
