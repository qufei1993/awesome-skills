# Crit 审阅技能合集

通过浏览器行内反馈审阅计划、代码变更与运行界面。

![Crit 审阅技能合集 官方项目封面](<https://raw.githubusercontent.com/tomasz-tomczyk/crit/9694e99b6291ee910a541ae3451c62bf622cbc5c/docs/images/demo-overview.png>)

## 合集介绍

Crit 原生 Claude Code 技能组涵盖审阅命令行、交互批注和故事流程，配套本地程序与助手反馈集成。

## 适用场景

- 批注计划或代码差异
- 审阅运行中的应用或静态界面

## 使用建议

安装 Crit 程序和上游 Claude Code 插件，再打开待审材料并将评论传回助手。其他集成目录是不同宿主的适配版本。
