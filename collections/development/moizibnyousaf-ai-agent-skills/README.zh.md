# AI Agent 本地与技能库管理合集

开发软件并管理经过整理的团队技能库。

![AI Agent 本地与技能库管理合集 官方项目封面](<https://repository-images.githubusercontent.com/1118483478/5e0234ef-59d8-4a90-9744-0a57ae2eda21>)

## 合集介绍

作者完整本地技能组结合后端、数据库、文档、研究和验证指导，以及技能发现、整理、共享、审查、更新和迁移。

## 适用场景

- 开展后端或文档开发与审查
- 创建并整理团队技能库
- 更新审查或迁移已安装技能

## 使用建议

通过上游命令行或交互界面维护技能库并安装本地技能。独立上游目录指向外部仓库，不属于这个本地技能包。
