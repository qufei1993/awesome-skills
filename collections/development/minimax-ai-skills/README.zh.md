# MiniMax 技能合集

使用 MiniMax 公开技能开发应用并制作文档与媒体。

## 合集介绍

主技能库覆盖前端、移动开发、着色器、办公文件、视觉分析，以及 MiniMax 图像、视频、语音和音乐流程。

## 适用场景

- 开发网页与移动应用
- 制作文档、演示文稿和生成媒体

## 使用建议

按上游说明安装对应助手版本，准备任务所需的开发环境或文档工具，生成媒体时配置 MiniMax 接口。
