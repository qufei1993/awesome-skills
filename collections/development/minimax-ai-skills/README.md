# MiniMax Skills

Build applications and create documents or media with MiniMax’s public Skills.

## Overview

The main library covers frontend and mobile development, shaders, office files, visual analysis, and MiniMax image, video, voice, and music workflows.

## Scenarios

- Build web and mobile applications
- Create documents, presentations, and generated media

## Usage

Follow the upstream installation for your agent. Prepare the development runtime or document tools required by the task and configure MiniMax API access for generation.
