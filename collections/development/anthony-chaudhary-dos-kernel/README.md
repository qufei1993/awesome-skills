# DOS Kernel Skills

Coordinate agent work and verify delivery claims against repository evidence.

## Overview

The complete Claude plugin Skill pack covers setup, dispatch, replanning, supervision, goal gates, claim witnesses, promotion, statistics, and workflow improvement. DOS provides the underlying verification kernel, hooks, and MCP.

## Scenarios

- Dispatch and supervise agent tasks
- Check claimed work against Git evidence
- Replan stalled work and inspect statistics

## Usage

Install the dos-kernel Python package and initialize it in the working repository. Use the author’s complete plugin for its hooks and MCP connection before running dispatch workflows.
