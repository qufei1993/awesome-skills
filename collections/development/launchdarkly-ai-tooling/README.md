# LaunchDarkly Agent Skills

Manage feature flags, AgentControl, metrics, and release workflows.

## Overview

LaunchDarkly’s public repository catalog covers flag creation, targeting, cleanup, guarded rollout, agent configuration, evaluations, observability, metrics, experiments, and onboarding.

## Scenarios

- Configure and roll out feature flags
- Manage AgentControl configurations and evaluations
- Instrument metrics and investigate releases

## Usage

Connect the upstream LaunchDarkly tools and authenticate the required access. State the project and environment before requesting changes; the repository catalog is broader than its current plugin manifest.
