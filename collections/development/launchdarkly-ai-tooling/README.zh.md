# LaunchDarkly Agent 技能

管理功能开关、AgentControl、指标和发布流程。

## 合集介绍

LaunchDarkly 的公开仓库目录覆盖开关创建、定向、清理、受监控灰度、Agent 配置、评估、可观测性、指标、实验与接入。

## 适用场景

- 配置功能开关并推进灰度
- 管理 AgentControl 配置与评估
- 接入指标并调查发布

## 使用建议

按上游说明连接 LaunchDarkly 工具并完成认证。修改前说明项目和环境；仓库完整目录比当前插件清单更广。
