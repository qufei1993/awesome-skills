# Vibe 工作流技能合集

从研究与产品需求推进到技术设计和验证后的实现。

## 合集介绍

作者的正式流程库覆盖研究、PRD、技术设计、助手上下文、构建、变更、调试、审查、验证和交接。

## 适用场景

- 定义 MVP 与技术设计
- 实现、审查并交接项目工作

## 使用建议

结合保存的项目文档使用上游仅技能安装方式。workflow/skills 是平台副本的来源，应选择适合助手的一份发行版本。
