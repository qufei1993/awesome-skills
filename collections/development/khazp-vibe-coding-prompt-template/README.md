# Vibe Workflow Skills

Move from research and product requirements to technical design and verified implementation.

## Overview

The author’s canonical workflow library covers research, PRDs, technical design, agent context, builds, changes, debugging, review, verification, and handoff.

## Scenarios

- Define an MVP and technical design
- Build, review, and hand off project work

## Usage

Use the upstream skills-only CLI route with saved project documents. The workflow/skills source generates all platform copies, so install one matching distribution.
