# Agent Starter Skills

Bootstrap or retrofit agent-friendly projects with a per-project improvement loop.

## Overview

The toolkit combines project scaffolding, adoption, commits, simplification, reflection, memory promotion, and Skills with enforcement hooks and templates.

## Scenarios

- Bootstrap a new agent-friendly repository
- Improve project rules from recurring feedback

## Usage

Install the plugin for Skills and hooks together, or the standalone Skills pack. Audit existing projects first and review proposed changes before adopting them.
