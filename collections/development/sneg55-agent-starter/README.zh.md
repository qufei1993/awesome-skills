# Agent Starter 技能

通过项目级改进循环创建或改造适合 Agent 协作的项目。

## 合集介绍

工具包把项目骨架、接入、提交、简化、复盘、记忆升级与技能，同约束 Hook 及模板结合。

## 适用场景

- 创建适合 Agent 协作的新仓库
- 根据重复反馈改善项目规则

## 使用建议

通过插件一起安装技能与 Hook，或安装独立技能包；先审查现有项目，再审阅和采用改动建议。
