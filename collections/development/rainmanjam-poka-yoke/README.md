# Poka-Yoke Skills

Turn software hazards and incident lessons into mechanisms that prevent mistakes.

## Overview

The complete eleven-Skill plugin applies mistake-proofing to audits, API design, operations, authorization, UX, data, LLM systems, and guardrails. It also supplies a local hazard detector and shared references.

## Scenarios

- Audit code and APIs for footguns
- Design misuse-resistant interfaces
- Convert incidents into preventive controls

## Usage

Name the desired mode explicitly and provide the target or incident. Use the full upstream plugin to retain sibling references, scripts, and assets; the detector requires Python and Git for diff scans.
