# Archcore 项目上下文技能

把规格、架构决策和分支评审与代码一起保存在 Git 中。

## 合集介绍

Archcore 用 .archcore 项目文档连接初始化、规划、文档编写和评审。四个技能帮助编程 Agent 将实现与已记录的需求、规则及决策对照。

## 适用场景

- 将已有项目规则导入文档
- 准备功能规格与任务计划
- 依据项目上下文评审分支

## 使用建议

按上游方式安装 Archcore CLI 并初始化仓库。功能开发前使用 plan，开发过程中用 document 记录决策，集成前使用 review 检查分支。
