# Spartan AI Toolkit 技能

用工程知识、可配置规则与质量门槛引导 Agent 交付。

## 合集介绍

Spartan 领域技能在完整工具包中支持规格、规划、测试、审查、安全、架构、数据与界面工作。

## 适用场景

- 通过分阶段质量门槛开发功能
- 应用技术栈专用工程标准

## 使用建议

安装工具包，初始化技术栈规则并选择流程入口，按 Agent 配置；生成的 Codex 输出镜像源包。
