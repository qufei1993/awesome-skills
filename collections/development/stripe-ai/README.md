# Stripe Agent Skills

Build and maintain Stripe integrations using Stripe’s current engineering workflows.

## Overview

The official library covers integration practices, documentation, Connect verification, Stripe Apps, project tools, payments, Metronome, and SDK upgrades.

## Scenarios

- Implement a payment or Connect integration
- Upgrade Stripe SDKs and API usage

## Usage

Use the upstream official plugin or portable Skills installation and provide the application context. Configure Stripe authentication and MCP access when the workflow needs account tools.
