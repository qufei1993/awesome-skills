# Unity Agent 调试技能

使用 Jahro 构建结构化 Unity 调试流程。

## 合集介绍

Jahro 的八技能包覆盖配置、日志、运行命令、观察器、快照、生产配置、迁移和排障。

## 适用场景

- 添加结构化 Unity 日志
- 通过命令与观察器检查运行状态
- 配置或排查 Jahro

## 使用建议

提供 Unity 项目和调试问题，先通过配置技能准备支持的 Unity、Jahro 版本，再选择日志、状态检查或生产指导。
