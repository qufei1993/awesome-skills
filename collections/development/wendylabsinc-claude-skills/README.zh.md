# Swift 服务端技能

使用作者的工程指导开发 Swift 服务与 Wendy 集成。

## 合集介绍

Wendy Labs 发布的整仓技能包覆盖 Swift、并发、NIO、数据库驱动、Hummingbird、交付流程以及 Wendy 云端和设备操作；配套 Swift 检查工具将规则落到代码检查中。

## 适用场景

- 实现 Swift 服务与数据库集成
- 评审并发和库设计
- 处理 Wendy 云端与设备部署

## 使用建议

按作者的软链接说明安装完整仓库；需要代码检查时构建 swift-server-lint。审阅生成代码，再按当前任务使用相应 Swift 或 Wendy 主题技能。
