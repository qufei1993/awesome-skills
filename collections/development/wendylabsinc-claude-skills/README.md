# Swift Server Skills

Develop Swift services and Wendy integrations with the author’s shared engineering guidance.

## Overview

Wendy Labs publishes a repository-wide Skill package for Swift, concurrency, NIO, database drivers, Hummingbird, delivery workflows, and Wendy cloud or device operations. A companion Swift linter reinforces the rules.

## Scenarios

- Implement Swift services and database integrations
- Review concurrency and library design
- Work on Wendy cloud and device deployments

## Usage

Follow the author’s symlink setup for the complete repository and build swift-server-lint when using its checks. Review generated code and use the matching Swift or Wendy topic.
