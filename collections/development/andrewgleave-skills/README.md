Improve reasoning, code readability, engineering decisions, and interface writing.

## Overview

This five-Skill package combines critical rationalism, code cleanup, a five-step engineering process, interface copy, and Git-history diagnosis. The root-level folders form the author’s complete public collection.

## Scenarios

- Challenge requirements and simplify engineering work
- Diagnose codebase history and readability
- Review interface wording and reasoning

## Usage

Provide the relevant requirements, interface text, or repository. For navvy, retain Git history so its diagnosis can begin from change patterns before code inspection.
