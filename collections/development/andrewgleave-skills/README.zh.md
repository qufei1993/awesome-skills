# Andrew Gleave 的 Agent 技能

改善推理、代码可读性、工程决策与界面文字。

## 合集介绍

这套五技能包组合了批判理性主义、代码整理、五步工程流程、界面文案和 Git 历史诊断，根目录下的技能文件夹构成作者完整公开合集。

## 适用场景

- 质疑需求并简化工程工作
- 诊断代码库历史与可读性
- 审阅界面措辞和推理过程

## 使用建议

提供相关需求、界面文字或仓库。使用 navvy 时保留 Git 历史，使诊断能够先从变更规律开始。
