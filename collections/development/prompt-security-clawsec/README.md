# ClawSec Security Skills

Inspect agent-runtime security, verify signed advisories, and detect configuration drift.

![ClawSec Security Skills — original project cover](<https://raw.githubusercontent.com/prompt-security/clawsec/c8faf9de88bde1d75d6e08680980f3a546a2cbb9/assets/readme/hero.webp>)

## Overview

Prompt Security’s public package family covers OpenClaw, NanoClaw, Hermes, and Picoclaw, with advisory, audit, integrity, guarded-install, incident-reporting, and release workflows.

## Scenarios

- Audit an agent environment and check advisory intelligence
- Verify artifacts and track configuration drift

## Usage

Choose the package for the runtime and follow its upstream setup. Optional persistent protections have separate activation steps; consult the feature matrix because traffic-guardian packages currently provide specifications rather than runtime proxies.
