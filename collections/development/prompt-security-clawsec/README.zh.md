# ClawSec 安全技能合集

检查助手运行时安全、验证签名通告并发现配置漂移。

## 合集介绍

Prompt Security 公开包覆盖 OpenClaw、NanoClaw、Hermes 和 Picoclaw，提供通告、审查、完整性、安装检查、事件报告和发布流程。

## 适用场景

- 审查助手环境与安全通告
- 验证产物并跟踪配置漂移

## 使用建议

按运行时选择包并遵循上游设置，可选持久保护需单独启用。功能矩阵说明当前流量防护包提供规格，尚未提供运行时代理。
