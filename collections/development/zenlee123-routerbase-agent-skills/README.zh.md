# RouterBase Agent 技能

接入 RouterBase API，并规划模型路由或媒体生成流程。

## 合集介绍

作者完整三技能包覆盖兼容 OpenAI 的 API 迁移、模型选择与降级，以及同步或异步图像、视频和音频生成。

## 适用场景

- 将 SDK 调用迁移到 RouterBase
- 选择模型与降级策略
- 构建媒体生成流程

## 使用建议

提供应用代码及质量、延迟或成本要求，配置服务端 RouterBase 访问，并在使用路由前核对当前模型标识符。
