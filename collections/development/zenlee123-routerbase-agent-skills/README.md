# RouterBase Agent Skills

Integrate RouterBase APIs and plan model routing or media-generation workflows.

## Overview

The author’s complete three-Skill package covers OpenAI-compatible API migration, model selection and fallbacks, and synchronous or asynchronous image, video, and audio generation.

## Scenarios

- Move SDK calls to RouterBase
- Choose models and fallback behavior
- Build media-generation workflows

## Usage

Provide the application code and quality, latency, or cost requirements. Configure server-side RouterBase access and check current model identifiers before using a route.
