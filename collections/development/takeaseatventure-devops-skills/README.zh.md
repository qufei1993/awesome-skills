# Takeaseat DevOps 技能

诊断定时任务、环境差异和 Dockerfile 问题。

## 合集介绍

作者公开仓库包包含 cron-doctor、env-drift-hunter 和 dockerfile-auditor，检查调度陷阱、配置差异、镜像层、缓存及容器安全。

## 适用场景

- 诊断 cron 调度
- 比较环境配置
- 审查 Dockerfile

## 使用建议

提供调度表达式、环境文件或 Dockerfile，安装完整公开 skills 目录；README 提到的其他专业版项目不在此仓库包中。
