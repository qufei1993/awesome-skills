# Takeaseat DevOps Skills

Diagnose cron schedules, environment drift, and Dockerfile problems.

## Overview

The author’s public repository package contains cron-doctor, env-drift-hunter, and dockerfile-auditor. These focused workflows examine scheduling traps, configuration differences, image layers, caching, and container security.

## Scenarios

- Diagnose a cron schedule
- Compare environment configuration
- Audit a Dockerfile

## Usage

Provide the schedule, environment files, or Dockerfile. Install the complete public skills directory; other pro offerings mentioned in the README are not present in this repository package.
