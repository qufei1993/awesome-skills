# Emdash 产品开发技能

通过工程、设计、内容与部署流程协同构建产品。

## 合集介绍

Emdash 作者声明的插件包包含二十三个类别，覆盖简报、架构、实现、验证、品牌、动效、可观测性和 Cloudflare 交付。

## 适用场景

- 将产品简报拆成实现任务
- 开发界面、内容与媒体系统
- 验证和部署 Cloudflare 应用

## 使用建议

从 operating-system 和 goal 技能开始，再按阶段推进。使用上游完整包保留 Agent、命令、参考资料与平台集成。
