# Emdash Skills

Build products through a coordinated engineering, design, content, and deployment playbook.

## Overview

Emdash’s author-declared plugin package contains twenty-three categories, from briefs and architecture to implementation, verification, brand, motion, observability, and Cloudflare delivery.

## Scenarios

- Turn a product brief into implementation slices
- Develop interface, content, and media systems
- Verify and deploy Cloudflare applications

## Usage

Start with the operating-system and goal Skills, then follow the stage-specific workflow. Use the full upstream package for agents, commands, references, and platform integrations.
