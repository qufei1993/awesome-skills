# Logic-Lens 逻辑审查技能

通过执行推演发现行为错误，并解释代码语义差异。

## 合集介绍

Logic-Lens 提供评审、讲解、比较、根因定位、健康报告和检查修复六个技能，按前提、执行路径、偏差、触发条件和补救措施开展分析。

## 适用场景

- 检查代码中的行为错误
- 比较两份实现
- 诊断失败测试与崩溃

## 使用建议

提供代码、预期行为和故障证据。需要命令集成时使用上游插件；仓库开发辅助技能不属于这套六技能包。
