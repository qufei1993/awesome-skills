# Logic-Lens Skills

Trace code execution to find behavioral bugs and explain semantic differences.

## Overview

Logic-Lens publishes six Skills for review, explanation, comparison, root-cause location, health reporting, and audit-and-fix work. Its method follows premises, execution traces, divergence, triggers, and remedies.

## Scenarios

- Review code for behavioral bugs
- Compare two implementations
- Diagnose failing tests and crashes

## Usage

Provide the code, expected behavior, and any failure evidence. Use the upstream plugin for command integration; repository development helpers are separate from this six-Skill package.
