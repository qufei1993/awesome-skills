# DevOps and Security Agent Skills

Build and review infrastructure, delivery systems, and security operations.

## Overview

The author’s native domains cover CI/CD, containers, observability, cloud platforms, networking, databases, AI infrastructure, hardening, secrets, incident work, and compliance.

## Scenarios

- Operate and troubleshoot cloud infrastructure
- Review security controls and delivery pipelines
- Prepare incident, recovery, and compliance workflows

## Usage

Install the complete upstream catalog and provide the target environment. Use the relevant domain workflow with its platform CLI, access permissions, and bundled configuration examples.
