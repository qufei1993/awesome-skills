# DevOps 与安全技能合集

建设和审查基础设施、交付系统与安全运维。

## 合集介绍

作者原生领域涵盖持续集成、容器、可观测性、云平台、网络、数据库、AI 基础设施、加固、凭据、事件处理和合规。

## 适用场景

- 管理并排查云基础设施
- 审查安全控制与交付流水线
- 准备事件、恢复和合规流程

## 使用建议

安装完整上游目录并提供目标环境，结合平台命令行、访问权限和配套配置示例使用相应领域流程。
