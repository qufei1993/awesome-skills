# Callstack React Native 技能合集

依据 Callstack 生产经验开发、测试和迁移 React Native 应用。

## 合集介绍

公开包结合 Callstack 独立技能，以及作者正式测试插件中配套的设备自动化、探索测试和测试编写技能。

## 适用场景

- 改善 React Native 性能、导航和电视端行为
- 在模拟器和设备上测试应用
- 评估并开展原生应用迁移

## 使用建议

使用上游开发、测试或迁移插件并准备原生项目工具链。测试流程需要设备自动化与构建工具，保留作者原包中的依赖。
