# Callstack React Native Skills

Build, test, and migrate React Native applications using Callstack’s production experience.

## Overview

The public package joins standalone Callstack Skills with the device automation, exploratory QA, and testing Skills bundled in its official testing plugin.

## Scenarios

- Improve React Native performance, navigation, and TV behavior
- Test applications on simulators and devices
- Assess and perform a native-app migration

## Usage

Use the upstream building, testing, or migration plugins and prepare the native project toolchain. Testing workflows require their device automation and build tools; keep the author’s bundled dependencies together.
