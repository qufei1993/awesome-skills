# Claude Code Development Workflows

Plan, design, implement, and independently review backend, frontend, and full-stack changes.

## Overview

Shinpr’s workflows connect requirement convergence, design documents, implementation plans, tests, and review. The canonical library contains shared guidance and project-specific recipe Skills used by the author’s workflow plugins.

## Scenarios

- Design a change before implementation
- Build and verify a full-stack feature
- Diagnose a problem with documented evidence

## Usage

Choose the backend, frontend, or full-stack workflow plugin for the project. The author warns against installing dev-skills together with a workflow plugin because shared descriptions duplicate.
