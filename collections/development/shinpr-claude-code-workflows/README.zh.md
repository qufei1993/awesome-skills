# Claude Code 开发工作流

规划、设计、实现并独立审查后端、前端与全栈改动。

## 合集介绍

Shinpr 的工作流连接需求收敛、设计文档、实现计划、测试与审查；规范库包含共享指引和不同项目的流程技能，供作者的工作流插件使用。

## 适用场景

- 实现前设计改动
- 开发并验证全栈功能
- 用文档化证据诊断问题

## 使用建议

按项目选择后端、前端或全栈工作流插件。作者提醒不要把 dev-skills 与工作流插件同时安装，以免共享说明重复。
