# Forge Harness 技能

维护项目规则、验证关卡与可重复的 Agent 工作流。

## 合集介绍

Forge Harness 通过四个作者插件发布四十六个技能，覆盖验证、编排、诊断、经验提取、关卡、发现、模拟和配置；中枢另提供项目轨道与共享 Agent。

## 适用场景

- 将项目接入可复用规则
- 诊断上下文与工作流问题
- 执行质量检查与验证流程

## 使用建议

按上游安装向导配置中枢和插件，并保留共享资源。质量平台使用会话浏览器工具；其中一个关卡需要 Python 与 PyYAML。
