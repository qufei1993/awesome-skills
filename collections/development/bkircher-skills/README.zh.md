# Bkircher 的 CLI 技能

通过专用命令行工具指导编程 Agent 完成工程任务。

## 合集介绍

完整根目录包覆盖 GitHub 评审与故障、提交、测试、浏览器自动化、安全质量工具、Jira、Confluence 和英文编辑。

## 适用场景

- 评审修改并处理 GitHub 反馈
- 调查故障和执行质量检查
- 处理项目跟踪与文档

## 使用建议

开始前配置所需命令行工具和账户访问，保留作者技能目录，并按证据或操作选择流程。
