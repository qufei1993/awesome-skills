# Bkircher’s CLI Skills

Guide coding agents through engineering tasks using focused command-line tools.

## Overview

The complete root-level package covers GitHub reviews and failures, commits, testing, browser automation, security and quality tools, Jira, Confluence, and English editing.

## Scenarios

- Review changes and resolve GitHub feedback
- Investigate failures and run quality checks
- Work with project tracking and documentation

## Usage

Configure the needed command-line tool and its account access before the task. Preserve the author’s Skill folders and choose the workflow matching the evidence or operation.
