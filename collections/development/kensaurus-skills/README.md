# Kenji Skills

Run engineering playbooks for React, Next.js, Supabase, and agent-tool workflows.

## Overview

Kenji’s complete catalog includes 161 general Skills and twelve distinct Cursor-specific Skills. It spans audits, development, testing, shipping, documentation, and IDE tooling, with separate commands, agents, and MCP templates.

## Scenarios

- Develop and verify application changes
- Audit quality, security, and architecture
- Configure Cursor tools and agent workflows

## Usage

Provide the job and project context. Use the upstream installer for commands and integrations; Cursor-specific Skills require Cursor’s corresponding capabilities.
