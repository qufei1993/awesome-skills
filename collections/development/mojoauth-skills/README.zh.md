# MojoAuth Agent 技能

跨应用框架实现托管无密码登录与机器认证。

## 合集介绍

MojoAuth 完整包覆盖 Web、服务端、Android 和 iOS 的 OIDC 托管登录集成，以及机器间客户端凭据认证。

## 适用场景

- 添加托管无密码登录
- 接入移动端或后端 OIDC
- 配置机器间认证

## 使用建议

提供框架与认证需求，按对应集成指南配置 MojoAuth 应用、回调地址和凭据。
