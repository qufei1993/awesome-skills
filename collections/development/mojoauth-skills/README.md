# MojoAuth Agent Skills

Implement hosted passwordless login and machine authentication across application frameworks.

## Overview

MojoAuth’s complete package covers OIDC hosted-page integrations for web, server, Android, and iOS environments plus machine-to-machine client credentials.

## Scenarios

- Add hosted passwordless login
- Integrate mobile or backend OIDC flows
- Configure machine-to-machine authentication

## Usage

Provide the framework and authentication requirements. Configure the MojoAuth application, callback URLs, and credentials using the matching integration guide.
