# AG Kit 技能合集

使用 Antigravity 项目级工程工具包开发应用。

![AG Kit 技能合集 官方项目封面](<https://raw.githubusercontent.com/vudovn/ag-kit/549ba3dc2eb1d40fccb5b6d792eba4101c80cd69/web/public/images/og-image.png>)

## 合集介绍

AG Kit 的原生工作区提供应用构建、架构、测试、部署、安全、编排和游戏开发领域技能。

## 适用场景

- 规划并构建完整应用
- 审查代码、测试、安全和部署
- 协调专项或游戏开发任务

## 使用建议

按上游项目安装器提供完整 .agents 工作区。Antigravity 是作者支持的运行平台，技能配套规则、流程、记忆和钩子。
