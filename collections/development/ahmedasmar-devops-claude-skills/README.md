# DevOps Skills by Ahmed Asmar

Operate infrastructure, Kubernetes, CI/CD, GitOps, costs, and observability.

## Overview

The six-Skill pack groups Terraform and Terragrunt work, incident response, AWS cost review, delivery pipelines, GitOps, and monitoring into documented DevOps workflows.

## Scenarios

- Troubleshoot a Kubernetes incident
- Build delivery and monitoring workflows

## Usage

Install the author’s marketplace and choose the DevOps task. Provide the infrastructure or incident context and configure access to the systems involved.
