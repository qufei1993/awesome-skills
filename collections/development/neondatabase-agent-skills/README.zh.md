# Neon Agent 技能

用 Neon Postgres、认证、分支、存储与 AI 服务开发云后端。

## 合集介绍

官方库涵盖 Neon 后端基础能力与 Agent 平台流程，并提供可移植插件与托管 Neon MCP 连接。

## 适用场景

- 使用 Neon Postgres 分支开发
- 配置后端与 Agent 服务

## 使用建议

安装规范技能或插件并授权 Neon MCP，提供项目背景，再选择数据库、认证、存储或 AI 流程。
