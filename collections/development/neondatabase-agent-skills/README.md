# Neon Agent Skills

Build cloud backends with Neon Postgres, authentication, branches, storage, and AI services.

## Overview

The official library covers Neon backend primitives and agent-platform workflows, with a portable plugin and hosted Neon MCP connection.

## Scenarios

- Develop with Neon Postgres branches
- Configure backend and agent services

## Usage

Install the canonical Skills or plugin and authorize Neon MCP. Provide project context, then select the database, authentication, storage, or AI workflow.
