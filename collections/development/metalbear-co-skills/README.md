# mirrord Agent Skills

Develop local code against Kubernetes state with mirrord workflows.

## Overview

MetalBear’s eleven Skills cover setup, configuration, operators, CI, database branches, Kafka and Temporal queues, preview environments, multi-service sessions, chaos, and header propagation.

## Scenarios

- Connect local development to a cluster
- Isolate databases and queue traffic
- Test multi-service behavior and failures

## Usage

Prepare mirrord and authorized cluster access using the upstream quickstart. Choose the workflow matching the service, traffic filter, and infrastructure needed for the task.
