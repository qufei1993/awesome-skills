# Apollo GraphQL Agent Skills

Design and operate GraphQL schemas, clients, servers, federation, and Apollo tooling.

## Overview

The official library covers GraphOS, Router, Server, Client, mobile SDKs, Rover, operations, connectors, MCP, and supporting Rust and Skill-authoring practices.

## Scenarios

- Design a federated GraphQL graph
- Integrate and troubleshoot an Apollo client

## Usage

Select the relevant Skills with skills CLI or GitHub CLI and configure the Apollo project. Pin a release for a stable workflow; GraphOS Factory downloads its bundled binary on first use.
