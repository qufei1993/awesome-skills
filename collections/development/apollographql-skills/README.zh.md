# Apollo GraphQL Agent 技能

设计并运行 GraphQL 结构、客户端、服务端、联邦与 Apollo 工具。

## 合集介绍

官方库覆盖 GraphOS、Router、Server、Client、移动 SDK、Rover、操作、连接器、MCP，以及配套 Rust 与技能创作实践。

## 适用场景

- 设计联邦 GraphQL 图
- 集成并排查 Apollo 客户端

## 使用建议

通过 skills CLI 或 GitHub CLI 选择相关技能并配置 Apollo 项目，可固定版本以稳定流程；GraphOS Factory 首次使用会下载配套二进制。
