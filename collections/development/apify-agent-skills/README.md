# Apify Agent Skills

Select web-data Actors and build or integrate Apify automation.

## Overview

Apify’s official library covers scraping, Actor development, converting existing code to Actors, integrations, and the retained legacy schema entry point.

## Scenarios

- Extract web data with an existing Actor
- Build and deploy an Actor or product integration

## Usage

Install the upstream plugin and prepare Apify account access and the required runtime. Prefer actor-development for schema work, as the separate schema Skill is deprecated.
