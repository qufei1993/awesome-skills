# Apify 技能合集

选择网页数据 Actor 并开发或接入 Apify 自动化。

## 合集介绍

Apify 官方库涵盖抓取、Actor 开发、现有代码转换、产品集成和保留的旧模式定义入口。

## 适用场景

- 通过现有 Actor 提取网页数据
- 开发部署 Actor 或产品集成

## 使用建议

安装上游插件并准备 Apify 账号访问和运行环境。模式定义优先使用 actor-development，单独模式技能已弃用。
