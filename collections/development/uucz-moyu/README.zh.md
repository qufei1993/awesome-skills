# 摸鱼工程约束技能

把编程 Agent 改动保持在请求范围内，并约束过度工程。

![摸鱼工程约束技能 官方项目封面](<https://raw.githubusercontent.com/uucz/moyu/f276e3cc8a7fba8a71a6aa2180ffb991c138bbc3/assets/hero.svg>)

## 合集介绍

作者规范包包含不同语言版本及轻量、严格变体，宿主专用规则副本是另行镜像。

## 适用场景

- 把错误修复限制在所需范围
- 检查改动中不必要的抽象

## 使用建议

选择适合项目的语言与强度变体，在实际工作环境安装合适的一种，避免指引重叠。
