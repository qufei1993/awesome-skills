# Moyu Engineering Guard Skills

Keep coding-agent changes within the requested scope and control overengineering.

## Overview

The author’s canonical pack includes language editions and lightweight or strict variants of the scope guard. Host-specific rule copies are separate mirrors.

## Scenarios

- Limit a bug fix to its required scope
- Check a change for unnecessary abstraction

## Usage

Choose the language and intensity variant suitable for the project. Install one appropriate variant in a working environment to avoid overlapping guidance.
