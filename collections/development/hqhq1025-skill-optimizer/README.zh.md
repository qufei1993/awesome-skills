# Skill Optimizer

从真实工作挖掘、个性化并通用化 Agent 技能。

## 合集介绍

作者把技能改进分成三个方向：有证据的工作流挖掘、适配个人工具，以及把私有本地技能准备为公开分享包。

## 适用场景

- 从编程历史发现重复工作流
- 把个人技能准备为公开发布包

## 使用建议

按目标选择 miner、personalizer 或 generalizer，提供相关会话证据或技能包并审阅改动。
