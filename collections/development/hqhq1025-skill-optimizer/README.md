# Skill Optimizer

Mine, personalize, and generalize agent Skills from real work.

## Overview

The author splits Skill improvement into three directions: evidence-backed workflow mining, adapting a pack to personal tools, and preparing private local Skills for public sharing.

## Scenarios

- Find repeated workflows in coding history
- Prepare a personal Skill for publication

## Usage

Choose miner, personalizer, or generalizer for the intended direction. Supply the relevant session evidence or Skill package and review the resulting changes.
