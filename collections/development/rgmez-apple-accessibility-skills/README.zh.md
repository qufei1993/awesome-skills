# Apple 无障碍审查技能

审查 SwiftUI、UIKit 和 AppKit 界面的无障碍体验。

## 合集介绍

三个框架专用审查技能检查界面语义、辅助技术行为、导航和文字缩放，给出按严重程度排序的问题与人工验证建议。

## 适用场景

- 审查 SwiftUI 视图
- 检查 UIKit 页面和单元格
- 检查 AppKit 窗口和表格

## 使用建议

选择与框架对应的技能并提供真实页面或代码。按优先级修复，再使用配套清单与辅助技术验证。
