# Apple Accessibility Skills

Audit accessibility in SwiftUI, UIKit, and AppKit interfaces.

## Overview

Three framework-specific auditors check Apple interface semantics, assistive technology behavior, navigation, and text scaling. They produce prioritized findings and manual verification guidance.

## Scenarios

- Audit a SwiftUI view
- Inspect UIKit screens and cells
- Check AppKit windows and tables

## Usage

Choose the auditor matching the framework and supply a real screen or code. Apply prioritized fixes and verify with the companion checklist and relevant assistive technologies.
