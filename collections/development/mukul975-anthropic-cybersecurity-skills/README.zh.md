# 社区网络安全技能合集

使用映射到安全框架的流程开展授权评估与防护。

![社区网络安全技能合集 官方项目封面](<https://raw.githubusercontent.com/mukul975/anthropic-cybersecurity-skills/54a798831d2266a3ca61ce68a7acb80b81160d57/assets/banner.png>)

## 合集介绍

Mukul 的独立社区库涵盖安全运营、取证、应用和云环境测试、威胁分析与合规，并映射到六套安全框架。

## 适用场景

- 调查事件与取证证据
- 评估授权的应用和云环境
- 将安全工作映射到 ATT&CK 和合规框架

## 使用建议

先选择安全领域并明确许可范围，再准备对应技能所需工具。不同流程的依赖以仓库说明为准。
