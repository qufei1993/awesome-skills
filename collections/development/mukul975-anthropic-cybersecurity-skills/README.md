# Community Cybersecurity Skills

Use framework-mapped workflows for authorized security assessment and defense.

## Overview

Mukul’s independent community library covers security operations, forensics, application and cloud testing, threat analysis, and compliance with mappings to six security frameworks.

## Scenarios

- Investigate incidents and forensic evidence
- Assess authorized applications and cloud environments
- Map security work to ATT&CK and compliance frameworks

## Usage

Choose the security domain, define the permitted scope, and prepare the tools listed by the selected Skill. The repository’s prerequisites vary by workflow.
