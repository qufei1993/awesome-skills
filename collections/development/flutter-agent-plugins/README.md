# Flutter Agent Skills

Develop, test, and debug Flutter and Dart applications with the Flutter team’s workflows.

## Overview

The public Skill library covers architecture, responsive layouts, state, widgets, tests, static analysis, package issues, performance, and common Dart tasks.

## Scenarios

- Build and repair Flutter interfaces
- Add tests and investigate runtime problems

## Usage

Use the upstream plugin setup with the Dart and Flutter toolchain and MCP configuration. Provide the project and reproduce the issue before choosing a repair workflow.
