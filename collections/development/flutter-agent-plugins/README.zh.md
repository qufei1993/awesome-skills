# Flutter 技能合集

使用 Flutter 团队流程开发、测试和调试 Flutter 与 Dart 应用。

## 合集介绍

公开技能库涵盖架构、响应布局、状态、组件、测试、静态分析、依赖问题、性能和常见 Dart 任务。

## 适用场景

- 制作并修复 Flutter 界面
- 添加测试并调查运行问题

## 使用建议

按上游插件说明配置 Dart 与 Flutter 工具链和 MCP，提供项目并复现问题后选择修复流程。
