# NVIDIA 技能合集

使用 NVIDIA 软件构建 AI、仿真、机器人与加速计算流程。

## 合集介绍

产品技能目录覆盖 CUDA-X、NeMo、NIM、物理 AI、BioNeMo、RAG、蓝图和平台工具，并提供官方查找插件。

## 适用场景

- 训练、部署或评估 NVIDIA AI 任务
- 开发加速计算与仿真任务
- 构建机器人或领域 AI 流程

## 使用建议

按产品任务选择流程，准备支持的运行环境、硬件和账号权限，执行前查看对应技能的验证与依赖记录。
