# Netlify Context and Tools

Build and operate Netlify applications with focused platform references.

## Overview

Netlify’s canonical package covers functions, edge functions, storage, databases, image delivery, forms, configuration, frameworks, caching, authentication, deployment, access control, agents, and MCP servers.

## Scenarios

- Implement Netlify functions and data services
- Configure framework builds and deploy contexts
- Manage deployments and protected previews

## Usage

Use the upstream Netlify installer for agent-specific placement and updates. Provide the application framework and platform primitive involved; keep each Skill’s reference files with it.
