# Netlify 平台技能

依据平台专题参考构建和运维 Netlify 应用。

## 合集介绍

Netlify 的原生完整包覆盖函数、边缘函数、存储、数据库、图片分发、表单、配置、框架、缓存、认证、部署、访问控制、Agent 与 MCP 服务。

## 适用场景

- 实现 Netlify 函数和数据服务
- 配置框架构建与部署环境
- 管理部署和受保护的预览

## 使用建议

按上游安装器完成 Agent 目录配置和更新，并说明应用框架与涉及的平台能力。保留各技能的配套参考文件。
