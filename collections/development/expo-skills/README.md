# Expo Agent Skills

Build, deploy, upgrade, and debug Expo applications with the Expo team’s workflows.

## Overview

The public suite covers app interfaces, APIs, data, native capabilities, SDK migrations, development clients, and EAS build, updates, hosting, and observability.

## Scenarios

- Build and debug an Expo app
- Upgrade native modules or SDK versions
- Deploy and monitor releases through EAS

## Usage

Use the upstream official plugin or Skills CLI and prepare Expo and EAS CLI access. The experimental plugin’s migration workflow has its own status and requirements.
