# Superpowers · Software Development

Guide coding agents through design, planning, implementation, debugging, and review with reusable development Skills.

## Overview

Superpowers provides 15 composable Skills for software development. This collection includes the repository's complete Skills directory, with its supporting files and cross-Skill references. Tool-specific plugin hooks and integrations remain part of the upstream project.

## Scenarios

- Designing and implementing features
- Debugging and verifying fixes
- Planning work and reviewing changes

## Usage

Start by clarifying requirements with brainstorming, then plan the work and choose inline or subagent implementation. Use testing, debugging, and review Skills as needed. For the official tool-specific plugin setup, follow the source repository's installation guide.
