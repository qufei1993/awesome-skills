# Superpowers · 软件开发

用可组合的开发 Skills，引导编程 Agent 完成设计、规划、实现、调试与评审。

## 合集介绍

Superpowers 提供 15 个可组合的软件开发 Skills。本合集收录仓库的完整技能目录，保留配套文件和技能间引用。各工具的插件启动机制与集成文件仍属于上游项目。

## 适用场景

- 设计与实现新功能
- 调试并验证修复
- 规划任务与评审改动

## 使用建议

先用 brainstorming 澄清需求，再规划工作，选择直接实现或子 Agent 实现。按需要使用测试、调试与评审技能。需要官方针对各工具的插件集成时，按照来源仓库的安装指南操作。
