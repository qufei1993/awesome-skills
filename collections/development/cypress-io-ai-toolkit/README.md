# Cypress AI Toolkit Skills

Author, explain, research, and investigate Cypress tests with official tooling guidance.

## Overview

Cypress publishes five Skills for test writing, suite explanation, documentation lookup, running open-mode sessions, and investigating Cypress Cloud results. The complete skills directory is part of its broader toolkit.

## Scenarios

- Write or repair Cypress tests
- Explain brittle tests and research Cypress behavior
- Investigate local sessions or Cloud failures

## Usage

Start with the test, failure, or documentation question. Use the upstream plugin for bundled configuration; interactive and Cloud workflows need their corresponding Cypress tools.
