# Cypress AI Toolkit 技能

通过官方工具指导编写、讲解、研究和调查 Cypress 测试。

## 合集介绍

Cypress 发布五个技能，覆盖测试编写、测试套件讲解、文档检索、运行中的开发会话和 Cypress Cloud 结果调查；本合集保留工具包的完整 skills 目录。

## 适用场景

- 编写或修复 Cypress 测试
- 分析不稳定测试并查询 Cypress 行为
- 调查本地会话或 Cloud 测试失败

## 使用建议

提供测试代码、失败信息或文档问题。可使用上游插件完成配套配置；交互会话与 Cloud 调查需要相应 Cypress 工具。
