# n8n 工作流技能合集

通过 n8n-mcp 指导构建、验证和运行 n8n 自动化。

## 合集介绍

合集包含工作流模式、节点配置、表达式、JavaScript 与 Python 代码、数据处理、错误恢复、助手节点和自托管。

## 适用场景

- 创建并验证 n8n 工作流
- 调试代码节点和数据转换
- 准备自托管 n8n 实例

## 使用建议

先配置 n8n-mcp 与实例访问，再安装上游插件。路由和验证技能用于选择工具并解决工作流错误。
