# n8n Workflow Skills

Build, validate, and operate n8n automations with n8n-mcp guidance.

## Overview

The collection joins workflow patterns and node configuration with expressions, JavaScript and Python code, data handling, error recovery, agent nodes, and self-hosting.

## Scenarios

- Create and validate an n8n workflow
- Debug code nodes and data transformations
- Prepare a self-hosted n8n instance

## Usage

Configure n8n-mcp and access to your n8n instance, then install the upstream plugin. The router and validation Skills help select tools and resolve workflow errors.
