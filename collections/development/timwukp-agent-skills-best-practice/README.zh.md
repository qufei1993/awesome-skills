# Agentic Skills 最佳实践

使用面向 AWS、DevSecOps、工程角色和技能开发的可移植流程。

## 合集介绍

作者完整正式目录将 AgentCore、Kiro CI 与工程、合规、架构、文档、设计和角色实践组合起来；模板位于正式目录之外。

- 构建 AWS Agent 基础设施
- 建立 CI 评审与验证流程

## 使用建议
