# Comet 工作流技能合集

以明确阶段和评估结果继续长期编程任务。

## 合集介绍

Comet 公开包提供 Native 与 Classic 流程，以及需求、设计、实现、验证、归档、记忆和项目知识支持。

## 适用场景

- 将想法转为受控实现流程
- 继续任务并验证验收结果

## 使用建议

安装 Comet 命令行工具，并在项目中选择 Native、Classic 或两者初始化。保留技能随附运行时与参考资料。
