# Comet Workflow Skills

Resume long-running coding tasks with explicit phases and evaluated outcomes.

![Comet Workflow Skills — original project cover](<https://raw.githubusercontent.com/rpamis/comet/0fd42a02eec42a09c572ac359f79a639a2aeb32f/img/title-log.png>)

## Overview

Comet’s public package contains Native and Classic workflows, requirements, design, implementation, verification, archives, memory, and project knowledge support.

## Scenarios

- Turn an idea into a governed implementation
- Resume a task and verify acceptance results

## Usage

Install the Comet CLI and initialize the project with Native, Classic, or both. Keep its generated runtime and references with the installed Skills.
