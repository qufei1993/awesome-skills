# Cloudflare 技能合集

在 Cloudflare 开发平台上构建和管理应用。

## 合集介绍

Cloudflare 官方库涵盖 Workers、Agents、Durable Objects、Sandbox、Next.js、Turnstile、分析、网络、邮件、性能和部署工具。

## 适用场景

- 开发 Workers 与持久助手系统
- 配置平台服务和部署
- 诊断应用性能或网络问题

## 使用建议

可安装同时提供指导与 Cloudflare MCP 的原生插件，也可使用标准技能。准备 Cloudflare 授权与相关项目配置。
