# Browserbase Skills

Automate browsing, capture evidence, and build browser-powered integrations.

## Overview

Browserbase’s official library covers remote browsing, cloud functions, traces, research, UI testing, prompt optimization, cookie sync, and WebMCP workflows.

## Scenarios

- Test a website and capture browser traces
- Research companies or competitors
- Build browser automations and WebMCP tools

## Usage

Install the official browse CLI and plugin, then configure Browserbase access. Choose a task Skill and preserve traces or session data when the workflow needs them.
