# Browserbase 技能合集

自动操作浏览器、记录证据并构建浏览器集成。

## 合集介绍

Browserbase 官方库涵盖远程浏览、云函数、跟踪记录、研究、界面测试、提示词优化、Cookie 同步和 WebMCP。

## 适用场景

- 测试网站并记录浏览器轨迹
- 研究公司或竞争对手
- 开发浏览器自动化与 WebMCP 工具

## 使用建议

安装官方 browse 命令行工具与插件并配置 Browserbase 访问，按任务选择技能，必要时保留轨迹与会话数据。
