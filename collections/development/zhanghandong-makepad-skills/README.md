# Makepad 2.0 Skills

Build cross-platform Makepad 2.0 interfaces with framework-specific design and implementation guidance.

## Overview

The library covers Makepad application structure, DSL, layout, widgets, events, animation, shaders, themes, vectors, performance, troubleshooting, and migration from 1.x.

## Scenarios

- Build a Makepad 2.0 application
- Implement GPU-rendered interface details
- Migrate a Makepad 1.x project

## Usage

Load makepad-2.0-design-judgment first, then the relevant implementation Skills. Install by adding the repository as a working directory or copying or linking its skills folders.
