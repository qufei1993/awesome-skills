# Makepad 2.0 技能库

以框架专用的设计和实现指引开发跨平台 Makepad 2.0 界面。

## 合集介绍

本库覆盖 Makepad 应用结构、DSL、布局、组件、事件、动画、着色器、主题、矢量、性能、故障排查与 1.x 迁移。

## 适用场景

- 开发 Makepad 2.0 应用
- 实现 GPU 渲染界面细节
- 迁移 Makepad 1.x 项目

## 使用建议

先加载 makepad-2.0-design-judgment，再配合相关实现技能。可把仓库加入工作目录，或复制、链接其中的技能文件夹。
