# Harness Evolver Skills

Diagnose and improve agent prompts, routing, retrieval, and orchestration.

## Overview

Includes the six public harness namespace skills from the author’s plugin; repository development helpers are separate.

Use the author’s plugin setup and keep shared orchestration resources. Preserve harness namespace names while adapting safe installation directories for the host.
