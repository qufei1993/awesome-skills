# 审查技能

用两个模型角色辩论审查发现，并处理 PR 反馈。

## 合集介绍

技能组合将 debate-review 的审查者与质疑者，同 babysit-pr 的验证、阻塞问题修复、回复与后续审查轮次结合。

## 适用场景

- 发布审查前质疑发现
- 解决 PR 审查中的阻塞问题

## 使用建议

安装两项技能，配置受支持编程 Agent 与 gh、glab 或 az 访问；授权发布前可先本地预览审查。
