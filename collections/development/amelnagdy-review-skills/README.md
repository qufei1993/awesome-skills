# Review Skills

Debate review findings and work through pull-request feedback with two model roles.

## Overview

The pair combines debate-review’s reviewer and challenger with babysit-pr’s verification, blocker fixes, replies, and follow-up review rounds.

## Scenarios

- Challenge findings before posting a review
- Resolve review blockers on a pull request

## Usage

Install the two Skills and configure the supported coding agents and gh, glab, or az access. Preview a review locally before authorizing it to be posted.
