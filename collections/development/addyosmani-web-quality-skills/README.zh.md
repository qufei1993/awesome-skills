# 网页质量技能合集

衡量并改善网页性能、无障碍、SEO 和工程质量。

## 合集介绍

Addy Osmani 的跨框架库整合 Lighthouse 审查、Core Web Vitals 分析、无障碍检查和网页最佳实践。

## 适用场景

- 诊断加载缓慢或布局不稳定
- 审查无障碍、SEO 和整体网页质量

## 使用建议

修改前建立测量基线，有 Chrome DevTools MCP 时使用实时审查与性能轨迹，修改后用相同指标验证效果。
