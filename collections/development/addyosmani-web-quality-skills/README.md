# Web Quality Skills

Measure and improve web performance, accessibility, SEO, and engineering quality.

## Overview

Addy Osmani’s framework-independent library combines Lighthouse audits, Core Web Vitals analysis, accessibility checks, and web best practices.

## Scenarios

- Diagnose slow loading or unstable layouts
- Audit accessibility, SEO, and overall web quality

## Usage

Establish measurements before making changes. Use Chrome DevTools MCP when available for live audits and traces, then verify improvements with the same measurements.
