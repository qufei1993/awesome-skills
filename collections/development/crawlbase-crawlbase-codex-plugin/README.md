# Crawlbase Codex Skills

Crawl pages and manage stored results through Crawlbase MCP.

## Overview

The complete Codex plugin Skill package covers HTML, Markdown, screenshots, and storage listing, counting, retrieval, and deletion, including bulk operations.

## Scenarios

- Extract pages as HTML or Markdown
- Capture rendered page screenshots
- Inspect and manage stored crawl results

## Usage

Prepare a Crawlbase account and the tokens needed for static or JavaScript pages. Use the upstream Codex plugin to connect MCP, then specify the URLs or stored-result operation.
