# Crawlbase Codex 技能

通过 Crawlbase MCP 抓取页面并管理存储结果。

## 合集介绍

完整 Codex 插件技能包覆盖 HTML、Markdown、截图以及存储列表、计数、读取、删除和批量操作。

## 适用场景

- 将页面提取为 HTML 或 Markdown
- 捕获渲染页面截图
- 查看和管理已存抓取结果

## 使用建议

准备 Crawlbase 账号和静态或 JavaScript 页面需要的凭据，使用上游 Codex 插件连接 MCP，再提供网址或存储操作。
