# Sentry 工程技能合集

应用 Sentry 的工程、审查、文档与沟通约定。

## 合集介绍

Sentry 员工流程库覆盖代码与安全审查、Django 接口、Git 与合并请求、持续集成、指令、技能编写、文档、博客和演示文稿。

## 适用场景

- 审查代码、Django 权限与持续集成安全
- 准备合并请求和接口文档
- 制作团队文档与工程沟通材料

## 使用建议

安装完整上游插件或技能包并提供仓库背景，原生插件流程保留配套助手和参考资料，并结合 Sentry 专属约定使用。
