# Sentry Engineering Skills

Apply Sentry’s engineering, review, documentation, and communication conventions.

## Overview

Sentry’s employee workflow library covers code and security review, Django APIs, Git and pull requests, CI, instructions, Skill writing, documentation, blogs, and presentations.

## Scenarios

- Review code, Django access, and CI security
- Prepare pull requests and API documentation
- Create team documents and engineering communications

## Usage

Install the complete upstream plugin or Skill package and provide the repository context. Keep supporting agents and references for native plugin workflows and account for Sentry-specific conventions.
