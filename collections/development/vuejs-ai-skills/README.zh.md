# Vue 开发技能合集

为 Vue 3 应用开发提供组件、路由、状态管理、测试和调试指导。

![AI 生成的 Vue 开发技能合集封面](cover.webp)

## 合集介绍

这套由 vuejs-ai 社区维护的合集包含八个技能，覆盖 Vue 3 的 Composition API 与 TypeScript、Options API、Vue Router、Pinia、测试、JSX、调试和可复用组合式函数。上游项目仍处于早期实验阶段，使用时应结合项目实际情况和已安装版本核验建议。

## 适用场景

- 编写 Vue 3 组件和可复用组合式函数
- 配置路由导航和 Pinia 状态管理
- 编写组件测试和端到端测试
- 排查运行时错误和水合问题

## 使用建议

安装合集后，说明项目的 Vue 版本、API 风格和具体任务。作者建议以 `use vue skill` 开始提示词，再按开发、测试或调试任务选用对应技能，并在项目中验证结果。
