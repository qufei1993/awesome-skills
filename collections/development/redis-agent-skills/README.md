# Redis Agent Skills

Build and optimize Redis-backed applications with official Redis guidance.

## Overview

The pack covers the author’s Redis development workflows and bundled references. The redis-development plugin distributes copies of the same canonical Skill set.

## Scenarios

- Review Redis query and data-model choices
- Improve application performance with Redis

## Usage

Install with the Agent Skills CLI or the Redis plugin for your host. Give the agent the workload, Redis configuration, and performance target.
