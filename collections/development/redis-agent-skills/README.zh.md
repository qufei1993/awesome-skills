# Redis Agent 技能

用 Redis 官方指引开发并优化 Redis 应用。

## 合集介绍

技能包涵盖作者 Redis 开发流程与配套资料，redis-development 插件分发同一规范技能集的副本。

## 适用场景

- 检查 Redis 查询与数据模型选择
- 用 Redis 改善应用性能

## 使用建议

通过 Agent Skills CLI 或宿主 Redis 插件安装，提供负载、Redis 配置与性能目标。
