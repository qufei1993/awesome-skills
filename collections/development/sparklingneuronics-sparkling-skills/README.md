# Sparkling Dispatch Skills

Request Codex and Gemini second opinions from Claude Code.

![Sparkling Dispatch Skills — original project cover](<https://raw.githubusercontent.com/sparklingneuronics/sparkling-skills/313630de4f6fc6a4df4dd53814b8d8c5dc944426/assets/hero.svg>)

## Overview

The complete dispatch plugin pairs codex and agy Skills for independent reviews, parallel checks, side tasks, and visual work. Results return to the main agent for comparison and verification.

## Scenarios

- Get an independent code review
- Run parallel checks on a migration
- Delegate a bounded research or visual task

## Usage

Install the upstream dispatch plugin inside Claude Code. Prepare authenticated Codex and Gemini-compatible tools, then state the task and ask the main agent to reconcile the results.
