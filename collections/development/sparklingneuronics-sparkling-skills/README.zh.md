# Sparkling Dispatch 技能

从 Claude Code 请求 Codex 与 Gemini 的独立意见。

## 合集介绍

完整 dispatch 插件包含 codex 和 agy 两个技能，用于独立评审、并行检查、辅助任务和视觉工作，再由主 Agent 对照和验证结果。

## 适用场景

- 获得独立代码评审
- 并行检查迁移方案
- 委派有边界的研究或视觉任务

## 使用建议

在 Claude Code 中安装上游插件，准备已认证的 Codex 与 Gemini 对应工具，再说明任务并让主 Agent 核对结果。
