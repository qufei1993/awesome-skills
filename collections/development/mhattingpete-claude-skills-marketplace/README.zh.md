# Claude Skills Marketplace

组合工程工作流、可视化文档、代码操作与项目效率能力。

## 合集介绍

Mhattingpete 发布四个含技能的插件，覆盖功能规划、测试、审查、图表、代码库文档与批量文件操作；执行运行时为大型操作提供可选的 API 路径。

## 适用场景

- 规划并验证工程改动
- 制作架构与时间线文档
- 开展结构化批量代码操作

## 使用建议

安装符合任务的插件。使用 API 支持的操作时遵循作者的 execution-runtime 配置；所列技能涵盖全部四个正式插件。
