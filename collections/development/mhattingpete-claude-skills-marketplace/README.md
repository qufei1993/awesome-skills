# Claude Skills Marketplace

Combine engineering workflows, visual documentation, code operations, and project productivity.

## Overview

Mhattingpete publishes four Skill-bearing plugins for feature planning, tests, reviews, diagrams, codebase documentation, and batch file operations. The execution runtime provides an optional API-based route for larger operations.

## Scenarios

- Plan and verify an engineering change
- Create architecture and timeline documentation
- Perform structured batch code operations

## Usage

Install the plugin that matches the task. Follow the author’s execution-runtime setup when using API-backed operations; the linked Skills cover all four published plugins.
