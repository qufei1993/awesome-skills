# Playwright 技能指南

用 TestDino 完整指南包编写、调试、扩展与迁移 Playwright 测试。

## 合集介绍

技能包将规范索引与核心测试、CI/CD、浏览器 CLI、Page Object Model 和迁移技能结合，涵盖受支持框架的架构决策与测试实现。

## 适用场景

- 稳定不可靠的端到端测试
- 设计 CI 执行并迁移测试套件

## 使用建议

按仓库命令安装全部包，或选择具体包；提供测试代码、轨迹或迁移目标，让 Agent 加载对应指南。
