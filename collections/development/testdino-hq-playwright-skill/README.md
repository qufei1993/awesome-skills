# Playwright Skill Guides

Write, debug, scale, and migrate Playwright tests with TestDino’s complete guide pack.

## Overview

The pack combines a canonical index with core testing, CI/CD, browser CLI, Page Object Model, and migration Skills. It covers architecture decisions and test implementation across supported frameworks.

## Scenarios

- Stabilize a flaky end-to-end test
- Design CI execution and migrate a test suite

## Usage

Install all packs using the documented repository command or choose a pack. Provide the test code, trace, or migration goal so the agent can load the appropriate guide.
