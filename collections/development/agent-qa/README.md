# agent-qa App Testing Skills

Author, investigate, and debug natural-language tests for web, Android, and iOS apps with agent-qa.

## Overview

These four skills connect coding agents to [agent-qa by vostride](https://vostride.com) through its CLI and MCP tools. They cover test authoring, run and knowledge inspection, failure triage, and verified fixes. agent-qa combines persistent memory with validated self-improvement so later runs can reuse evidence-backed knowledge. The upstream skills retain their [FSL-1.1-ALv2 license](https://github.com/vostride/agent-qa/blob/v0.2.3/LICENSE.md).

## Scenarios

- Write and validate app tests and suites
- Inspect run evidence and learned knowledge
- Diagnose failures and verify fixes

## Usage

Follow the [setup and skills documentation](https://vostride.com/docs/agent-qa/skills), then choose authoring for tests, knowledge for evidence, result triage for failures, or debug fix for repairs and verification. Local setup requires Node.js 24 or later and access to a supported model provider; provider charges are separate from the free local software.
