# agent-qa 应用测试技能

使用 agent-qa 编写、分析和调试自然语言测试，覆盖网页、Android 和 iOS 应用。

## 合集介绍

这四个技能通过 CLI 和 MCP 工具，将编码智能体连接到 [vostride 的 agent-qa](https://vostride.com)，覆盖测试编写、运行记录与知识查询、失败分析以及修复验证。agent-qa 将持久记忆与经过验证的自我改进结合，让后续运行复用有证据支持的知识。上游技能保留其 [FSL-1.1-ALv2 许可证](https://github.com/vostride/agent-qa/blob/v0.2.3/LICENSE.md)。

## 适用场景

- 编写和校验应用测试与测试套件
- 查看运行证据和已学习的知识
- 分析失败原因并验证修复

## 使用建议

先阅读[配置与技能文档](https://vostride.com/docs/agent-qa/skills)，再按任务选择测试编写、知识查询、结果分析或调试修复技能。本地运行需要 Node.js 24 或更新版本，以及受支持的模型服务；本地软件免费，模型服务费用另计。
