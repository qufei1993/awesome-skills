# Aegis 工程方法技能

让编程助手遵循项目架构，并以证据验证完成情况。

## 合集介绍

Aegis 将项目背景、目标、规划、架构记录、实现、调试、审查、测试和长任务连续性组合为工程方法。

## 适用场景

- 依据项目契约与边界规划变更
- 实现并验证审查功能
- 在长任务中保留架构决策

## 使用建议

按所用助手指南安装完整 Aegis 方法包，配置工作空间支持和原生入口集成，较大任务开始前提供真实项目基线。
