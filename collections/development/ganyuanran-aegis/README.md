# Aegis Engineering Method Skills

Align coding-agent work with project architecture and verify completion with evidence.

## Overview

Aegis combines project context, goal framing, planning, architecture records, implementation, debugging, review, testing, and long-task continuity into a governed engineering method.

## Scenarios

- Plan changes against project contracts and boundaries
- Implement and review a feature with verification
- Preserve architecture decisions across long tasks

## Usage

Install the full Aegis method pack using the guide for your host. Configure its workspace support and native entry integration, then provide the real project baseline before starting substantial work.
