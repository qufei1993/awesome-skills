# AWS Portable Agent Skills

Build and operate AWS applications with the toolkit’s complete portable Skill catalog.

## Overview

AWS groups its portable Skills into core guidance and specialized service domains for analytics, databases, networking, security, operations, resilience, serverless, and storage.

## Scenarios

- Select and implement AWS services
- Troubleshoot infrastructure and application operations
- Plan migrations, security, or resilience work

## Usage

Install the full portable directory through the upstream Skills route. Prepare AWS CLI credentials and add MCP servers or native plugin integrations when the workflow requires them.
