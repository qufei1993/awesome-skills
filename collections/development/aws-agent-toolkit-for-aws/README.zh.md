# AWS 可移植技能合集

通过工具包完整的可移植目录开发和管理 AWS 应用。

## 合集介绍

AWS 将可移植技能分为核心指导和专项服务领域，涵盖分析、数据库、网络、安全、运维、韧性、无服务器和存储。

## 适用场景

- 选择并实现 AWS 服务
- 排查基础设施与应用运行问题
- 规划迁移、安全或韧性工作

## 使用建议

按上游技能安装方式安装完整可移植目录，准备 AWS 命令行凭据，并按流程补充 MCP 或原生插件集成。
