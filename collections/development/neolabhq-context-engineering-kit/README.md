# Context Engineering Kit Skills

Improve agent reasoning and software delivery through structured development workflows.

## Overview

NeoLabHQ’s native plugins combine reflection, review, Git, TDD, specifications, subagent work, continuous improvement, documentation, MCP, and first-principles reasoning.

## Scenarios

- Plan and implement changes from a specification
- Review code with focused agents and feedback
- Improve prompts, instructions, and project knowledge

## Usage

Install the complete native plugin suite to retain commands and agent integrations. Use the relevant workflow with repository context; portable Skill copies alone do not supply those integrations.
