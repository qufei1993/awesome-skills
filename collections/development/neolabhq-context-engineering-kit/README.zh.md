# Context Engineering Kit 技能合集

通过结构化开发流程改善助手推理和软件交付。

## 合集介绍

NeoLabHQ 原生插件结合反思、审查、Git、测试驱动开发、规格、子助手协作、持续改进、文档、MCP 和第一性原理推理。

## 适用场景

- 依据规格规划并实现变更
- 通过专项助手和反馈审查代码
- 改进提示词、指令和项目知识

## 使用建议

安装完整原生插件套件以保留命令与助手集成，结合仓库背景使用相应流程；可移植技能副本本身不提供这些集成。
