# Transloadit Skills

Build uploads, asset delivery, and media transformations with Transloadit.

## Overview

Transloadit’s complete router-led catalog covers Robot documentation, Next.js integrations, collages, PDF conversion, image generation and cleanup, video encoding, and audio transcription.

## Scenarios

- Integrate uploads or SmartCDN into Next.js
- Transform images and generate collages
- Encode video or transcribe audio

## Usage

Start with the transloadit router and specify the input, output, and application context. Configure the Transloadit account and credentials required by the chosen operation.
