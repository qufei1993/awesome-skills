# Transloadit 技能

通过 Transloadit 构建上传、素材分发与媒体转换流程。

## 合集介绍

Transloadit 完整路由式目录覆盖 Robot 文档、Next.js 集成、拼贴、PDF 转换、图像生成与处理、视频编码和音频转写。

## 适用场景

- 在 Next.js 接入上传或 SmartCDN
- 处理图像并制作拼贴
- 编码视频或转写音频

## 使用建议

先使用 transloadit 路由，说明输入、输出和应用背景，再配置所选操作需要的 Transloadit 账号与凭据。
