# YYLO Skills

Manage project understanding, task ledgers, workflow records, benchmarks, and execution loops.

## Overview

YYLO’s complete eight-Skill canonical package serves its CLI, Ledger, and Benchmark products. It connects project exploration and planning with task state, wiki records, artifacts, studies, and Ralph execution.

## Scenarios

- Understand a project and plan ledger tasks
- Track workflow and artifact records
- Run benchmark studies or execution loops

## Usage

Provide the repository and objective. Use the upstream YYLO tooling when the workflow requires it and preserve ledger, wiki, and artifact records for resumable work.
