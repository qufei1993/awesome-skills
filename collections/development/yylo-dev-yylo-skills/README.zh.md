# YYLO 技能

管理项目理解、任务台账、流程记录、基准与执行循环。

## 合集介绍

YYLO 完整八技能原生包服务于 CLI、Ledger 和 Benchmark，将项目探索、规划与任务状态、百科、产出记录、评估和 Ralph 执行连接起来。

## 适用场景

- 理解项目并规划台账任务
- 跟踪流程和产出记录
- 开展基准研究或执行循环

## 使用建议

提供仓库和目标，需要时使用上游 YYLO 工具，并保留台账、百科和产出记录以继续工作。
