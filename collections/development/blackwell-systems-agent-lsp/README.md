# agent-lsp Workflow Skills

Use language-server intelligence for agent code navigation, edits, diagnostics, and review.

![agent-lsp Workflow Skills — original project cover](<https://raw.githubusercontent.com/blackwell-systems/agent-lsp/38ca4880dd5d499a76fe83ecaaa1bd5040e266fc/assets/banner.png>)

## Overview

The library bundles twenty-four workflows around agent-lsp’s MCP orchestration layer, including batch and speculative operations across supported languages.

## Scenarios

- Navigate and refactor with semantic code context
- Check diagnostics before accepting an edit

## Usage

Install agent-lsp and the language servers for the project, verify setup, then install its Skills. Configure the AI host’s MCP connection before running workflows.
