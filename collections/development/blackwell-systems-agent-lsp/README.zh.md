# agent-lsp 工作流技能

通过语言服务器能力开展 Agent 代码导航、编辑、诊断与审查。

![agent-lsp 工作流技能 官方项目封面](<https://raw.githubusercontent.com/blackwell-systems/agent-lsp/38ca4880dd5d499a76fe83ecaaa1bd5040e266fc/assets/banner.png>)

## 合集介绍

技能库围绕 agent-lsp MCP 编排层提供二十四个工作流，包含支持语言的批量与推测操作。

## 适用场景

- 用语义代码上下文导航与重构
- 接受编辑前检查诊断

## 使用建议

安装 agent-lsp 及项目语言服务器，验证配置后安装技能；运行流程前配置 AI 宿主的 MCP 连接。
