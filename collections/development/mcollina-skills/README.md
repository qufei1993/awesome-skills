# Matteo Collina Development Skills

Develop Node.js and Fastify applications and maintain their engineering workflows.

## Overview

Matteo Collina’s library covers Node.js runtime and core internals, Fastify, TypeScript, linting, OAuth, documentation, GitHub operations, and Skill optimization.

## Scenarios

- Build and debug Node.js or Fastify services
- Improve TypeScript, linting, and project documentation

## Usage

Install the upstream Skill folders and provide the project’s runtime and stack. Prepare the relevant Node.js tooling, GitHub CLI access, or optimization utilities for the chosen task.
