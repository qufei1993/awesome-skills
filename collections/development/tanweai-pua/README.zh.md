# PUA 助手工作流程技能

帮助编程助手持续排错、验证结果并主动推进任务。

## 合集介绍

公开 PUA 插件将调试和工作管理方法与不同强度模式、语言版本结合，README 同时记录了兼容性限制。

## 适用场景

- 推进反复失败的调试任务
- 核查任务是否真正完成
- 协调主动执行的工程工作

## 使用建议

按上游插件选择合适模式并说明任务边界。各平台的钩子和运行方式不同，应遵循作者对应的平台指南。
