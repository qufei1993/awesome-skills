# Firebase Agent Skills

Develop Firebase-backed applications with the Firebase team’s agent workflows.

## Overview

The official pack provides reusable Firebase instructions and scripts for coding agents and is distributed through Skills CLI and native agent plugins.

## Scenarios

- Build an application with Firebase services
- Configure and maintain a Firebase project

## Usage

Use the installation path for your agent, then give it the application requirements and Firebase project context. Configure project access for operations that contact Firebase.
