# Firebase Agent 技能

用 Firebase 团队的 Agent 工作流开发 Firebase 应用。

## 合集介绍

官方技能包为编程 Agent 提供可复用的 Firebase 指令与脚本，并通过 Skills CLI 和原生 Agent 插件分发。

## 适用场景

- 使用 Firebase 服务开发应用
- 配置并维护 Firebase 项目

## 使用建议

选择适合 Agent 的安装方式，再提供应用需求与 Firebase 项目背景；连接 Firebase 的操作需要配置项目访问。
