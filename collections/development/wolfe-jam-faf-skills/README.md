# FAF Skills

Create persistent project context and keep project.faf, agent guidance, and tests aligned.

## Overview

The author’s seven-Skill package covers context setup, guided interviews, generation, expert reference, repository maintenance, and WJTTC test building or execution.

## Scenarios

- Create or complete project.faf
- Synchronize project context and CLAUDE.md
- Generate and run test suites

## Usage

Start with faf-context or the guided interview and supply project goals. Use the upstream FAF tools for scoring and keep context files current as the project changes.
