# FAF 项目上下文技能

建立持续项目背景，并对齐 project.faf、Agent 指导与测试。

## 合集介绍

作者七技能包覆盖上下文配置、访谈、生成、专家参考、仓库维护和 WJTTC 测试构建与执行。

## 适用场景

- 建立或补全 project.faf
- 同步项目背景与 CLAUDE.md
- 生成和执行测试套件

## 使用建议

先用 faf-context 或访谈提供项目目标，再使用上游 FAF 工具评分，并随项目变化更新背景文件。
