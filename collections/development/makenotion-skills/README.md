# Notion CLI & Apps Skills

Use the Notion CLI and build Notion Apps, workflows, and database syncs.

## Overview

The official two-Skill repository pairs ntn installation and operations with App scaffolding and SDK development.

## Scenarios

- Run Notion API and file-upload tasks
- Build an App workflow or database sync

## Usage

Install both Skills with the skills CLI and follow the ntn and App setup for your project. Configure Notion access before API or deployment operations.
