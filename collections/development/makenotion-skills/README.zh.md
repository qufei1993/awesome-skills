# Notion CLI 与 Apps 技能

使用 Notion CLI，开发 Notion Apps、工作流与数据库同步。

## 合集介绍

官方双技能仓库将 ntn 安装与操作同 App 骨架及 SDK 开发结合。

## 适用场景

- 执行 Notion API 与文件上传任务
- 开发 App 工作流或数据库同步

## 使用建议

通过 skills CLI 安装两项，按项目配置 ntn 与 App，并在 API 或部署操作前配置 Notion 访问。
