# Addy 的工程技能合集

指导 AI 编程助手完成需求梳理、开发、测试、审查和发布准备。

![Addy 工程技能项目的原始封面](https://addyosmani.com/assets/images/addys-agent-skills.jpg)

## 合集介绍

Addy Osmani 整理的 25 个工程技能，覆盖软件开发的各个阶段，包括需求梳理、规格说明、任务规划、增量开发、测试、调试、代码审查、安全、性能和发布准备。

## 适用场景

- 澄清需求并编写规格说明
- 拆解任务并逐步实现功能
- 开发界面与接口
- 测试、调试和审查代码
- 准备安全发布并监控运行情况

## 使用建议

先澄清需求，编写规格说明，再把工作拆成小任务。按当前阶段选择开发、测试、审查和发布技能。部分技能使用上游仓库根目录 `references/` 中的共享检查清单。按上游安装说明准备这些参考资料，或使用带有配套命令和审查角色的完整插件。
