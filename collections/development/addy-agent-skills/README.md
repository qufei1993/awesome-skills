# Addy's Agent Skills

Guide AI coding agents through requirements, implementation, testing, review, and release preparation.

![Original Addy's Agent Skills project cover](https://addyosmani.com/assets/images/addys-agent-skills.jpg)

## Overview

Addy Osmani's collection contains 25 engineering Skills for the software development lifecycle. It covers requirements, specifications, planning, incremental implementation, testing, debugging, code review, security, performance, and release preparation.

## Scenarios

- Clarifying requirements and writing specifications
- Planning tasks and building features incrementally
- Developing interfaces and APIs
- Testing, debugging, and reviewing code
- Preparing secure releases and monitoring production

## Usage

Clarify the requirements, write a specification, and break the work into small tasks. Choose the implementation, testing, review, and release Skills for each stage. Some Skills use shared checklists in the upstream repository's root `references/` directory. Follow the upstream setup guide to provide those references, or use the full plugin with its commands and reviewer personas.
