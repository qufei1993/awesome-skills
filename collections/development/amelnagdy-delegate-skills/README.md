# Delegate Skills

Delegate implementation to coding-agent CLIs while retaining review and commit ownership.

## Overview

The library provides fleet setup and per-implementer delegation workflows for a range of coding agents, with task lanes, handoffs, and diff review.

## Scenarios

- Assign feature, test, or UI work to an agent
- Review and land a delegated implementation

## Usage

Prepare and authenticate the desired implementer CLI, then use delegate-setup or a direct delegation Skill. Review the resulting diff before landing the change.
