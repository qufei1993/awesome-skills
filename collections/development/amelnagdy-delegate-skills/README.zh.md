# 任务委派技能合集

将实现委派给编程助手命令行工具，同时保留审查和提交职责。

## 合集介绍

技能库提供工具队伍设置与各实现助手的委派流程，支持任务分工、交接和差异审查。

## 适用场景

- 将功能、测试或界面任务分配给助手
- 审查并接纳委派产生的实现

## 使用建议

先安装并授权所需实现助手，再使用 delegate-setup 或直接委派技能，接纳变更前审查结果差异。
