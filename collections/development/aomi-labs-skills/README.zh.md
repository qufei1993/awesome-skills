# Aomi 技能

构建 Aomi 应用，并通过 CLI 操作区块链流程。

## 合集介绍

Aomi 当前公开包包含 build 与 transact 两个技能，将 API、SDK 资料连接到应用脚手架，并支持价格和余额查询、交易模拟与链上操作。

## 适用场景

- 搭建 Aomi 应用或插件
- 查询余额并模拟交易
- 准备链上转账或交换

## 使用建议

按上游方式配置 Aomi CLI，并保持版本与技能兼容。构建时提供 API 资料，交易时明确链和钱包信息。
