# Aomi Skills

Build Aomi applications and operate blockchain workflows through its CLI.

## Overview

Aomi’s current public package consists of build and transact Skills. It connects API and SDK specifications to application scaffolding, then supports price and balance queries, transaction simulation, and on-chain operations.

## Scenarios

- Scaffold an Aomi application or plugin
- Query balances and simulate transactions
- Prepare blockchain transfers or swaps

## Usage

Follow the upstream Aomi CLI setup and keep the installed CLI version compatible with the Skills. Provide API material for builds and explicit chain and wallet details for transactions.
