# Gstack Source Skills

Engineering workflows for planning, design, review, testing, and delivery.

## Overview

The fixed source scope contains the root router and all 55 first-level skills discovered by the author’s setup.

## Scenarios

- Review an implementation
- Plan and test a release

## Usage

Use the author’s host-specific setup for shared bin/lib resources, browser builds, and hooks. These links index source skills; installation and runtime behavior remain unverified.
