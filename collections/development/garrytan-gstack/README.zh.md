# Gstack 源码技能包

把规划、设计、评审、测试和交付串成工程工作流。

## 合集介绍

收录作者 setup 发现规则对应的根路由与 55 个一级技能。

## 适用场景

- 评审实现
- 规划并验证交付

## 使用建议

使用作者面向宿主的 setup 配置共享 bin/lib、浏览器构建和 hooks；这些链接整理源码技能，尚未验证安装与运行。
