# Tinybird Agent 技能

构建 Tinybird 数据资源，并通过 CLI 与 SDK 管理项目。

## 合集介绍

Tinybird 的四技能包组合项目实践、CLI、Python SDK 和 TypeScript SDK，覆盖数据源、管道、接口、SQL、测试与部署。

## 适用场景

- 开发 Tinybird 数据源和管道
- 优化查询与数据接口
- 通过 CLI 或 SDK 管理项目

## 使用建议

提供 Tinybird 项目和目标数据操作。资源开发先使用项目实践，再选择 CLI 或对应 SDK 并配置凭据。
