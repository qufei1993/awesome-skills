# Tinybird Agent Skills

Build Tinybird data resources and operate projects through CLI and SDK workflows.

## Overview

Tinybird’s four-Skill package combines project best practices with CLI, Python SDK, and TypeScript SDK guidance for data sources, pipes, endpoints, SQL, testing, and deployment.

## Scenarios

- Develop Tinybird data sources and pipes
- Optimize queries and endpoints
- Operate projects with CLI or SDKs

## Usage

Provide the Tinybird project and desired data operation. Use project best practices for resource work, then choose CLI or the matching SDK and prepare its credentials.
