# Supercov 技能

衡量覆盖率与代码质量，并为 Agent 提供明确改进目标。

## 合集介绍

正式插件把现有测试命令、未覆盖路径、质量分数与安全发现转成迭代编程 Agent 流程。

## 适用场景

- 为未覆盖路径编写有效测试
- 检查代码质量与安全风险

## 使用建议

安装插件或技能，通过 Supercov 运行项目现有测试命令；覆盖率在本地计算，质量评分使用 TypeSafe AI API 密钥。
