# HashiCorp Agent Skills

Develop Terraform infrastructure and Packer images with HashiCorp’s product Skill bundles.

## Overview

The official library groups its Terraform and Packer guidance into two product bundles, covering infrastructure code, modules, provider development, policy, and machine images.

## Scenarios

- Build reusable Terraform modules
- Review infrastructure policy and configuration
- Create Packer machine images

## Usage

Choose the Terraform or Packer bundle for your project. The author publishes both as Claude Code and Codex plugins and also supports individual installation through the skills CLI.
