# HashiCorp Agent Skills

用 HashiCorp 的产品技能包开发 Terraform 基础设施与 Packer 镜像。

## 合集介绍

官方技能库按 Terraform 与 Packer 分成两个产品包，覆盖基础设施代码、模块、Provider 开发、策略和机器镜像。

## 适用场景

- 开发可复用的 Terraform 模块
- 检查基础设施策略与配置
- 制作 Packer 机器镜像

## 使用建议

按项目选择 Terraform 或 Packer 包。作者同时提供 Claude Code、Codex 插件及 skills CLI 单项安装方式。
