# Anthony Fu’s Skills

Use Anthony Fu’s preferences and documentation-based guidance for the Vue toolchain.

## Overview

The library combines hand-maintained project and PR practices with Skills for Vue, Nuxt, Vite, Vitest, Pinia, pnpm, UnoCSS, Nitro, and VitePress.

## Scenarios

- Build Vue and Nuxt applications
- Configure tooling, tests, and package workflows

## Usage

Install the collection and provide the project’s stack. The author describes it as a proof of concept, so validate generated guidance against the project and its installed versions.
