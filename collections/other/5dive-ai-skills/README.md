# 5dive Skills

Coordinate agents, maintain knowledge, verify work, and produce research or marketing content.

## Overview

The complete 5dive repository package joins runtime CLI workflows with durable knowledge, personas, recurring loops, browser testing, review, verification, research, and writing.

## Scenarios

- Manage agent tasks and recurring loops
- Build knowledge stores and verify claims
- Create research and marketing deliverables

## Usage

Choose the task and provide its evidence or brief. Runtime administration needs a 5dive VM; portable loops and other standalone workflows use their own listed tools.
