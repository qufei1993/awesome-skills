# 5dive 技能

协调 Agent、维护知识、验证工作并制作研究或营销内容。

## 合集介绍

5dive 完整仓库包组合运行时 CLI、持续知识、角色、定期循环、浏览器测试、评审、验证、研究和写作。

## 适用场景

- 管理 Agent 任务和定期循环
- 建立知识库并核实声明
- 制作研究和营销产出

## 使用建议

选择任务并提供证据或简报。运行时管理需要 5dive VM；可移植循环和其他独立流程按自身要求准备工具。
