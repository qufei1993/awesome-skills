# Agent 37 技能合集

使用 Agent 37 插件合集的创业建议与可复用提示请求。

## 合集介绍

市场提供从整理的创业资源提炼的 YC 建议，以及提示请求技能；local-review 插件是命令。

## 适用场景

- 讨论融资与创业决策
- 准备可复用 Agent 提示请求

## 使用建议

添加 Agent 37 市场并安装所需插件；创业问题激活 yc-advisor，提示请求流程按对应插件方式调用。
