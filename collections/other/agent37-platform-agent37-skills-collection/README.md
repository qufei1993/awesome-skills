# Agent 37 Skills Collection

Use startup advice and reusable prompt requests from Agent 37’s plugin collection.

## Overview

The marketplace publishes YC advice drawn from curated startup resources and a prompt-request Skill. Its local-review plugin is a command rather than a Skill.

## Scenarios

- Discuss fundraising and startup decisions
- Prepare a reusable agent prompt request

## Usage

Add the Agent 37 marketplace and install the required plugin. Startup questions activate yc-advisor; follow the prompt-request plugin’s invocation for that workflow.
