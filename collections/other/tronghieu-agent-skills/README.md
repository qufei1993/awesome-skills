# Method-Driven Agent Skills

Structure decisions, projects, evidence analysis, writing, and finished artifacts.

## Overview

Trong Hieu’s library combines thinking methods with product and project management, research, testing, data science, fiction, technical writing, and presentations.

## Scenarios

- Analyze evidence for a decision
- Produce a project plan or written artifact

## Usage

Install the full collection and explicitly invoke the chosen role. Provide the real context and inspect the analysis and quality checks before making the decision.
