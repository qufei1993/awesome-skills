# 方法驱动 Agent 技能

组织决策、项目、证据分析、写作与最终成果。

## 合集介绍

Trong Hieu 技能库将思考方法与产品和项目管理、研究、测试、数据科学、小说、技术写作和演示结合。

## 适用场景

- 为决策分析证据
- 制作项目计划或写作成果

## 使用建议

安装完整合集并明确调用所选角色，提供真实背景，并在决策前检查分析与质量验证。
