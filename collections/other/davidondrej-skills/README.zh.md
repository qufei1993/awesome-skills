# David Ondrej 技能合集

复用 David Ondrej 的助手、研究、文档和运营流程。

## 合集介绍

作者按原生类别组织助手编排、技能创作、网页研究、结构化思考、文档以及机器与服务器配置。

## 适用场景

- 协调编程助手并审查工作
- 研究想法并整理为文档
- 配置工具和运行环境

## 使用建议

按任务选择类别并保留配套文件。研究流程常用 DeepAPI，助手与运维任务需准备对应工具和访问权限。
