# David Ondrej’s Skills

Reuse David Ondrej’s workflows for agents, research, documents, and operations.

## Overview

The library groups agent orchestration, Skill authoring, web research, structured thinking, documentation, and machine or server setup into native categories.

## Scenarios

- Coordinate coding agents and review work
- Research ideas and turn them into documents
- Configure tools and operational environments

## Usage

Choose the category for the task and keep supporting files with the Skill. Research workflows often require DeepAPI; agent and operations workflows need the named tools and access.
