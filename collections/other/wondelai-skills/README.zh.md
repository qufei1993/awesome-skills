# Wondel.ai 框架技能合集

通过引导流程应用书籍中的商业、体验和工程框架。

## 合集介绍

Wondel.ai 正式库将专项框架与创建、改善或发展商业、网站和应用的综合技能结合。

## 适用场景

- 制定产品策略与用户发现流程
- 改善设计、转化和营销
- 审查架构、代码质量和技术债

## 使用建议

选择专项框架或综合引导流程，回答各阶段问题，并保留项目文档以便跨会话继续。
