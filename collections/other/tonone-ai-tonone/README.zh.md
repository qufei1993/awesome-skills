# Tonone 公司技能

协调创始人的工程、产品、运营与专业团队流程。

## 合集介绍

Tonone 完整插件将专业 Agent 与工程、法律、设计、数据、安全、开发者体验、基础设施和 AI 运营流程结合。

## 适用场景

- 通过专业角色交接规划产品
- 开展基础设施、安全与运营审查

## 使用建议

安装完整 Tonone 插件并向负责人提出目标，选择建议的深度和预算；Codex 可直接读取相同根技能流程。
