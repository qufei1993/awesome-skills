# Tonone Company Skills

Coordinate a founder’s engineering, product, operations, and specialist team workflows.

## Overview

Tonone’s complete plugin combines specialist agents with workflows across engineering, legal, design, data, security, developer experience, infrastructure, and AI operations.

## Scenarios

- Plan a product with specialist handoffs
- Run infrastructure, security, and operational reviews

## Usage

Install the complete Tonone plugin and invoke a lead with the intended outcome. Select the proposed depth and budget; Codex can read the same root Skill workflows directly.
