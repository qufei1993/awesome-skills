# AgentBay 技能

借助 AgentBay 沙箱执行代码、操作浏览器、监测信息并连接外部服务。

## 合集介绍

AgentBay 的完整仓库包将沙箱执行、浏览器自动化与舆情报告、中国股票数据、交通、招聘、提醒、社交热点及图像生成组合起来。

## 适用场景

- 在沙箱中执行代码或自动操作浏览器
- 监测舆情并收集公开信息
- 生成图片或管理服务提醒

## 使用建议

先查看所用技能的 SKILL.md 配置说明。沙箱任务需要 AgentBay，交通和图像生成等服务各自需要对应凭据。
