# AgentBay Skills

Use AgentBay sandboxes for code, browsing, monitoring, and service integrations.

## Overview

AgentBay’s complete repository package combines sandbox execution and browser automation with sentiment reports, Chinese stock data, traffic, job search, reminders, social trends, and image generation.

## Scenarios

- Execute code or automate a browser in a sandbox
- Monitor sentiment and collect public information
- Generate images or manage service-based reminders

## Usage

Check the chosen Skill’s SKILL.md for setup. Sandbox work uses AgentBay; traffic and image-generation integrations require their own provider credentials.
