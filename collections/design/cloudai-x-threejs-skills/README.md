# Three.js Skills

Create interactive 3D scenes with focused Three.js API and implementation guidance.

## Overview

CloudAI-X’s library covers fundamentals, geometry, materials, textures, lights, loaders, animation, interaction, shaders, and postprocessing.

## Scenarios

- Build and animate a 3D scene
- Add interactions, materials, and visual effects

## Usage

Install the full Skill folders and provide the scene requirements and application code. Use the matching domain Skill and validate against the installed Three.js version.
