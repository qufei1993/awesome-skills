# Three.js 技能合集

通过专项接口与实现指导制作交互式三维场景。

## 合集介绍

CloudAI-X 的技能库涵盖基础、几何、材质、纹理、灯光、加载、动画、交互、着色器和后处理。

## 适用场景

- 构建三维场景并添加动画
- 加入交互、材质和视觉效果

## 使用建议

安装完整技能目录并提供场景要求与应用代码，按领域选择技能，并结合项目的 Three.js 版本验证。
