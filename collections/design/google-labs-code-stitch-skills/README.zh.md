# Stitch 插件技能包

通过 Stitch 工作流与工具完成界面设计和实现。

## 合集介绍

收录作者 stitch-design、stitch-build、stitch-utilities 三个插件的 16 个技能入口。

## 适用场景

- 探索界面设计
- 实现 Stitch 设计

## 使用建议

配置 Stitch MCP 服务并按插件流程使用，保留原名称和插件资源；安装目录名称需要按宿主适配。
