# Emil Kowalski UI Skills

Build and review interfaces with focused guidance on motion and interaction details.

## Overview

Emil Kowalski’s collection covers animation choices, interface prototypes, Apple design principles, mobile behavior, Swift, and Sonner, grounded in his design engineering practice.

## Scenarios

- Create and review interface animations
- Compare UI prototypes and choose libraries
- Improve mobile interactions and edge-case layouts

## Usage

Use emil-design-eng as the broad starting point, then choose a specific implementation or review task. Supply the relevant UI code and its target platform.
