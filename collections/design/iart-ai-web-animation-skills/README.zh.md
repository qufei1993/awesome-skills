# Web 动画技能

结合 GSAP、SVG、Lottie 与无障碍交互模式制作网页动画。

## 合集介绍

iart.ai 的完整包将网页动画引擎、微交互、页面转场、玻璃效果、ASCII 动画、无障碍与性能指导组合起来。

## 适用场景

- 为页面和交互组件添加动画
- 接入 SVG 或 Lottie 动效
- 改善动画性能与减少动态效果的适配

## 使用建议

提供框架、目标交互和浏览器约束，使用对应引擎的流程，并检查普通动效及其无障碍降级。
