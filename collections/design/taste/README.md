# Taste Skill · Frontend Design

Give AI-generated interfaces a stronger design direction, from typography and visual style to motion.

![Original Taste Skill frontend design project cover](https://raw.githubusercontent.com/Leonxlnx/taste-skill/ce26fc25c0e5e8cab638f883de62d9a86ee5e45b/assets/readme-banner.webp)

## Overview

A collection of web design, existing project redesign, and visual style guidance, with image generation for web interfaces, mobile screens, and brand visuals. Explore a design direction, or build and improve pages directly.

## Scenarios

- Websites and portfolios
- Redesigning existing interfaces
- Design and brand proposals

## Usage

Choose by task: frontend design for new pages, redesign guidance for existing interfaces. For visual exploration, generate reference images first, then ask a coding agent to implement them.
