# KiCad Happy 技能合集

审查电子设计并衔接原型到生产流程。

## 合集介绍

套件将 KiCad 原理图、PCB 和 Gerber 分析，与数据手册、EMC、SPICE、物料管理、元件采购和制造服务结合。

## 适用场景

- 订购前审查原理图或 PCB
- 检查元件选型并制作采购物料表
- 准备制造文件与仿真

## 使用建议

安装上游插件并提供 KiCad 项目或制造文件，按所选审查或采购流程准备 Python 工具、KiCad 程序及供应商接口访问。
