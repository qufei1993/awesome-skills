# KiCad Happy Skills

Review electronics designs and support the prototype-to-production workflow.

## Overview

The suite connects KiCad schematic, PCB and Gerber analysis with datasheets, EMC, SPICE, BOM management, component sourcing, and fabrication services.

## Scenarios

- Review a schematic or PCB before ordering
- Check component choices and build a sourcing BOM
- Prepare manufacturing files and simulation

## Usage

Install the upstream plugin and provide the KiCad project or fabrication files. Prepare its Python tooling, KiCad utilities, and supplier API access for the selected review or sourcing workflow.
