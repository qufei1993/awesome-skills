# Modellix 插件技能

通过 Modellix 准备提示并生成图片、视频或音频。

## 合集介绍

完整可移植插件包包含设计执行与图像提示工程技能，将创意规划连接到 Modellix CLI、API 和可选文档 MCP。

## 适用场景

- 准备详细图像提示
- 生成或编辑创意媒体
- 执行 Modellix 生成流程

## 使用建议

准备提示无需凭据；生成时配置 API 密钥或 CLI 配置档，并按上游要求准备 Node.js CLI 与 Python 就绪检查工具。
