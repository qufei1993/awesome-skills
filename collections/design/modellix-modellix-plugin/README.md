# Modellix Plugin Skills

Prepare prompts and generate image, video, or audio through Modellix.

## Overview

The complete portable plugin package includes design execution and image-prompt engineering Skills. It connects creative planning with the Modellix CLI or API and optional documentation MCP.

## Scenarios

- Prepare detailed image prompts
- Generate or edit creative media
- Operate Modellix generation workflows

## Usage

Prompt preparation needs no credential. For generation, configure an API key or CLI profile; keep the supported Node.js CLI and Python preflight tools available as described upstream.
