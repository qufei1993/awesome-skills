# Papercraft 纸艺立体书

把游戏、网页和动画做成立体书，让纸片随着页面展开、折起或转动。

## 合集介绍

Papercraft 提供 Three.js 和 Canvas 2D 模板，用裁切、叠放和折叠的卡纸构造场景。纸片沿折痕转动，配上柔和的阴影和纸张摩擦声，呈现手工模型的质感。

## 适用场景

- 为面包店制作首页，让纸模型店面在访客打开网页时展开
- 搭建纸艺港口小镇，让玩家步行探索
- 把晨光中的纸灯塔渲染成竖屏短片

## 使用建议

运行 `npx skills add xikhar/papercraft` 安装。告诉智能体你想做什么场景、哪些部件需要活动，以及成品是互动网页还是视频。如果已有配色或布景参考，可以一并附图。
