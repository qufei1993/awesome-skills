# Papercraft

Build games, web pages, and animations that open and move like a paper pop-up book.

## Overview

Papercraft pairs Three.js and Canvas 2D templates with techniques for cutting, layering, and folding virtual cardstock. Hinged movement, soft shadows, and paper sounds give each scene the feel of a handmade model.

## Scenarios

- Make a bakery storefront unfold as visitors open its landing page
- Build a harbor town that players can explore on foot
- Render a vertical video of a paper lighthouse at dawn

## Usage

Install with `npx skills add xikhar/papercraft`. Describe the subject, what should move, and whether you want an interactive page or a rendered clip. Include reference images if you have a particular palette or setting in mind.
