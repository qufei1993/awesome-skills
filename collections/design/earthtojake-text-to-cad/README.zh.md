# Text-to-CAD 技能合集

让助手设计 CAD 模型、检查制造限制并准备打印。

## 合集介绍

公开技能库将建模与仿真格式、制造审查、切片和支持的打印机流程连接起来。

## 适用场景

- 创建 CAD 零件与仿真模型
- 检查可打印性和制造限制
- 准备 G-code 并发送支持的打印任务

## 使用建议

按上游说明安装对应平台版本并准备建模工具和查看器。生成零件前提供尺寸、材料与制造约束。
