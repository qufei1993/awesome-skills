# Text-to-CAD Skills

Design CAD models, inspect fabrication constraints, and prepare prints with an agent.

## Overview

Text-to-CAD’s public library connects modeling and simulation formats with manufacturing review, slicing, and supported printer workflows.

## Scenarios

- Create CAD parts and simulation models
- Review printability and manufacturing constraints
- Prepare G-code and send supported prints

## Usage

Follow the upstream platform installer and keep the modeling tools and viewer available. Provide dimensions, materials, and manufacturing constraints before generating a part.
