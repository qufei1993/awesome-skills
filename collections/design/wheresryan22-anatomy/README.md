# Anatomy

Explain technical ideas through detailed, interactive isometric machines and instruments built with SVG.

## Overview

Anatomy by wheresryan22 maps a concept onto a recognizable physical mechanism, with shaded solid parts, working controls, and live readouts driven by the same model as the motion. It produces standalone HTML, SVG, or React/Next.js components, with optional WebGL effects and an experimental 3D mode. The upstream project is MIT-licensed.

## Scenarios

- Explaining algorithms and systems through interactive physical analogies
- Creating technical illustrations for documentation and articles
- Building detailed product and landing-page figures
- Illustrating machinery with cutaways and exploded views

## Usage

Install the upstream Skill for your agent, then invoke `/anatomy` in Claude Code or `$anatomy` in Codex with the concept and desired interaction, such as an interactive token-bucket rate limiter. It requires Node.js 20.10+ and Chrome or Chromium for verification. Start with SVG; use WebGL for effects such as fire or water, and treat 3D as experimental.
