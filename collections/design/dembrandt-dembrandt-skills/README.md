# Dembrandt Skills

Apply enterprise UX judgment to design systems, interfaces, and accessibility reviews.

![Dembrandt Skills — original project cover](<https://raw.githubusercontent.com/dembrandt/dembrandt-skills/20de5f225ea7cffe2a721ac18c1077a92769a013/dembrandt-skills.png>)

## Overview

The package covers visual identity, tokens, layout, components, interaction, usability, accessibility, and technical UI foundations. Its dembrandt orchestrator coordinates the full design review pipeline.

## Scenarios

- Review interface usability and accessibility
- Build coherent palettes, type scales, and components
- Extract a live site’s design system

## Usage

Ask for a specific interface decision or a full screen review. Live-site token extraction and brand-based generation need the Dembrandt CLI or MCP engine described upstream.
