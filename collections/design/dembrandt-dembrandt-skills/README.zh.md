# Dembrandt 界面设计技能

将企业级 UX 判断用于设计系统、界面与无障碍评审。

## 合集介绍

完整技能包覆盖视觉识别、设计变量、布局、组件、交互、可用性、无障碍和界面技术基础；dembrandt 编排技能负责串联完整设计评审流程。

## 适用场景

- 评审界面可用性与无障碍
- 建立一致的配色、字号与组件
- 提取现有网站的设计系统

## 使用建议

直接说明界面决策问题，或请求整体页面评审。提取在线网站变量及基于品牌生成界面时，需要按上游说明连接 Dembrandt CLI 或 MCP 引擎。
