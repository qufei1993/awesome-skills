# WebGL Animation Skills

Create Three.js animation, GLSL effects, and particle systems.

## Overview

This three-Skill iart.ai package focuses on browser-based 3D motion and GPU visual effects. It keeps scene animation, shader work, and particle design together.

## Scenarios

- Animate a Three.js scene
- Develop GLSL shader effects
- Build and troubleshoot particle motion

## Usage

Provide the scene, target effect, and browser or GPU constraints. Use the matching Three.js or shader workflow and test rendering performance on the target device.
