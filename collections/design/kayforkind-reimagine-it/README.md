# reimagine-it Design Skills

Redesign existing HTML from its real content using the reimagine-it engine.

## Overview

The agent package includes the main orchestration Skill and its audit, extract, generate, infographic, lock, and variation modules. Source content drives the resulting design.

## Scenarios

- Generate redesign directions from an HTML page
- Capture and reuse an approved brand surface

## Usage

Install the CLI engine and Agent Skill, then provide an HTML source. Use seeds to reproduce approved variations and the engine’s audit to inspect design health.
