# reimagine-it 设计技能

用 reimagine-it 引擎根据真实内容重设计现有 HTML。

## 合集介绍

Agent 包包含主编排技能及 audit、extract、generate、infographic、lock、variations 模块，由源内容驱动最终设计。

## 适用场景

- 从 HTML 页面生成重设计方向
- 捕获并复用已批准品牌表现

## 使用建议

安装 CLI 引擎与 Agent 技能，再提供 HTML 源文件；用种子重现已批准版本，通过引擎审查检查设计质量。
