# UX/UI Principles Skills

Evaluate interfaces, user flows, and AI interactions using focused UX review workflows.

## Overview

The author’s five-Skill package covers principle-based evaluation, interface antipatterns, AI interface reviews, flow checklists, and UX context for coding sessions.

## Scenarios

- Audit interface usability
- Review AI-powered interactions
- Check user flows before and after implementation

## Usage

Provide interface code, screens, or flow descriptions. Most reviews work without an API; enriched taxonomy output needs UXUI_API_KEY, and flow-checker requires the author’s pro service.
