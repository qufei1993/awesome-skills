# UX/UI Principles 技能

通过专项 UX 评审检查界面、用户流程和 AI 交互。

## 合集介绍

作者的五技能包覆盖原则评估、界面反模式、AI 界面评审、流程清单和编程会话中的 UX 背景。

## 适用场景

- 审查界面可用性
- 评审 AI 功能交互
- 在实现前后核对用户流程

## 使用建议

提供界面代码、页面或流程说明。多数审查无需 API；增强分类输出需要 UXUI_API_KEY，flow-checker 需要作者的专业版服务。
