# 平台设计技能

依据 Apple HIG、Material Design 与 WCAG 指引设计和评估界面。

## 合集介绍

八个平台技能覆盖 iPhone、iPad、Mac、Watch、Vision、TV、Android 与网页界面，将简明设计规则、实现示例和平台交互惯例结合起来。

## 适用场景

- 按平台惯例审查 SwiftUI 界面
- 让设计适应不同设备
- 改善界面无障碍

## 使用建议

通过 skills CLI 安装技能包，并提供目标平台及界面代码或设计；与平台相关的任务会调用对应指引。
