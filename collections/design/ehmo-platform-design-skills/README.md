# Platform Design Skills

Design and evaluate interfaces against Apple HIG, Material Design, and WCAG guidance.

## Overview

Eight platform Skills cover iPhone, iPad, Mac, Watch, Vision, TV, Android, and web interfaces. They pair concise design rules with implementation examples and platform-specific interaction expectations.

## Scenarios

- Review a SwiftUI interface for platform conventions
- Adapt a design across devices
- Improve interface accessibility

## Usage

Install the pack with the skills CLI and give the agent the target platform and interface code or design. Platform-relevant work activates the matching guidance.
