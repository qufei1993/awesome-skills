# GSAP 技能合集

在不同网页框架中制作正确高效的 GSAP 动效。

## 合集介绍

GreenSock 官方技能库涵盖补间、时间线、ScrollTrigger、插件、工具、React 集成、框架模式和性能。

## 适用场景

- 制作界面与滚动动效
- 审查动效性能和生命周期清理

## 使用建议

安装合集后提供目标框架与动效行为，遵循上游的插件注册、上下文清理和减少动态效果规则。
