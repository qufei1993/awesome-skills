# GSAP Skills

Build correct and efficient GSAP animations across web frameworks.

## Overview

GreenSock’s official library covers tweens, timelines, ScrollTrigger, plugins, utilities, React integration, framework patterns, and performance.

## Scenarios

- Animate interfaces and scroll-driven scenes
- Review motion performance and lifecycle cleanup

## Usage

Install the collection and provide the target framework and animation behavior. Use the upstream GSAP patterns for registration, context cleanup, and reduced-motion handling.
