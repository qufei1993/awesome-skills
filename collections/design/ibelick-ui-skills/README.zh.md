# Ibelick 界面技能合集

改进界面质量、无障碍、元数据和动效。

## 合集介绍

Ibelick 的设计工程库提供界面基线、专项修复、设计文档与界面改进指导。

## 适用场景

- 审查并修复界面无障碍问题
- 改进动效、元数据和视觉一致性

## 使用建议

通过上游命令行或 MCP 注册表查找技能，并提供相关界面代码、目标平台和待改善行为。
