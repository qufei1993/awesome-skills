# Intelligent Image Prompt Skills

Generate image prompts and learn reusable visual elements from existing prompts.

## Overview

The canonical Claude group combines a three-mode image-prompt generator with prompt comparison and a learner that extracts reusable elements into the project’s shared library.

## Scenarios

- Create portrait, cross-domain, or design prompts
- Analyze prompt differences and learn visual elements

## Usage

Use the complete upstream workspace with its Python generator, element database, and design variables. Configure local workspace paths before invoking the Skills; the Codex directory is a host adaptation.
