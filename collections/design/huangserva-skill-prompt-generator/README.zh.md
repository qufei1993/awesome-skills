# 智能图像提示词技能

生成图像提示词，并从现有提示词中学习可复用视觉元素。

## 合集介绍

正式 Claude 技能组结合三模式图像提示词生成器、提示词比较，以及将可复用元素提取到共享库的学习器。

## 适用场景

- 制作人像、跨领域或设计提示词
- 分析提示词差异并学习视觉元素

## 使用建议

使用完整上游工作空间及 Python 生成器、元素数据库和设计变量，调用前配置本地工作空间路径；Codex 目录属于宿主适配。
