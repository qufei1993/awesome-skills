# UIZZE 界面技能

结合设计指导与参考研究构建符合产品特点的界面。

## 合集介绍

UIZZE 的完整仓库发行包含 ui-design、anti-ui-slop 和 ui-radar，连接页面设计、完成度评审与可选的真实 Web、iOS 界面参考研究。

## 适用场景

- 构建或重新设计产品页面
- 评审缺少产品特点的界面草稿
- 研究具体的界面设计决策

## 使用建议

提供页面简报和产品背景。仓库中的三个技能对应作者的域名发行包；在线参考检索需要可选的付费 UIZZE MCP 连接。
