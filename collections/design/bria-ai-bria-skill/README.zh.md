# Bria AI 图像技能

通过 Bria 模型和结构化视觉提示生成、编辑图像。

## 合集介绍

Bria 的主技能包覆盖图像生成、背景移除、视觉生成语言、广告图层与尺寸调整、产品图和图像工具。本合集保留完整主 skills 目录。

## 适用场景

- 制作与编辑产品图
- 从广告成图恢复可编辑图层
- 移除背景并适配素材尺寸

## 使用建议

按上游指南配置 Bria API 密钥，并提供参考图片和修改要求。图像工具还需要 Pillow 与 requests。
