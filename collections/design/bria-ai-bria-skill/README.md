# Bria AI Skills

Generate and edit images with controllable Bria models and structured visual prompts.

## Overview

Bria’s primary agent package covers image generation, background removal, visual generation language, ad layers and resizing, product imagery, and image utilities. This collection retains the complete primary skills directory.

## Scenarios

- Create and edit product imagery
- Recover editable advertisement layers
- Remove backgrounds and adapt asset sizes

## Usage

Configure a Bria API key using the upstream guide. Supply reference images and the desired edits; image utilities additionally require Pillow and requests.
