# Figma MCP 技能合集

制作和检查 Figma 设计，并衔接实现与项目规划。

## 合集介绍

Figma 标准插件库覆盖原生设计、组件、变量、代码连接、动效和实现，另含作者公开的独立故事板与项目计划流程。

## 适用场景

- 制作或修改 Figma 设计系统
- 将界面录制转为故事板
- 将产品需求转为 FigJam 项目计划

## 使用建议

连接 Figma MCP 服务器并安装上游插件，需要时添加独立流程。画布写入使用远程服务器，并提供文件权限与项目背景。
