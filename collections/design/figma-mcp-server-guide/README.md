# Figma MCP Skills

Create and inspect Figma designs and connect them to implementation and planning.

## Overview

Figma’s standard plugin library covers native design work, components, variables, code connections, motion, and implementation, alongside two published standalone storyboard and project-plan workflows.

## Scenarios

- Build or revise a Figma design system
- Map a UI recording into a storyboard
- Turn a product brief into a FigJam project plan

## Usage

Connect the Figma MCP server and install the upstream plugin, adding standalone workflows when needed. Use the remote server for canvas writing and provide the relevant file access and project context.
