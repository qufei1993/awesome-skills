# TraderSpy Skills

Read crypto-market signals, positions, screeners, and technical data through TraderSpy MCP.

## Overview

The complete six-Skill plugin covers market briefings, screeners, position checks, smart-money tracking, technical analysis, and signals. Its hosted MCP service supplies read-only market tools.

## Scenarios

- Prepare a crypto-market briefing
- Inspect positions and smart-money activity
- Run screeners and technical analysis

## Usage

Connect the TraderSpy MCP server and authenticate through the supported account flow. Provide the market, asset, and time horizon; keep observations separate from trading decisions.
