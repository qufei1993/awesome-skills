# TraderSpy 技能

通过 TraderSpy MCP 读取加密市场信号、头寸、筛选和技术数据。

## 合集介绍

完整六技能插件覆盖市场简报、筛选、头寸检查、聪明钱跟踪、技术分析与信号；在线 MCP 提供只读市场工具。

## 适用场景

- 准备加密市场简报
- 检查头寸与聪明钱活动
- 运行筛选和技术分析

## 使用建议

连接 TraderSpy MCP 服务并按支持的账号流程认证，再明确市场、资产和时间范围，并将观察结果与交易决策分开。
