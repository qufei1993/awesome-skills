# Binance Skills Hub

Access Binance and Web3 data and account workflows through agent instructions.

## Overview

Binance’s public catalog covers market and token information, wallet activity, audits, signals, rankings, spot and other platform workflows, and Web3 interactions.

## Scenarios

- Retrieve token, market, or wallet information
- Review token audits and monitored signals
- Work with supported exchange and Web3 account operations

## Usage

Install the upstream package with Node.js 22 or later. Configure the API access required by the chosen endpoint and follow that Skill’s account and operation requirements.
