# Binance 技能中心合集

通过助手指令访问 Binance 与 Web3 数据和账号流程。

## 合集介绍

Binance 公开目录涵盖市场与代币信息、钱包活动、审查、信号、排名、现货等平台流程和 Web3 交互。

## 适用场景

- 查询代币、市场或钱包信息
- 查看代币审查与监测信号
- 处理支持的交易平台和 Web3 账号操作

## 使用建议

使用 Node.js 22 及以上版本安装上游包，配置所选接口需要的访问权限，并遵循对应技能的账号与操作要求。
