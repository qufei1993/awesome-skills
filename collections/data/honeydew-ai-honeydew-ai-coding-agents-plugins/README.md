# Honeydew AI Skills

Build semantic data models and query them through Honeydew MCP.

## Overview

Honeydew’s thirteen-Skill plugin covers entities, attributes, metrics, relations, domains, model exploration, queries, debugging, validation, conversation review, context, and workspace branches.

## Scenarios

- Define semantic models for warehouse tables
- Query metrics and investigate anomalies
- Validate models and debug data queries

## Usage

Connect the Honeydew MCP service and an accessible workspace using the upstream plugin setup. Provide the business question or schema change and preserve the model’s naming conventions.
