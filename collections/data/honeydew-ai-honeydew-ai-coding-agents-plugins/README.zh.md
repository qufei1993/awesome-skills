# Honeydew AI 数据技能

通过 Honeydew MCP 构建语义数据模型并查询数据。

## 合集介绍

Honeydew 的十三个插件技能覆盖实体、属性、指标、关系、领域、模型探索、查询、调试、验证、对话评审、上下文和工作区分支。

## 适用场景

- 为数据仓库表建立语义模型
- 查询指标并调查数据异常
- 验证模型和诊断数据查询

## 使用建议

按上游插件说明连接 Honeydew MCP 与可访问的工作区，并提供业务问题或表结构变更，沿用已有模型的命名约定。
