# ClickHouse Agent Skills

Design, optimize, and operate ClickHouse and chdb analytical workloads.

## Overview

The official library covers schema choices, ingestion, architecture, JavaScript troubleshooting, Python in-process analytics, infrastructure, and ClickStack collection.

## Scenarios

- Review ClickHouse schema and query performance
- Use chdb for local Python analytics

## Usage

Install with skills CLI or clickhousectl, then provide the schema, query, or ingestion workload. The pack supports both open-source deployments and ClickHouse Cloud.
