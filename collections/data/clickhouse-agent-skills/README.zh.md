# ClickHouse Agent 技能

设计、优化与运行 ClickHouse 和 chdb 分析工作负载。

## 合集介绍

官方库覆盖表结构选择、数据摄取、架构、JavaScript 排障、Python 进程内分析、基础设施与 ClickStack 采集。

## 适用场景

- 检查 ClickHouse 表结构与查询性能
- 用 chdb 开展本地 Python 分析

## 使用建议

通过 skills CLI 或 clickhousectl 安装，提供表结构、查询或摄取任务；技能包支持开源部署与 ClickHouse Cloud。
