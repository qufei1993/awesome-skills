# YouTube TranscriptAPI 技能合集

通过 TranscriptAPI 获取 YouTube 文本、搜索、频道和播放列表。

## 合集介绍

公开目录提供完整 YouTube 流程，以及文本、字幕、搜索、频道、播放列表和接口专项入口，ClawHub 副本为同组的 OpenClaw 适配。

## 适用场景

- 提取视频文本或字幕
- 研究视频并浏览频道或播放列表数据

## 使用建议

安装上游技能并配置 TranscriptAPI 密钥。综合任务从 youtube-full 开始，单项任务使用对应入口并提供视频或频道标识。
