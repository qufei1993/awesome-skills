# YouTube TranscriptAPI Skills

Retrieve YouTube transcripts, search results, channels, and playlists through TranscriptAPI.

## Overview

The public catalog provides a full YouTube workflow plus focused transcript, caption, search, channel, playlist, and API entry points; ClawHub copies adapt the same group for OpenClaw.

## Scenarios

- Extract a video transcript or captions
- Research videos and browse channel or playlist data

## Usage

Install the upstream Skills and configure a TranscriptAPI key. Start with youtube-full for combined access or use a focused entry point for the task, supplying the video or channel identifiers.
