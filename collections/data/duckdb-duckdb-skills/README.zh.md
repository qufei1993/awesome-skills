# DuckDB 技能

用 DuckDB 探索文件与数据库，并保留查询会话背景。

## 合集介绍

Claude Code 插件整合数据库连接、结构探索、SQL 查询、文件检查、文档、扩展与会话记忆；保存的 SQL 状态让后续任务恢复相同工作背景。

## 适用场景

- 探索本地分析数据库
- 查询 CSV 或 Parquet 文件
- 继续先前的数据调查

## 使用建议

安装 DuckDB 插件，连接数据库或读取文件后再查询；保留生成的会话状态，并在格式或集成需要时安装 DuckDB 扩展。
