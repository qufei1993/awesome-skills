# DuckDB Skills

Explore files and databases with DuckDB while preserving query-session context.

## Overview

The Claude Code plugin combines database attachment, schema exploration, SQL queries, file inspection, documentation, extensions, and session memory. Saved SQL state lets later tasks restore the same working context.

## Scenarios

- Explore a local analytical database
- Query CSV or Parquet files
- Resume an earlier data investigation

## Usage

Install the DuckDB plugin, attach the database or read a file, then query it. Keep the generated session state available and install DuckDB extensions when a format or integration requires them.
