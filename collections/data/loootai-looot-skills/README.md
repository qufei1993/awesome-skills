# Looot Skills

Run focused research and enrichment jobs through a shared data API catalog.

## Overview

Looot’s complete package contains a base router and twenty data jobs for companies, people, email, jobs, local businesses, reviews, search, keywords, backlinks, advertisements, and social data.

## Scenarios

- Research companies and professional contacts
- Collect search, keyword, and advertising data
- Find local businesses and public reviews

## Usage

Configure the Looot key and balance, then provide the data question. Review endpoint inputs and displayed price before a paid call, and preserve source fields in the result.
