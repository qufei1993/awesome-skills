# Looot 数据技能

通过共享数据 API 目录执行研究与信息补全任务。

## 合集介绍

Looot 完整包包含基础路由和二十个数据任务，覆盖公司、人物、邮件、招聘、本地商家、评价、搜索、关键词、外链、广告和社交数据。

## 适用场景

- 研究公司与职业联系人
- 收集搜索、关键词和广告数据
- 查找本地商家与公开评价

## 使用建议

配置 Looot 密钥与账户余额，再提出数据问题。付费调用前查看端点输入与显示价格，并保留结果来源字段。
