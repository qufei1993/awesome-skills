# 长桥金融数据技能

通过长桥工具查询行情、持仓与公司信息。

## 合集介绍

长桥当前完整技能包覆盖行情、技术分析、衍生品、基本面、研究、持仓操作、量化分析、自选股、资讯、财报和价值投资，面向其支持的市场。

## 适用场景

- 查询行情、新闻与财报
- 比较公司与估值数据
- 查看持仓和自选股

## 使用建议

按上游说明配置长桥 CLI 或 MCP 并完成账号认证。账户操作需要对应权限；可直接用希望得到回复的语言提出问题。
