# Longbridge Skills

Query market, portfolio, and company information through Longbridge tools.

## Overview

Longbridge’s current package spans market data, technicals, derivatives, fundamentals, research, portfolio operations, quantitative analysis, watchlists, news, earnings, and value investing across supported markets.

## Scenarios

- Inspect quotes, news, and earnings
- Compare companies and valuation data
- Review portfolios and watchlists

## Usage

Configure Longbridge CLI or MCP and authenticate the account as instructed upstream. Account operations need corresponding permissions; ask in the language you want the response to use.
