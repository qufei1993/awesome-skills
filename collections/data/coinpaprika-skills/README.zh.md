# CoinPaprika 与 DexPaprika 技能

通过 Paprika API 查询中心化与去中心化加密市场数据。

## 合集介绍

完整双技能包包含 CoinPaprika 币种和交易所数据，以及 DexPaprika 链、池、代币、K 线和流式数据。

## 适用场景

- 查询价格与历史 K 线
- 检查去中心化池和代币
- 比较交易所与市场数据

## 使用建议

说明资产、链、时间范围和需要的数据，按对应 API 或 CLI 配置操作，并在分析中保留时间戳与标识符。
