# CoinPaprika and DexPaprika Skills

Query centralized and decentralized crypto market data from the Paprika APIs.

## Overview

The complete two-Skill package covers CoinPaprika coin and exchange data plus DexPaprika chains, pools, tokens, candles, and streaming.

## Scenarios

- Query prices and historical candles
- Inspect decentralized pools and tokens
- Compare exchange and market data

## Usage

Specify the asset, chain, time range, and desired data. Follow the relevant API or CLI setup and retain timestamps and identifiers in the resulting analysis.
