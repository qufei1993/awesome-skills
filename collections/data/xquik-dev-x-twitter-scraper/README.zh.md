# Xquik X 数据技能

通过 Xquik API 工具搜索 X 帖子、资料、回复与受众。

## 合集介绍

可移植插件打包三个技能与托管 MCP 服务，支持公开数据研究、提取、监控与已连接账号流程。

## 适用场景

- 研究公开帖子与受众模式
- 规划批量提取与监控

## 使用建议

创建 Xquik API 密钥并选择 REST、CLI、SDK 或 MCP 方式；公开读取无需官方 X 开发者账号，私有操作需要连接账号。
