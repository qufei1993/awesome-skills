# A-Share Analysis & Paper Trading Skills

Analyze Chinese equities, scan technical signals, and run paper-trading workflows.

## Overview

The library combines market data, main-board and all-market strategies, paper trading, and additional MACD and short-term methods documented by the author.

## Scenarios

- Inspect stock data and strategy signals
- Backtest and review a paper account

## Usage

Install the author’s core and additional public Skills for the chosen agent. Use paper-trading outputs to inspect assumptions, positions, and exit signals.
