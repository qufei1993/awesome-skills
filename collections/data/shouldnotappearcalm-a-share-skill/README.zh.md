# A 股分析与模拟交易技能

分析中国股票、筛选技术信号并开展模拟交易。

## 合集介绍

本库结合市场数据、主板与全市场策略、模拟交易，以及作者记录的其他 MACD 和短线方法。

## 适用场景

- 检查股票数据与策略信号
- 回测并检查模拟账户

## 使用建议

按所选 Agent 安装作者的核心及其他公开技能，通过模拟交易输出检查假设、仓位与退出信号。
