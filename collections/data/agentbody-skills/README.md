# AgentBody Skills

Research public platforms and process documents through AgentBody APIs.

## Overview

AgentBody’s complete router-led catalog covers social and people research, video transcripts, document parsing, keyword data, and writing revision. All specialist Skills use the same API service.

## Scenarios

- Research public social-platform content
- Extract video transcripts and document text
- Collect people or SEO data

## Usage

Configure AgentBody access through the upstream setup, then provide the source URL or research question. Use the router or specialist and check the selected API’s input and usage requirements.
