# AgentBody 技能

通过 AgentBody API 研究公开平台并处理文档。

## 合集介绍

AgentBody 完整路由式目录覆盖社交与人物研究、视频逐字稿、文档解析、关键词数据和改稿，所有专项技能连接同一 API 服务。

## 适用场景

- 研究公开社交平台内容
- 提取视频逐字稿和文档文字
- 收集人物或 SEO 数据

## 使用建议

按上游方式配置 AgentBody 访问，再提供来源网址或研究问题。使用路由或专项技能，并检查所选 API 的输入与用量要求。
