# Xberg Document Intelligence Skills

Extract and analyze documents with Xberg’s polyglot processing tools.

## Overview

The official plugin Skills guide document extraction, configuration, OCR, server integration, and related Xberg workflows across supported formats.

## Scenarios

- Extract text, tables, images, and metadata
- Integrate document processing into applications

## Usage

Install Xberg through the required binding or CLI and use its official plugin. Keep the configured extraction runtime available; other plugin Skill trees are host mirrors.
