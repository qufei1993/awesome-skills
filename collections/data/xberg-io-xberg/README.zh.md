# Xberg 文档智能技能合集

通过 Xberg 多语言处理工具提取和分析文档。

## 合集介绍

官方插件技能指导文档提取、配置、OCR、服务集成以及支持格式的相关处理流程。

## 适用场景

- 提取文本、表格、图片和元数据
- 将文档处理接入应用

## 使用建议

安装所需 Xberg 语言绑定或命令行工具并使用官方插件。准备提取运行环境，其他插件技能目录是宿主镜像。
