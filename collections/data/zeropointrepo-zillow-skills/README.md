# Zillow Property Data Skills

Query property estimates, listings, comparables, and history through Zillapi.

![Zillow Property Data Skills — original project cover](<https://raw.githubusercontent.com/zeropointrepo/zillow-skills/fb2af78daff329bdf1861764358f7cfe97c799c8/assets/zillapi-agent-skill.jpg>)

## Overview

The author’s three-Skill package provides a complete property toolkit plus focused search and Zestimate workflows. Zillapi is an independent service supplying Zillow-sourced data.

## Scenarios

- Look up property details and estimates
- Search sale or rental listings
- Collect comparables and price history

## Usage

Configure a Zillapi key and provide an address, property URL, or search area. Use zillow-full for broad data, or the focused variants for a narrow response.
