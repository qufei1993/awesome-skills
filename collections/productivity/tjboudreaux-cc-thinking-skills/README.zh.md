# 结构化思考技能合集

为决策与复杂问题选择并应用明确推理流程。

## 合集介绍

目录通过第一性原理、科学检验、OODA 和事前复盘等模型，覆盖诊断、系统、不确定性、风险、策略、创新和执行。

## 适用场景

- 诊断原因并比较不同解释
- 评估有风险或可撤回的决策
- 制定策略并检验想法

## 使用建议

提供决策与证据，再由模型路由选择合适框架或组合，按模型流程推进并保留假设与结果。
