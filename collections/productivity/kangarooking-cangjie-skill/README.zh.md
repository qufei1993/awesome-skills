# 纳瓦尔宝典技能包

通过已发布的纳瓦尔路由和六项晋级技能处理决策与工作问题。

## 合集介绍

采用作者 BUILD_MANIFEST 声明的 dist/naval-almanack-pack 七入口完整版本。

## 适用场景

- 比较决策选择
- 安排专注工作

## 使用建议

连同引用资料使用 pack 版本；作者要求 single 与 pack 二选一，避免同时安装。
