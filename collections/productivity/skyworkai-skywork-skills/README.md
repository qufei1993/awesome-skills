# Skywork Skills

Create presentations, documents, spreadsheets, images, research, and music with Skywork.

## Overview

The official AI office-suite pack supplies six product workflows to compatible agents, spanning office artifacts and creative or research outputs.

## Scenarios

- Prepare a presentation or report
- Create spreadsheets and research materials

## Usage

Install the repository through the supported agent path and follow the chosen Skywork product’s service setup. State the requested artifact and source materials.
