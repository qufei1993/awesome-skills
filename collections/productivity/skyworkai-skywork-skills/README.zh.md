# Skywork 技能

用 Skywork 制作演示文稿、文档、表格、图片、研究与音乐。

## 合集介绍

官方 AI 办公套件技能包为兼容 Agent 提供六个产品流程，涵盖办公成果、创意内容与研究输出。

## 适用场景

- 准备演示文稿或报告
- 制作表格与研究材料

## 使用建议

通过受支持 Agent 方式安装仓库，并按所选 Skywork 产品配置服务，说明所需成果与源资料。
