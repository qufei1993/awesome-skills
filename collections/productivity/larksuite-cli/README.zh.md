# 飞书命令行技能合集

通过官方命令行流程操作 Lark 与飞书业务服务。

## 合集介绍

Larksuite 的公开技能涵盖消息、文档、多维表格、电子表格、日历、邮件、审批、会议和跨服务报告。

## 适用场景

- 管理消息、邮件和日程
- 编辑文档、电子表格与多维表格记录
- 整理会议总结与站会报告

## 使用建议

先安装 lark-cli，配置应用并按所需权限登录。使用共享技能与领域辅助技能后，再组合跨服务流程。
