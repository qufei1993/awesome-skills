# Lark CLI Skills

Use Lark and Feishu business services through the official command-line workflows.

## Overview

Larksuite’s public Skills cover messages, documents, Base, Sheets, calendars, mail, approvals, meetings, and cross-service reporting.

## Scenarios

- Manage messages, mail, and schedules
- Edit documents, spreadsheets, and Base records
- Prepare meeting summaries and standup reports

## Usage

Install lark-cli, configure an app, and log in with the required scopes. Use the shared Skill and domain helper before composing a multi-service workflow.
