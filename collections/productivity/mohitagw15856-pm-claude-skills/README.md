# PM Professional Skills

Complete professional and everyday tasks using structured frameworks and reusable outputs.

## Overview

The author’s canonical professional library spans product work, engineering, research, operations, career, communication, and life administration, with output templates and quality checks.

## Scenarios

- Prepare a PRD, research synthesis, or stakeholder update
- Plan operations, career moves, and practical paperwork
- Analyze a decision using a documented framework

## Usage

Use the upstream installer and select a task or bundle from the catalog. Provide the real context and source documents, then use the author’s workflows to connect related tasks.
