# Notion MCP Workflow Skills

Capture knowledge, plan projects, research, and manage Notion trackers.

## Overview

Includes the complete six-skill portable MCP client package under skills/mcp-clients.

## Scenarios

- Organize Notion knowledge
- Turn a specification into project work

## Usage

Connect an authorized Notion MCP client and choose the workflow that matches the task. App and Workers SDK loaders belong to separate product scopes.
