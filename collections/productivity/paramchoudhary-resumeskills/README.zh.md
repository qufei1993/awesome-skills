# 简历与职业技能合集

准备真实准确的简历、申请、面试与职业决策。

## 合集介绍

合集涵盖 ATS 审查、职位适配、经历要点、求职信、LinkedIn、作品集、学术与高管简历、面试和待遇谈判。

## 适用场景

- 按职位描述调整简历
- 准备面试故事与申请材料
- 比较录用方案并规划谈判

## 使用建议

提供真实简历、职位要求和职业背景，依次开展分析、材料适配和面试准备，保持经历信息准确。
