# Daymade Workflow Skills

Handle development, documents, research, media, and desktop work through Daymade’s marketplace.

## Overview

The complete published marketplace groups Skill creation and governance, Claude and Codex operations, office files, audio, financial research, macOS tasks, and focused workflow plugins.

## Scenarios

- Maintain coding-agent workflows and project tools
- Process documents, meeting audio, and research materials
- Troubleshoot desktop and cloud tasks

## Usage

Install the upstream marketplace suites or individual plugins and provide the task materials. Each workflow has its own CLI, runtime, platform, or service requirements; keep suite routers and support files together.
