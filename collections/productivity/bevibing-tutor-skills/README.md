# Obsidian StudyVault Tutor Skills

Turn documents or code into an Obsidian study vault and test comprehension.

## Overview

The two-part suite builds structured, linked study notes and then runs graded question rounds with concept tracking and targeted review.

## Scenarios

- Create a study vault from books, documents, or a codebase
- Quiz yourself and review weak concepts

## Usage

Use tutor-setup with the source materials, then tutor for study sessions. Prepare the local Obsidian vault and the upstream document extraction dependencies required by the input format.
