# Obsidian 学习仓库辅导技能

将文档或代码转为 Obsidian 学习仓库并检验理解。

## 合集介绍

两项技能先创建结构化互链笔记，再开展带评分、概念跟踪和专项复习的问答轮次。

## 适用场景

- 从书籍、文档或代码库创建学习仓库
- 通过测验复习薄弱概念

## 使用建议

先用 tutor-setup 处理源材料，再通过 tutor 开展学习。准备本地 Obsidian 仓库，以及输入格式所需的上游文档提取依赖。
