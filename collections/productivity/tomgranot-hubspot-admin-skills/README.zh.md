# HubSpot 管理技能

审查、清理、丰富、评分、自动化并维护 HubSpot CRM。

## 合集介绍

Tom Granot 三十七技能工具包将门户审查、清理计划、数据整洁、信息丰富、分群、自动化与持续管理分组。

## 适用场景

- 审查门户并安排清理优先级
- 维护 CRM 信息与自动化

## 使用建议

连接 HubSpot，审查门户并生成清理计划，再逐项执行技能；较大改动前使用作者的自带沙盒验证。
