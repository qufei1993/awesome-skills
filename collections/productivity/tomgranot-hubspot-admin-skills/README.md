# HubSpot Admin Skills

Audit, clean, enrich, score, automate, and maintain a HubSpot CRM.

## Overview

Tom Granot’s thirty-seven-Skill toolkit groups portal audits, cleanup plans, database hygiene, enrichment, segmentation, automations, and ongoing administration.

## Scenarios

- Audit a portal and prioritize cleanup
- Maintain CRM enrichment and automations

## Usage

Connect HubSpot, audit the portal, generate a cleanup plan, then execute Skills one at a time. Use the author’s bring-your-own sandbox self-test before broader changes.
