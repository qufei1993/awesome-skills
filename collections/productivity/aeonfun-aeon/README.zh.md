# Aeon 自主 Agent 技能库

通过 Aeon Agent 框架安排仓库工作、研究与周期任务。

## 合集介绍

Aeon 的业务技能库在受支持的编程宿主中驱动定时 GitHub Actions 运行，作者通过可配置的 Agent 实例连接功能交付、研究、维护、部署与沟通。

## 适用场景

- 安排仓库维护任务
- 运行周期研究摘要
- 把功能工作交给 Agent 实例

## 使用建议

通过 Aeon Connect 或终端配置自己的 Aeon 仓库、模型连接与所选技能；运行依赖 GitHub Actions 及选定的模型服务。
