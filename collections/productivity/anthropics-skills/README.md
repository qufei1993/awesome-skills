# Anthropic Agent Skills

Create documents, visual work, and technical artifacts using Anthropic’s public Skills.

## Overview

The repository demonstrates creative, communication, development, and document workflows. It includes the document Skills used by Claude alongside self-contained examples.

## Scenarios

- Edit Word, PDF, spreadsheet, and presentation files
- Build visual artifacts and interface prototypes
- Test web apps and build MCP integrations

## Usage

Use the upstream document-skills or example-skills plugin, or install the needed folders. Keep bundled scripts and assets with each Skill and check its own license.
