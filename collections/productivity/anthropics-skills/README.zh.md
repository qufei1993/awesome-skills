# Anthropic 技能合集

使用 Anthropic 公开技能制作文档、视觉作品和技术产物。

## 合集介绍

仓库展示创意、沟通、开发和文档处理流程，既包含 Claude 使用的文档技能，也包含可独立使用的示例技能。

## 适用场景

- 编辑 Word、PDF、电子表格和演示文稿
- 制作视觉作品与界面原型
- 测试网页并开发 MCP 集成

## 使用建议

可按上游说明安装 document-skills 或 example-skills 插件，也可安装所需技能目录。保留配套脚本与素材，并查看各技能的许可。
