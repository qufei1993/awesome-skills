# PPTX Deck Creation Kit

通过明确幻灯片规格和原生对象制作可编辑 PowerPoint。

## 合集介绍

作者完整 Copilot 插件包包含文稿背景、页面规格、视觉素材、参考文稿分析和质量关卡；市场暂存与单技能精简版属于其他发行。

## 适用场景

- 规划和制作可编辑幻灯片
- 分析参考文稿和设计风格
- 检查布局与 PowerPoint 包质量

## 使用建议

使用上游完整插件保留协调 Agent 和设计配置，提供内容、受众及参考文稿，再准备文档规定的 PowerPoint 工具。
