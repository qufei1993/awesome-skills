# PPTX Deck Creation Kit

Create editable PowerPoint decks with explicit slide specifications and native objects.

## Overview

The author’s full Copilot plugin package includes deck context, slide specifications, visual assets, reference-deck analysis, and quality gates. Marketplace staging and compact single-Skill variants are separate distributions.

## Scenarios

- Plan and build an editable slide deck
- Analyze a reference deck and design profile
- Check layout and PowerPoint package quality

## Usage

Use the upstream full plugin for its coordinating agent and design profiles. Provide the content, audience, and reference deck; prepare the documented PowerPoint tooling for generation and analysis.
