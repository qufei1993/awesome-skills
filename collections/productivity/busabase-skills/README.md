# Busabase Skills

Operate an approval-based knowledge workspace and build native workspace applications.

## Overview

Busabase’s current public two-Skill package covers workspace records and change requests plus app creation with bounded data access and reviewable AirApps. Host plugins distribute the same pair.

## Scenarios

- Inspect workspace bases and records
- Propose and merge reviewed changes
- Create a workspace application

## Usage

Configure Busabase HTTP access using upstream setup. Provide the workspace task or app brief and follow its proposal, review, and approved-merge workflow.
