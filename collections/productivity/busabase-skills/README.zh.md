# Busabase 技能

操作基于审批的知识工作区，并构建原生工作区应用。

## 合集介绍

Busabase 当前公开双技能包包含工作区记录与变更请求，以及有边界的数据访问和可评审 AirApp 应用创建；宿主插件分发同一对技能。

## 适用场景

- 查看工作区数据与记录
- 提出并合并已评审变更
- 创建工作区应用

## 使用建议

按上游配置 Busabase HTTP 访问，提供工作区任务或应用简报，并遵循提案、评审和已批准合并流程。
