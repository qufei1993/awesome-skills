# Composio Claude Skills

Combine practical document, development, and app automation workflows from Composio’s library.

![Original project cover](https://github.com/user-attachments/assets/e91255af-e4ba-4d71-b1a8-bd081e8a234a)

## Overview

The repository’s local Skill packages cover everyday work and a large SaaS automation catalog. App workflows use Composio’s tool connections and authentication.

## Scenarios

- Automate CRM and project tracking tasks
- Work with email, calendars, and cloud files
- Prepare documents and developer workflow artifacts

## Usage

Install the local Skill package you need and follow the upstream connection guide for Rube MCP or Composio. Authenticate the relevant apps before running their workflows.
