# Composio Claude 技能合集

使用 Composio 技能库完成文档、开发和应用自动化任务。

![原项目封面](https://github.com/user-attachments/assets/e91255af-e4ba-4d71-b1a8-bd081e8a234a)

## 合集介绍

仓库提供日常工作技能与大型 SaaS 自动化技能目录，应用流程依赖 Composio 的工具连接和授权。

## 适用场景

- 自动处理 CRM 与项目跟踪任务
- 操作邮件、日历和云端文件
- 制作文档与开发流程产物

## 使用建议

安装所需本地技能包，并按上游说明配置 Rube MCP 或 Composio 连接。执行应用流程前先授权对应应用。
