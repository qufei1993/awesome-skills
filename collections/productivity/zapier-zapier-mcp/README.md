# Zapier MCP Plugin Skills

Set up Zapier MCP and carry out role-specific work across connected applications.

## Overview

The distribution bundles guided onboarding, a first-use demo, and role-tailored Skills on top of the Zapier MCP service connection.

## Scenarios

- Connect an AI client to Zapier applications
- Build a cross-application workflow

## Usage

Connect the client using its Zapier MCP server URL and install the plugin where supported. Authorize the applications and actions needed for the workflow.
