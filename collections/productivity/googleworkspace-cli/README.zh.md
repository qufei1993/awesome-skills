# Google Workspace 命令行技能合集

操作 Workspace 服务并组合成日常办公流程。

## 合集介绍

gws 技能库提供接口专项技能、任务辅助和配方，覆盖 Gmail、Drive、Docs、Calendar、Sheets 等服务。

## 适用场景

- 整理邮件并转为待办
- 准备会议与日历安排
- 更新云端文档和电子表格

## 使用建议

安装 gws，准备 Google Cloud OAuth 项目并授权账号。先完成共享设置，再使用服务辅助技能或工作配方。
