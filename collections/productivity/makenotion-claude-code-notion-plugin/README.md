# Notion Workspace Plugin Skills

Capture knowledge, prepare meetings, document research, and implement specifications in Notion.

## Overview

The official Claude Code plugin packages the four Notion Cookbook Skills together with slash commands and the hosted Notion MCP connection.

## Scenarios

- Turn meetings into structured workspace notes
- Move a Notion specification into an implementation plan

## Usage

Install the Notion workspace plugin, restart Claude Code, and authorize the Notion MCP connection before accessing workspace content.
