# Notion 工作区插件技能

在 Notion 中沉淀知识、准备会议、记录研究与落实规格。

## 合集介绍

官方 Claude Code 插件把四个 Notion Cookbook 技能与快捷命令、托管 Notion MCP 连接打包提供。

## 适用场景

- 把会议转成结构化工作区笔记
- 把 Notion 规格转为实现计划

## 使用建议

安装 Notion 工作区插件，重启 Claude Code，并在访问工作区内容前授权 Notion MCP 连接。
