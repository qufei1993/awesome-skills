## 合集介绍

完整五技能纯指令包覆盖技术校对、提交消息、会议纪要、代码评审和深入研究，每个流程配有简短清单与示例。

## 适用场景

- 校对技术文档
- 将笔记转成纪要或提交消息
- 组织代码评审和研究报告

## 使用建议

提供原文、笔记、差异或研究问题，使用对应技能，并明确缺失的负责人、日期和证据。
