# Tapestry Skills

Turn articles and videos into learning plans and concrete next actions.

## Overview

Tapestry combines content extraction with Learn This orchestration, Ship-Learn-Next planning, scrum advice, session logs, and unblock workflows.

## Scenarios

- Extract a video or article for study
- Convert lessons into a shipping plan

## Usage

Start with learn-this and a URL. Video extraction uses yt-dlp, with optional Whisper transcription; article extraction supports reader-cli or trafilatura.
