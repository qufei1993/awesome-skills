# Tapestry 技能

把文章与视频转成学习计划和具体行动。

## 合集介绍

Tapestry 将内容提取与 Learn This 编排、Ship-Learn-Next 规划、Scrum 建议、会话记录及解阻流程结合起来。

## 适用场景

- 提取视频或文章供学习
- 把学习内容转成交付计划

## 使用建议

从 learn-this 和一个链接开始；视频提取依赖 yt-dlp，可选 Whisper 转录，文章提取支持 reader-cli 或 trafilatura。
