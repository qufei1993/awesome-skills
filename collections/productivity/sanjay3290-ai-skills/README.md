# AI Agent Skills by Sanjay

Connect databases, workspace services, research, media tools, and delegated coding tasks.

## Overview

The portable pack brings together read-only database analysis, Google Workspace, project services, knowledge tools, model-backed research, and asynchronous coding assistants.

## Scenarios

- Query a database and prepare research
- Manage workspace documents and project work

## Usage

Install the author’s full plugin or select a task Skill. Configure its database driver or service authentication; Google Workspace Skills require a Workspace account rather than personal Gmail.
