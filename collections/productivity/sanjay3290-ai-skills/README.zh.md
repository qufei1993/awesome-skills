# Sanjay AI Agent 技能

连接数据库、工作区服务、研究、媒体工具与委派编程任务。

## 合集介绍

可移植技能包汇集只读数据库分析、Google Workspace、项目服务、知识工具、模型研究与异步编程助手。

## 适用场景

- 查询数据库并准备研究
- 管理工作区文档与项目工作

## 使用建议

安装作者完整插件或选择任务技能，配置所需数据库驱动或服务认证；Google Workspace 技能要求 Workspace 账号，不支持个人 Gmail。
