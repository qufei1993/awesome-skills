# Zinc 购物技能

通过 Zinc API 搜索零售商品并管理订单。

## 合集介绍

Zinc 完整包包含通用结账、零售商专用结账和作者的配送主题变体，支持商品查询、购买、追踪、退货与订单管理。

## 适用场景

- 跨支持的零售商查找商品
- 准备结账和配送信息
- 追踪或管理已有订单

## 使用建议

配置 Zinc API 访问并提供商品网址或搜索条件。广泛场景使用 universal-checkout，购买流程应提供所需订单信息。
