# Zinc Checkout Skills

Search retailer products and manage orders through the Zinc API.

## Overview

Zinc’s complete package includes universal checkout, retailer-specific checkout guides, and the author’s delivery-themed variants. It supports product lookup, purchase, tracking, returns, and order management.

## Scenarios

- Find products across supported retailers
- Prepare checkout and delivery details
- Track or manage existing orders

## Usage

Configure Zinc API access and provide the product URL or search criteria. Use universal-checkout for broad coverage and supply the required order details for a purchase workflow.
