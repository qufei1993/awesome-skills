# Agent Knowledge 项目知识技能

用可移植的 Markdown 知识包维护关联项目百科。

## 合集介绍

Agent Knowledge 基于 Open Knowledge Format 提供初始化、导入、文档、查询、检查和可视化；完整技能包共享规格、信任模型、模板与辅助工具。

## 适用场景

- 建立项目知识包
- 整合文档并回答带引用的问题
- 发现过时结论和孤立页面

## 使用建议

先初始化知识包并加入项目资料，再随知识增长使用查询和健康检查。保留共享 kb 目录；Janet CLI 属于独立包。
