# Agent Knowledge Skills

Maintain a connected project wiki in portable Markdown knowledge bundles.

## Overview

Agent Knowledge uses Open Knowledge Format for initialization, ingestion, documentation, queries, linting, and visualization. Its complete portable Skills share a specification, trust model, templates, and helpers.

## Scenarios

- Build a project knowledge bundle
- Integrate documents and answer cited questions
- Find stale claims and orphaned pages

## Usage

Initialize the bundle, add project sources, and use queries or health checks as knowledge grows. Retain the shared kb directory; the Janet CLI is a separate package.
