# Emulo Profile Skills

Turn selected coding-agent session evidence into a reusable personal working profile.

## Overview

Emulo’s public plugin separates mining, work, design, writing, and video guidance so the host loads the profile relevant to a task. Dated user quotes back the generated rules.

## Scenarios

- Identify repeated corrections across sessions
- Build task-specific personal agent guidance

## Usage

Install the plugin and select the session sources to analyze. Review the usage report and quoted evidence before adopting the mined profile.
