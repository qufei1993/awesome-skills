# Emulo 工作画像技能

把选定编程 Agent 会话证据转为可复用的个人工作画像。

## 合集介绍

Emulo 正式插件把挖掘、工作、设计、写作与视频指引分开，让宿主加载适合任务的画像，并用带日期的用户引文支撑生成规则。

## 适用场景

- 识别会话中反复出现的纠正
- 建立面向任务的个人 Agent 指引

## 使用建议

安装插件并选择要分析的会话来源；采用挖掘画像前先检查使用报告与引用证据。
