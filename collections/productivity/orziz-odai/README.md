The canonical pack contains the unified odai entry, dependent odai-orchestration routing, and the repository’s additional public Skill. Governance depth adapts to the task.

Start with /odai and the desired outcome. Install orchestration alongside odai when needed; the author’s all install exposes the full canonical library.
