# Memory Kit 记忆技能

跨 Agent 会话保存经过确认且带日期的项目记忆。

## 合集介绍

Memory Kit 连接配置、会话交接、文档、记忆审查、代码同步、编排与 QA；完整插件技能配合钩子和模板管理不同客户的记忆。

## 适用场景

- 记录经过确认的项目记忆
- 通过会话交接继续工作
- 审查记忆并同步项目知识

## 使用建议

在工作目录运行上游插件配置并审阅拟议修改。不同客户的记忆分开保存；需要自动注入上下文时使用完整插件。
