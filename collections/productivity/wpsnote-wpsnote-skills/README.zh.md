# WPS 笔记技能

通过 WPS 笔记捕获、整理、创作与学习。

## 合集介绍

作者生态以 wps-note 为基础，覆盖笔记操作、写作、搜索、捕获、灵感、学习与长篇创作。

## 适用场景

- 整理捕获资料并检索笔记
- 制作学习笔记与长篇草稿

## 使用建议

安装技能组，并从桌面应用配置 WPS 笔记 CLI 或 MCP 服务；先使用核心笔记能力，再串联内容或学习任务。
