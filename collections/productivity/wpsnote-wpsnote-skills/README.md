# WPS Note Skills

Capture, organize, create, and learn through WPS Note.

## Overview

The author’s ecosystem builds on wps-note and covers note operations, writing, search, capture, inspiration, study, and long-form creation.

## Scenarios

- Organize captured material and retrieve notes
- Develop study notes and long-form drafts

## Usage

Install the Skill groups and set up the WPS Note CLI or MCP server from the desktop app. Use the core note capability before chaining content or learning tasks.
