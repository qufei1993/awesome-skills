# SlideOps Skills

Generate repository-backed slide decks and detect when their claims drift from code.

## Overview

SlideOps packages deck creation with slide-to-PDF export. It connects slide claims to source citations, checks freshness, and prepares focused repair work for changed slides.

## Scenarios

- Explain a repository with a slide deck
- Check whether existing slides still match code
- Export a deck to PDF

## Usage

Provide a repository and the audience for the deck. Keep the generated deck’s citations, then use the upstream freshness checker after code changes and rebuild affected slides.
