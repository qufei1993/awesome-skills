# SlideOps 演示技能

生成有代码依据的演示文稿，并检查内容何时与仓库发生偏差。

![SlideOps 演示技能 官方项目封面](<https://raw.githubusercontent.com/glukicov/slideops/8bcb4257132939e7de54e493fa9d83e06fb759d4/docs/social-preview.png>)

## 合集介绍

SlideOps 将文稿制作与 PDF 导出组合起来，为幻灯片结论关联源码引用，检查内容是否仍然有效，并为发生变化的页面准备修订任务。

## 适用场景

- 用演示文稿介绍代码仓库
- 检查已有幻灯片是否仍与代码一致
- 将文稿导出为 PDF

## 使用建议

提供仓库和演示对象，保留生成文稿中的源码引用。代码修改后按上游方式检查新鲜度，并重新构建受影响的页面。
