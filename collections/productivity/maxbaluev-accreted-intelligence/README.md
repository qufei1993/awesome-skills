# Accreted Intelligence Skills

Use a local work model to preserve commitments, task frames, and outcome-based learning.

## Overview

AccInt’s complete reference-host Skill package contains commitments, frames, and solve workflows. The underlying local MCP daemon and retrieval model preserve work context and learn from real outcomes.

## Scenarios

- Frame and solve a continuing task
- Track commitments across sessions
- Retain lessons from task outcomes

## Usage

Install the upstream AccInt daemon and connect the reference Claude host. Prepare the hardware and storage for its selected embedding model; keep the local work state available between sessions.
