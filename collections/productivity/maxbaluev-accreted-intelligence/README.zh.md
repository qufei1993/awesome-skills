# Accreted Intelligence 技能

通过本地工作模型保存承诺、任务框架与基于结果的经验。

## 合集介绍

AccInt 完整参考宿主技能包包含 commitments、frames 和 solve；底层本地 MCP 服务与检索模型保留工作背景并从真实结果学习。

## 适用场景

- 形成任务框架并继续求解
- 跨会话跟踪工作承诺
- 保存任务结果中的经验

## 使用建议

安装上游 AccInt 服务并连接参考 Claude 宿主。为其选择的嵌入模型准备硬件和存储，并保留跨会话本地状态。
