# TikTok 短视频技能

结合字幕、倒计时和下三分之一图形制作短视频。

## 合集介绍

iart.ai 的四技能包将短视频结构、动态字幕、倒计时和下三分之一信息图形组合起来，适用于 TikTok、Reels 和 Shorts。

## 适用场景

- 规划短视频结构
- 制作易读的动态字幕
- 添加倒计时或人物信息图形

## 使用建议

提供视频素材或脚本、目标平台和画面比例。先规划开场与安全区域，再在手机尺寸下检查字幕时序和可读性。
