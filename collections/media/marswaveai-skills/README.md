# MarsWave Skills

Create voice, podcasts, video, slides, music, and creator assets with MarsWave.

## Overview

The author’s pack combines ListenHub content workflows with COLA avatar assets, voice generation, transcription, media generation, and content parsing.

## Scenarios

- Produce a podcast or narrated explainer
- Create an avatar and platform-ready content

## Usage

Install the pack and authenticate ListenHub CLI. Content-parser and creator require a ListenHub API key; COLA avatar work requires Python 3.10 or later and Pillow.
