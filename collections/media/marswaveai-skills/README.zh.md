# MarsWave 技能

用 MarsWave 制作语音、播客、视频、演示、音乐与创作者素材。

## 合集介绍

作者技能包把 ListenHub 内容流程与 COLA 形象素材、语音生成、转录、媒体生成及内容解析结合。

## 适用场景

- 制作播客或带旁白讲解
- 制作形象与平台内容

## 使用建议

安装技能包并认证 ListenHub CLI；content-parser 与 creator 需要 ListenHub API 密钥，COLA 形象工作需要 Python 3.10 及以上与 Pillow。
