# Sweety 手绘口播视频

把主题、文章或讲解稿制作成边画边讲的有声视频。

## 合集介绍

threerocks 开发的手绘视频技能，覆盖口播撰写、分镜设计、插画生成、逐笔描线、上色、手写文字、配音对齐与字幕，交付 MP4、封面、字幕、口播稿和检查记录。有轮廓的画风逐笔绘制，其他画风用笔刷逐步揭示插画。主项目采用 MIT 许可证，内置依赖与素材保留各自的许可条件。

## 适用场景

- 用手绘与旁白讲解知识
- 把文章或故事改编成视频
- 制作教学或产品原理讲解
- 复用已认可素材修改字幕或画面

## 使用建议

在 macOS 或 Linux 上使用 Codex 或 Claude Code，准备生图能力、Python、FFmpeg、适用字体，以及已配置的配音后端或现成录音。提供主题、受众和目标时长即可；默认尺寸为 1920×1080、30fps，制作竖屏视频时需明确指定 9:16。画风与声音可让 Agent 自动选择，也可自行指定。制作前按上游说明完成环境配置与检查。
