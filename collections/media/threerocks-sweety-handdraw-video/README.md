# Sweety Handdraw Video

Turn a topic, article, or script into a narrated hand-drawn explainer video.

## Overview

By threerocks, this Skill combines script writing, storyboards, generated illustrations, stroke animation, coloring, handwritten text, narration alignment, and subtitles. It delivers an MP4, cover, subtitles, script, and review records. Outlined styles use stroke drawing; other styles reveal the illustration with a brush. The main project uses the MIT License; bundled dependencies and assets retain their own terms.

## Scenarios

- Explain a concept with drawings and narration
- Adapt an article or story into a video
- Create narrated teaching or product explainers
- Revise subtitles or visuals while reusing approved assets

## Usage

Use Codex or Claude Code on macOS or Linux with image generation, Python, FFmpeg, suitable fonts, and a configured narration backend or supplied recording. Provide the topic, audience, and target duration; request 9:16 explicitly for vertical videos because the default is 1920×1080 at 30 fps. Let the agent choose the style and voice, or specify your preferences. Follow the upstream setup and environment checks before production.
