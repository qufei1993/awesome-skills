# Perso Dubbing Skills

Dub videos, prepare subtitles, and create short clips through Perso workflows.

![Perso Dubbing Skills — original project cover](<https://raw.githubusercontent.com/perso-ai/perso-dubbing-plugin/c12b2f5840af5bf946360832d7e0c4a34c80c9fe/docs/media/og-en.png>)

## Overview

The Perso package combines dubbing, srt, and clip Skills. It covers translation and lip-sync, speech transcription, styled subtitles, subtitle translation, short clips, and voice separation.

## Scenarios

- Translate and dub a video
- Create or style subtitle files
- Cut short clips from existing footage

## Usage

Install the upstream plugin or host-aware installer and provide the source video and target language. Configure a Perso API key for hosted dubbing; check the selected workflow’s local media requirements.
