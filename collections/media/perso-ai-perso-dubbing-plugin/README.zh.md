# Perso 视频配音技能

通过 Perso 流程为视频配音、处理字幕并制作短片。

## 合集介绍

Perso 完整包包含 dubbing、srt 和 clip 三个技能，覆盖翻译配音与口型同步、语音转写、样式字幕、字幕翻译、短片剪辑和声音分离。

## 适用场景

- 翻译视频并重新配音
- 生成或调整字幕文件
- 从现有视频中剪出短片

## 使用建议

使用上游插件或宿主识别安装器，提供源视频与目标语言。在线配音需要 Perso API 密钥；本地媒体处理按所选流程准备环境。
