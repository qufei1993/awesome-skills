# Black Forest Labs FLUX 技能

编写 FLUX 图片与视频提示，并集成 BFL 生成 API。

## 合集介绍

官方套件结合图片实践与 API 集成，以及 FLUX 3 路由、提示诊断、电影片段、关键帧、音频、档案风格与产品广告。

## 适用场景

- 生成图片或产品视频
- 调试提示词并轮询生成作业

## 使用建议

安装技能包并配置 BFL API 访问，先使用视频路由或图片指引，再按镜头和制作阶段选择专用技能。
