# Black Forest Labs FLUX Skills

Prompt FLUX images and video and integrate the BFL generation API.

## Overview

The official suite combines image practices and API integration with FLUX 3 routing, prompt diagnosis, cinematic inserts, keyframes, audio, archival looks, and product advertising.

## Scenarios

- Generate an image or product video
- Debug a prompt and poll generation jobs

## Usage

Install the pack and configure BFL API access. Begin with the video router or image guidance, then use specialists for the requested shot and production stage.
