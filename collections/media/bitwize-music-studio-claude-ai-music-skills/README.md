# Claude AI Music Skills

Produce an album from concept and lyrics through mastering and release preparation.

## Overview

Bitwize’s plugin organizes AI music production around concept planning, Suno prompts, research, quality gates, audio tools, and release assets.

## Scenarios

- Plan an album and write track lyrics
- Prepare masters and release materials

## Usage

Install the bitwize-music plugin and describe the album concept. Follow its MCP and audio-tool setup and configure the model or music services needed for the chosen stages.
