# Claude AI 音乐技能

从概念与歌词推进到母带处理和发行准备，制作完整专辑。

## 合集介绍

Bitwize 插件围绕概念规划、Suno 提示词、研究、质量检查、音频工具与发行素材组织 AI 音乐制作。

## 适用场景

- 规划专辑并创作曲目歌词
- 准备母带与发行材料

## 使用建议

安装 bitwize-music 插件并描述专辑概念，按其说明配置 MCP 与音频工具，以及所选阶段需要的模型或音乐服务。
