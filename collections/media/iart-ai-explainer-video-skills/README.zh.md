# 讲解视频技能

把信息与数据制作成带旁白的讲解、回顾和动态示意图。

![讲解视频技能 官方项目封面](<https://raw.githubusercontent.com/iart-ai/explainer-video-skills/3e2d411b725d9a72939cf8e5eb81579e751373e7/showcase.gif>)

## 合集介绍

iart.ai 的五技能包组合讲解视频制作、个性化回顾、图解揭示、白板动画和等距场景，将脚本、分镜与视觉节奏、旁白连接起来。

## 适用场景

- 制作带旁白的讲解视频
- 批量生成年终回顾视频
- 制作动态图解或白板讲解

## 使用建议

提供核心信息、受众、源数据与目标画面比例。先确定脚本和分镜，再渲染并检查旁白、字幕的时序。
