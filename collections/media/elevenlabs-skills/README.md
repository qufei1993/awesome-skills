# ElevenLabs Skills

Build speech, audio, music, dubbing, and voice-agent features with ElevenLabs.

## Overview

The official developer pack covers generation, transcription, real-time speech, conversational agents, voice transformation, isolation, and API-key setup.

## Scenarios

- Build a conversational voice agent
- Generate or transform production audio

## Usage

Configure an ElevenLabs API key, then select the product Skill. JavaScript examples use @elevenlabs/elevenlabs-js; the author also documents Python and CLI integrations.
