# Claude Code Video Toolkit Skills

Turn a video concept into generated assets, recorded footage, and a rendered MP4.

![Claude Code Video Toolkit Skills — original project cover](<https://raw.githubusercontent.com/digitalsamba/claude-code-video-toolkit/2c99460a5d0cba253f983283fb8d0fb9c4edb4a7/assets/banner/toolkit-banner-poster.png>)

## Overview

Digital Samba’s workspace combines voice, music, image and video generation with FFmpeg, MoviePy, Remotion, browser recording, and cloud GPU workflows.

## Scenarios

- Create narration, music, and visual assets
- Record a browser demo and render a video

## Usage

Use the complete upstream workspace and begin with its setup and video commands. Prepare FFmpeg, the Python or JavaScript runtime, and the chosen media provider accounts or GPU access.
