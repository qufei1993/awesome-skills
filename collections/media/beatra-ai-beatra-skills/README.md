# Beatra Creative Skills

Plan, direct, and render images, video, music, and voice through Beatra.

## Overview

Beatra’s complete published catalog provides creative-production workflows for product visuals, portraits, avatars, storyboards, dubbing, audio, video, and task-specific deliverables. All source packages remain included.

## Scenarios

- Generate product and editorial images
- Produce voice, music, and avatar media
- Create videos and storyboards

## Usage

Prepare Python and a Beatra account following upstream setup. Provide the creative brief and assets; rendering uses account credits and the chosen workflow’s authorization step.
