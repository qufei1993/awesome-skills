# Beatra 创意技能

通过 Beatra 规划、指导和渲染图片、视频、音乐与声音。

## 合集介绍

Beatra 的完整正式目录提供产品视觉、肖像、数字人、分镜、配音、音频、视频及具体交付物的创意流程，保留所有源技能包。

## 适用场景

- 生成产品和编辑图片
- 制作声音、音乐与数字人素材
- 制作视频和分镜

## 使用建议

按上游方式准备 Python 与 Beatra 账号，提供创意简报和素材。渲染使用账户额度，并遵循所选流程的授权步骤。
