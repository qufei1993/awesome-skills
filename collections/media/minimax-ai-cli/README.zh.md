# MiniMax 命令行技能

通过 MiniMax 命令行接口完成多模态生成与分析。

## 合集介绍

MiniMax 命令行技能统一处理文本、图片、视频、语音、视觉和搜索任务。内部的 H3 视频流程支持图片和动作参考。

## 适用场景

- 按提示生成图像、视频或语音
- 使用图像或动作参考制作 H3 视频

## 使用建议

安装 mmx-cli 与上游技能包并配置 MiniMax 访问。命令行需要 Node.js 18 及以上版本和 MiniMax Token Plan，媒体输入遵循文档限制。
