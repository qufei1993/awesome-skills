# MiniMax CLI Skills

Use MiniMax’s command-line interface for multimodal generation and analysis.

## Overview

The MiniMax CLI Skill coordinates text, images, video, speech, vision, and search. Its internal H3 video workflow handles image and motion references.

## Scenarios

- Generate images, video, or speech from a prompt
- Create H3 videos from image or motion references

## Usage

Install mmx-cli and the upstream Skill package, then configure MiniMax access. The CLI requires Node.js 18 or later and a MiniMax Token Plan; follow the documented media input limits.
