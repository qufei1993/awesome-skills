# Product Promo Videos

Clarify the brief, build the visuals, and combine Skills to create a product promo video.

![GPT-generated concept cover for product video creation, not a finished case-study video](cover.png)

## Overview

Requirement clarification, video creation, and visual design Skills collected from 302 AI's public example. The Skills come from three repositories. Skills Hub prepared the accompanying installation list for the current versions; it is not a list of individually recommended items in the original article. This collection includes Skills only, without screen recording, music, post-production tools, sample projects, or finished videos.

## Scenarios

- Product demos
- Feature introductions
- Launch videos

## Usage

Discuss the selling points, audience, and video goals first. Ask the agent to build the visuals, then refine them with design guidance and previews. Prepare assets and other tools as your project requires.
