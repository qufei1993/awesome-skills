# JavaScript 动画技能

用代码绘制 Canvas 影片并合成配乐。

## 合集介绍

作者的双技能包组合 JavaScript 动画与 Web Audio 配乐流程，控制逐帧运动并检查音画同步，无需依赖生成图像素材。

## 适用场景

- 制作 Canvas 动画影片
- 用代码合成音乐和音效
- 渲染并检查音画同步

## 使用建议

提供故事、视觉风格、时长和输出格式，协调动画与配乐时序，再按上游流程渲染和检查同步。
