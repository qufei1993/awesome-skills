# JavaScript Animation Skills

Draw canvas films and synthesize their soundtracks in code.

## Overview

The author’s two-Skill package combines JavaScript animation with a Web Audio soundtrack workflow. It produces frame-controlled motion and checks audio-video synchronization without requiring generated image assets.

## Scenarios

- Create a canvas animation film
- Synthesize music and effects in code
- Render and check synchronized video

## Usage

Provide the story, visual style, duration, and output format. Keep the animation and soundtrack timing coordinated, then follow upstream rendering and synchronization checks.
