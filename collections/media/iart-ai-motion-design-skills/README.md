# Motion Design Skills

Plan and polish motion with timing, composition, color, and animation engines.

## Overview

This iart.ai package combines animation principles and art direction with After Effects, Remotion, beat editing, logo motion, and animated backgrounds. All nine public Skills remain together.

## Scenarios

- Improve timing and easing in animations
- Create branded logo reveals and backgrounds
- Build Remotion videos or After Effects sequences

## Usage

Provide the format, brand references, and motion problem. Select the appropriate engine workflow and prepare its runtime when rendering or editing video.
