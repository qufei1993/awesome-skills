# Noiz 语音与媒体技能

生成有表现力的语音、音乐、配音与对话音频。

## 合集介绍

Noiz 技能包覆盖语音合成、角色表达、新闻播客、视频翻译、音效、歌曲与音乐视频组装。

## 适用场景

- 制作对话播客
- 为视频配音或制作音乐视频

## 使用建议

安装所需 Noiz 技能并按需配置 Noiz API 密钥；音乐视频需要 ffmpeg，代码模式还需要 Node.js、Chrome 与 Git。
