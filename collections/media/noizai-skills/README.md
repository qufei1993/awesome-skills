# Noiz Voice & Media Skills

Generate expressive speech, music, dubbing, and conversational audio.

## Overview

Noiz’s pack covers text-to-speech, character delivery, news podcasts, video translation, sound effects, songs, and music-video assembly.

## Scenarios

- Create a conversational podcast
- Dub a video or produce a music video

## Usage

Install the relevant Noiz Skill and configure a Noiz API key where required. Music-video work needs ffmpeg; code mode also needs Node.js, Chrome, and Git.
