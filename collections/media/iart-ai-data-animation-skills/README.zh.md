# 数据动画技能

将结构化数据转成动态图表、信息图和演示视频。

![数据动画技能 官方项目封面](<https://raw.githubusercontent.com/iart-ai/data-animation-skills/8ce2709c3992490251e8a991535b1945f01c6865/showcase.gif>)

## 合集介绍

iart.ai 的三技能包组合图表动画、动态信息图与演示视频，强调运动过程中显示数值与源数据一致。

## 适用场景

- 制作动态图表
- 构建讲解型信息图
- 将演示文稿转成视频

## 使用建议

提供数据表、单位、叙事和输出格式。先确定刻度与数值，再添加动画，并核对渲染帧中的数据。
