# Remotion 技能合集

在 Remotion 中制作、预览和导出程序化视频。

## 合集介绍

Remotion 官方库涵盖合成标记、字幕、地图、多媒体、交互、Studio、渲染、SaaS 集成和升级。

## 适用场景

- 创建并制作视频动效
- 添加字幕、地图和媒体
- 预览并导出完成的视频

## 使用建议

可通过 remotion-best-practices 选择流程，也可调用具体技能。制作和渲染前准备 Remotion 项目与所需媒体。
