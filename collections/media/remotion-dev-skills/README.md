# Remotion Agent Skills

Create, preview, and render programmatic videos in Remotion.

## Overview

Remotion’s official library covers composition markup, captions, maps, multimedia, interactivity, Studio, rendering, SaaS integration, and upgrades.

## Scenarios

- Create and animate a video composition
- Add captions, maps, and media
- Preview and export a finished video

## Usage

Use remotion-best-practices to select the workflow or invoke a specific Skill. Prepare the Remotion project and required media before composition and rendering.
