# Timeline Studio 编辑技能

编辑可移植时间线项目，或操作浏览器中的实时编辑器。

![Timeline Studio 编辑技能 官方项目封面](<https://raw.githubusercontent.com/martindelophy/ai-video-editor/9514d6579eb8e1dfd27d737dbf0393d80372116f/docs/screenshots/editor-timeline.png>)

## 合集介绍

收录作者本地项目编辑技能及站点 discovery 单独发布的浏览器编辑技能。

## 适用场景

- 编辑时间线项目
- 预览并导出视频

## 使用建议

本地编辑按宿主依赖说明配置；浏览器流程需要 Timeline Studio 与 WebMCP 集成，此范围不含仓库插件开发技能。
