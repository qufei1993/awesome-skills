# TasteRay Skills

Understand user preferences through conversation and apply them to recommendations.

## Overview

TasteRay’s complete two-Skill package joins conversational elicitation with recommendations. It uses narrative and motivational-interviewing approaches, then connects preferences to supported recommendation categories.

## Scenarios

- Explore a person’s values and preferences
- Recommend items with reasons
- Personalize a conversational experience

## Usage

Begin with a gradual conversation rather than a survey. Preserve the resulting preference context; API-backed recommendations require the TasteRay integration setup described upstream.
