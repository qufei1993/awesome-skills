# TasteRay 偏好与推荐技能

通过对话理解用户偏好，并据此提供推荐。

## 合集介绍

TasteRay 的完整双技能包将对话式了解与推荐连接起来，借助叙事与动机式访谈方法形成偏好背景，再对应到支持的推荐类别。

## 适用场景

- 了解个人价值观与偏好
- 提供有理由的内容或商品推荐
- 设计个性化对话体验

## 使用建议

从循序渐进的对话开始并保留偏好背景。需要 API 推荐时按上游方式配置 TasteRay 集成。
