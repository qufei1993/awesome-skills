# Dean Peters Product Manager Skills

Apply product frameworks through component Skills and guided workshops.

## Overview

Dean Peters’s library covers problem framing, discovery, strategy, stakeholder work, prioritization, delivery, business health, and product leadership.

## Scenarios

- Frame problems and plan customer research
- Prioritize roadmaps and write product requirements
- Run strategy or stakeholder workshops

## Usage

Begin with the problem and available evidence, then choose a component or interactive workflow. Follow the upstream guide for the three Skill types and workshop format.
