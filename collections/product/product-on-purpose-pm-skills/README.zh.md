# Product on Purpose 产品管理技能

推动产品工作完成发现、定义、交付、衡量与迭代。

## 合集介绍

本库遵循 Triple Diamond 产品周期，并配合基础技能、冲刺工具组、生命周期工具与工作流串联，让 PRD、假设、用户故事和发现证据共享项目背景。

## 适用场景

- 定义客户问题与假设
- 准备 PRD 与交付用户故事
- 衡量结果并规划迭代

## 使用建议

按当前产品阶段选择单个 PM 技能或工作流命令。作者的 skills CLI 安装扫描正式 skills 目录；可选项目记忆让连续工作保持一致。
