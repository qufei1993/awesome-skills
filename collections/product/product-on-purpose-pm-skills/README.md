# Product on Purpose PM Skills

Carry product work through discovery, definition, delivery, measurement, and iteration.

## Overview

The library follows the Triple Diamond product cycle, supported by foundation Skills, sprint tool families, lifecycle utilities, and workflow chaining. PRDs, hypotheses, user stories, and discovery evidence share a project context.

## Scenarios

- Frame customer problems and hypotheses
- Prepare PRDs and delivery stories
- Measure outcomes and plan iterations

## Usage

Use an individual PM Skill or a workflow command for the current product phase. The author’s skills CLI install scans the published skills directory; optional project memory keeps recurring work consistent.
