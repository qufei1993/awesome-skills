# Startup Skills for Claude Code

Support startup work with customer thinking, media preparation, and X publishing.

## Overview

This five-Skill startup plugin combines customer empathy, image compression, video downloading, transcription, and X posts. All author-published Skills are retained.

## Scenarios

- Explore customer needs and journeys
- Prepare images and video transcripts
- Publish startup updates to X

## Usage

Install the upstream startup plugin and provide the customer context or media source. Follow the selected Skill’s tool and account setup before processing or publishing assets.
