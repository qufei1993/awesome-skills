# Claude Code 创业技能

结合客户思考、媒体处理与 X 发布辅助创业工作。

## 合集介绍

这套五技能插件组合客户共情、图片压缩、视频下载、转写和 X 发帖，保留作者全部公开技能。

## 适用场景

- 分析客户需求与使用旅程
- 准备图片与视频逐字稿
- 向 X 发布创业动态

## 使用建议

安装上游 startup 插件并提供客户背景或媒体来源。处理与发布素材前，按所选技能配置工具及账户。
