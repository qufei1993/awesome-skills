# Solo Skills

Handle daily founder work with decisions, customer replies, launch writing, and short reviews.

## Overview

The author’s seven-Skill package supports solo standups, shipping decisions, launch posts, release notes, customer email, bug clarification, and postmortems. It ships English and Chinese guidance.

## Scenarios

- Decide what to ship and plan the day
- Turn customer messages into replies or bug reports
- Write launches, release notes, and postmortems

## Usage

Provide the real message, Git history, or decision options. Choose one short workflow and review the result for the product’s facts and tone.
