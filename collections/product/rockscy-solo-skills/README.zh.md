# Solo Skills 独立开发技能

处理独立创始人的决策、客户回复、发布写作与短复盘。

## 合集介绍

作者的七技能包支持个人站会、交付决策、发布动态、更新日志、客户邮件、缺陷澄清和复盘，提供中英文指导。

## 适用场景

- 决定交付内容并安排当天工作
- 将客户消息转成回复或缺陷报告
- 撰写发布动态、更新说明和复盘

## 使用建议

提供真实消息、Git 历史或决策选项，选用一个简短流程，并根据产品事实和语气审阅产出。
