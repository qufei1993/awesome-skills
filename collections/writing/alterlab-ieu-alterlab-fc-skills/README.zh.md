# AlterLab 传播学技能

面向六个专业方向完成传播学课程任务与作品。

## 合集介绍

AlterLab 的完整七十二技能包覆盖公关广告、电影、新媒体、生成式制作、视觉传播和研究方法，各流程连接调研、创作与作品评审。

## 适用场景

- 规划活动和传播简报
- 制作影视、媒体和视觉方案
- 完成研究报告与课程作业

## 使用建议

提供课程任务、简报和项目材料，按专业方向选择流程，并准备对应产出需要的检索或制作工具。
