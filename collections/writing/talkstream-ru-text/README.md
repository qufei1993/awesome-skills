# ru-text Russian Editing Skills

Proofread Russian typography, bureaucratic phrasing, and signs of machine-written text.

![ru-text Russian Editing Skills — original project cover](<https://raw.githubusercontent.com/talkstream/ru-text/879a775a243203aa53a5bd593ac8bcdba2303bff/assets/og/og-dark-1200x628.jpg>)

## Overview

The author’s three-Skill pack combines editing, checking, and scoring while retaining the writer’s voice. Corrections cite the text and the rule applied.

## Scenarios

- Proofread a Russian document
- Assess recurring machine-written patterns

## Usage

Install all three with the documented skills CLI command. Provide the Russian text and request editing, checking, or scoring; file rewriting requires an explicit request.
