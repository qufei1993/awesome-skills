# ru-text 俄语编辑技能

校对俄语排版、官样表达与机器写作痕迹。

## 合集介绍

作者的三技能包结合编辑、检查与评分，并保留作者表达风格；修改同时引用原文和使用的规则。

## 适用场景

- 校对俄语文档
- 评估反复出现的机器表达

## 使用建议

按文档的 skills CLI 命令安装全部三项，提供俄语文本并要求编辑、检查或评分；重写文件需要明确请求。
