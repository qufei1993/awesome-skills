# Sepia Writing Skills

Improve fiction and professional prose through structural review and careful revision.

## Overview

Sepia’s complete plugin supplies its canonical writing guidance with operation wrappers for writing, review, minimal refactoring, recreation, and Hemingway-style editing.

## Scenarios

- Repair narrative structure in fiction
- Review or revise release notes, articles, and professional drafts

## Usage

Install the complete plugin because operation wrappers depend on the canonical sibling Skill. Specify the document’s venue, desired operation, and material to preserve.
