# Sepia 写作技能合集

通过结构审查与谨慎修改改善小说和专业文稿。

## 合集介绍

Sepia 完整插件包含正式写作指导，以及写作、审查、最小修改、重写和海明威风格编辑入口。

## 适用场景

- 修复小说叙事结构
- 审查或修改发布说明、文章与专业草稿

## 使用建议

安装完整插件，操作入口依赖同组正式技能。说明文稿用途、所需操作和必须保留的材料。
