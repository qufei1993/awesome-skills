# Slop Grader Skills

Create text-review rules and turn line-level grading results into concrete edits.

![Slop Grader Skills — original project cover](<https://raw.githubusercontent.com/lukstei/slop-grader/f2807bc4cf174786eda30afd1749e9886201d5c7/assets/terminal.png>)

## Overview

Slop Grader ships a grading-review Skill and a rules-authoring Skill with its CLI and Markdown rulesets. The complete published package supports line checks and document-level scores.

## Scenarios

- Review flagged wording in drafts
- Define custom document-review rules
- Prepare exact edits from grading results

## Usage

Prepare Node.js and a supported provider API key for the CLI. Give the agent the original document and grading output, then review false positives before editing.
