# Slop Grader 文本评审技能

编写文本检查规则，并将逐行评分结果转化为具体修改。

## 合集介绍

Slop Grader 随 CLI 和 Markdown 规则包发布评分评审、规则编写两个技能，完整发行支持逐行检查与整篇文档评分。

## 适用场景

- 检查草稿中被标记的措辞
- 定义自有文档评审规则
- 依据评分准备精确修改

## 使用建议

按上游要求准备 Node.js 和支持的服务密钥。向 Agent 提供原文与评分输出，先判断误报再修改。
