# 宝玉技能合集

制作图文内容并发布到文章与社交平台。

## 合集介绍

宝玉的公开技能库涵盖文章配图、漫画、信息图、幻灯片、翻译、Markdown 排版、网页提取和社交发布。

## 适用场景

- 制作文章配图与封面
- 将内容转为漫画、幻灯片或社交图片
- 提取、排版、翻译并发布内容

## 使用建议

准备 Node.js 与 Bun 运行环境，按内容任务选择流程。根据上游说明配置图像服务、浏览器会话或平台账号。
