# Baoyu Skills

Create illustrated content and publish it across social and article platforms.

## Overview

Baoyu’s public library covers article images, comics, infographics, slides, translation, Markdown formatting, web extraction, and social publishing.

## Scenarios

- Illustrate an article and design its cover
- Turn content into comics, slides, or social images
- Extract, format, translate, and publish content

## Usage

Prepare Node.js and the ability to run Bun, then choose the content workflow. Configure its image provider, browser session, or platform account using the upstream guide.
