# Humanize Chinese Skills

Write, revise, and proofread Chinese prose with local text-inspection helpers.

![Humanize Chinese Skills — original project cover](<https://raw.githubusercontent.com/swaylq/humanize-chinese/6510ca720b91919a12fa2e828b5ec959deb11db4/docs/assets/og.png>)

## Overview

The Chinese writing Skill combines writing, rewriting, and proofreading in one workflow. Its internal stages and local Python tools inspect wording patterns and hidden characters.

## Scenarios

- Write or revise Chinese drafts
- Remove assistant-style phrasing
- Proofread text and inspect hidden characters

## Usage

Provide the original text and intended genre. Keep the upstream local tools with the Skills; hidden-character cleanup does not establish removal of statistical text watermarks.
