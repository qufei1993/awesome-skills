# prompts.chat 插件技能

通过 prompts.chat 的 Claude Code 插件查找可复用提示词和技能。

## 合集介绍

公开插件为 prompts.chat 社区库提供提示词查询与技能查询能力，帮助助手按当前任务寻找现成资源。

## 适用场景

- 按具体任务查找提示词
- 为助手工作流程寻找可复用技能

## 使用建议

按上游说明安装 prompts.chat 插件，并完成服务连接配置后进行查询。
