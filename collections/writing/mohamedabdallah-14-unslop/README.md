# Unslop Writing Skills

Revise formulaic prose while preserving facts, meaning, and personal voice.

## Overview

The canonical six-Skill system combines rewrite modes, voice matching, and feedback. Its plugin and host-specific directories mirror one source.

## Scenarios

- Edit an application or business draft
- Preserve voice during a prose revision

## Usage

Install the unslop plugin or canonical Skills and specify the desired mode and preservation requirements. Provide voice examples when using persistent voice matching.
