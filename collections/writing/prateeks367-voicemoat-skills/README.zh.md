# VoiceMoat 写作技能

保持 LinkedIn 与 X 内容语气一致，并在发布前审阅。

## 合集介绍

VoiceMoat 完整二十六技能目录覆盖草稿、开场、结尾、故事、个人资料、评论、回复、内容支柱、复用、规划、团队发布和效果复盘。

## 适用场景

- 按个人语气起草与修改帖子
- 规划内容和回复流程
- 审查发布质量与结果

## 使用建议

提供写作样本、想法和平台背景。可直接使用免费技能；可选 VoiceMoat 集成会依据已发布内容建立语气档案。
