# LinkDigest Skills

Read social-media links as transcripts, image text, and verified source material.

## Overview

LinkDigest’s complete canonical Skill catalog covers Xiaohongshu, Douyin, TikTok, long video, YouTube summaries, WeChat articles, viral analysis, and script rewriting. Its scripts use the hosted reading service.

## Scenarios

- Extract text from social posts and videos
- Summarize long videos or articles
- Analyze content and rewrite scripts from evidence

## Usage

Provide the source link and desired output. Configure LinkDigest access for full extraction; keep quoted wording tied to the extracted post or transcript.
