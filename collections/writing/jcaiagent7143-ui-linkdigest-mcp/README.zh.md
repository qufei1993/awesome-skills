# LinkDigest 内容读取技能

把社交媒体链接转成逐字稿、图片文字与可核对资料。

## 合集介绍

LinkDigest 完整原生目录覆盖小红书、抖音、TikTok、长视频、YouTube 摘要、公众号文章、内容拆解和脚本改写，脚本连接在线读取服务。

## 适用场景

- 提取社交帖子和视频文字
- 总结长视频或文章
- 依据源资料拆解内容和改写脚本

## 使用建议

提供来源链接与输出要求。完整提取需要配置 LinkDigest 访问，引用文字应与提取的帖子或逐字稿对应。
