# Avoid AI Writing Plugin Skills

Audit and revise English writing while preserving voice, meaning, and protected material.

## Overview

Conor Bronsdon’s native ChatGPT and Codex package provides focused detection, rewriting, file editing, preservation checks, false-positive review, and routing Skills.

## Scenarios

- Identify repetitive or artificial writing patterns
- Revise a draft or explicitly named file

## Usage

Use the upstream seven-Skill package with its pattern references and detector. State the voice and protected content; detector signals guide editing rather than establish authorship.
